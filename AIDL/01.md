## 1. What is AIDL?

**AIDL = Android Interface Definition Language**

A mechanism for **Inter-Process Communication (IPC)** — allowing one process to call methods in another process as if they were local calls.

```
┌─────────────┐         Binder IPC          ┌─────────────┐
│   Client     │ ──────────────────────────► │   Server     │
│  (App/Fwk)   │  uses generated Proxy       │  (Service)   │
│              │ ◄────────────────────────── │              │
└─────────────┘     returns result           └─────────────┘
```

## 2. Why HIDL was Replaced with AIDL

### The Problem with HIDL

> **Analogy:** A company where the Software dept speaks English (AIDL) and the Hardware dept speaks French (HIDL). Every time they need to talk, they need a translator. The company maintains two language training programs, two dictionaries, two sets of grammar rules.

```
Before Android 11:
┌──────────────────────────────────────────────┐
│              Android Framework               │
│         (Uses AIDL for IPC)                  │  ← Language 1: AIDL
├──────────────────────────────────────────────┤
│            HIDL Layer (HAL Interface)        │  ← Language 2: HIDL
├──────────────────────────────────────────────┤
│         Vendor HAL Implementations           │
└──────────────────────────────────────────────┘

Problems:
• Two different IDL languages to learn
• Two different code generators
• Two different build rules
• Two different testing tools
• HIDL had its own hwbinder (separate from binder)
• Conversion overhead between AIDL ↔ HIDL at boundaries
```

### The Solution: One Language for Everything

```
Android 11+ (AIDL HALs):
┌──────────────────────────────────────────────┐
│              Android Framework               │
│         (Uses AIDL for IPC)                  │  ← Same: AIDL
├──────────────────────────────────────────────┤
│         Stable AIDL HAL Interface            │  ← Same: AIDL ✓
├──────────────────────────────────────────────┤
│         Vendor HAL Implementations           │
└──────────────────────────────────────────────┘

Benefits:
• ONE language everywhere
• ONE binder (no separate hwbinder needed)
• ONE code generator
• ONE set of tools
• Simpler, less code, fewer bugs
```

### Concrete Example: Vibrator HAL

**Old way — HIDL** (`hardware/interfaces/vibrator/1.0/IVibrator.hal`):

```hidl
// HIDL syntax - unique to HALs only
package android.hardware.vibrator@1.0;

interface IVibrator {
    on(uint32_t timeoutMs) generates (Status vibratorOnRet);
    off() generates (Status vibratorOffRet);
    supportsAmplitudeControl() generates (bool supports);
    setAmplitude(uint8_t amplitude) generates (Status status);
};
```

**New way — AIDL** (`hardware/interfaces/vibrator/aidl/android/hardware/vibrator/IVibrator.aidl`):

```aidl
// Standard AIDL syntax - same as framework uses!
package android.hardware.vibrator;

@VintfStability
interface IVibrator {
    void on(in int timeoutMs);
    void off();
    boolean supportsAmplitudeControl();
    void setAmplitude(in int amplitude);
}
```

### Key Differences at a Glance

| Aspect | HIDL | AIDL |
|---|---|---|
| Return values | `generates (Type name)` | Normal Java/C++ style returns |
| Error handling | Return Status enum | Throws `ServiceSpecificException` |
| Binder | `hwbinder` (separate) | `/dev/binder` or `/dev/vndbinder` |
| Versioning | `@1.0`, `@2.0` (package level) | Interface-level with `version:` in build |
| Inheritance | Interface inheritance for versions | Method additions in new versions |
| Languages | C++, Java (limited) | C++, Java, Rust, NDK backend |
| Learning curve | Separate syntax to learn | Already known by framework devs |

## 3. Types of AIDL in AOSP

```
AIDL in AOSP
├── 1. Traditional AIDL (Framework IPC)
│   ├── App ↔ System Service communication
│   ├── Example: IActivityManager, IPackageManager
│   └── Location: frameworks/base/core/java/...
│
├── 2. Stable AIDL (HAL Interfaces)  ← NEW replacement for HIDL
│   ├── Framework ↔ Vendor HAL communication
│   ├── @VintfStability annotation
│   ├── Example: IVibrator, IPower, IHealth
│   └── Location: hardware/interfaces/...
│
└── 3. Stable AIDL (System-to-System)
    ├── Between APEX modules / Mainline modules
    ├── Frozen interfaces for compatibility
    └── Location: frameworks/hardware/interfaces/...
```

#include <aidl/android/hardware/led/ILedCallback.h>

class Led : public BnLed {

        const std::shared_ptr<ILedCallback>& callback) override;

private:
    void notifyStateChanged(const LedState& state);
    bool writeToHardware(LedType type, const LedColor& color, bool on);

    std::mutex mLock;
    std::map<LedType, LedState> mLedStates;
    std::vector<std::shared_ptr<ILedCallback>> mCallbacks;

```

**`hardware/interfaces/led/aidl/default/Led.cpp`**

```cpp
#include "Led.h"
#include <android-base/logging.h>

namespace aidl::android::hardware::led {

Led::Led() {
    LOG(INFO) << "LED HAL initialized";
    for (auto type : {LedType::NOTIFICATION, LedType::BATTERY}) {
        LedState state;
        state.type = type;
        state.color = {0, 0, 0, 0};
        state.isOn = false;
        state.flashOnMs = 0;
        state.flashOffMs = 0;
        mLedStates[type] = state;
    }
}

Led::~Led() {
    LOG(INFO) << "LED HAL destroyed";
}

ndk::ScopedAStatus Led::getSupportedTypes(
    std::vector<LedType>* _aidl_return) {
    *_aidl_return = {LedType::NOTIFICATION, LedType::BATTERY};
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::setLedOn(LedType type, const LedColor& color) {
    std::lock_guard<std::mutex> lock(mLock);

    LOG(INFO) << "setLedOn: type=" << static_cast<int>(type)
              << " R=" << color.red << " G=" << color.green
              << " B=" << color.blue << " brightness=" << color.brightness;

    if (mLedStates.find(type) == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1 /* UNSUPPORTED */);
    }

    if (!writeToHardware(type, color, true)) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-2 /* HW_ERROR */);
    }

    auto& state = mLedStates[type];
    state.color = color;
    state.isOn = true;
    state.flashOnMs = 0;
    state.flashOffMs = 0;

    notifyStateChanged(state);
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::setLedOff(LedType type) {
    std::lock_guard<std::mutex> lock(mLock);

    if (mLedStates.find(type) == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1);
    }

    LedColor offColor = {0, 0, 0, 0};
    writeToHardware(type, offColor, false);

    auto& state = mLedStates[type];
    state.isOn = false;
    state.flashOnMs = 0;
    state.flashOffMs = 0;

    notifyStateChanged(state);
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::setFlashing(
    LedType type, const LedColor& color,
    int32_t onMs, int32_t offMs) {

    std::lock_guard<std::mutex> lock(mLock);

    if (mLedStates.find(type) == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1);
    }

    if (onMs <= 0 || offMs <= 0) {
        return ndk::ScopedAStatus::fromExceptionCode(EX_ILLEGAL_ARGUMENT);
    }

    writeToHardware(type, color, true);

    auto& state = mLedStates[type];
    state.color = color;
    state.isOn = true;
    state.flashOnMs = onMs;
    state.flashOffMs = offMs;

    notifyStateChanged(state);
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::getLedState(
    LedType type, LedState* _aidl_return) {

    std::lock_guard<std::mutex> lock(mLock);
    auto it = mLedStates.find(type);
    if (it == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1);
    }
    *_aidl_return = it->second;
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::registerCallback(
    const std::shared_ptr<ILedCallback>& callback) {

    std::lock_guard<std::mutex> lock(mLock);
    if (callback == nullptr) {
        return ndk::ScopedAStatus::fromExceptionCode(EX_ILLEGAL_ARGUMENT);
    }
    mCallbacks.push_back(callback);
    LOG(INFO) << "Callback registered, total: " << mCallbacks.size();
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::unregisterCallback(
    const std::shared_ptr<ILedCallback>& callback) {

    std::lock_guard<std::mutex> lock(mLock);
    mCallbacks.erase(
        std::remove_if(mCallbacks.begin(), mCallbacks.end(),
            [&](const std::shared_ptr<ILedCallback>& cb) {
                return cb->asBinder() == callback->asBinder();
            }),
        mCallbacks.end());
    LOG(INFO) << "Callback unregistered, remaining: " << mCallbacks.size();
    return ndk::ScopedAStatus::ok();
}

void Led::notifyStateChanged(const LedState& state) {
    for (const auto& callback : mCallbacks) {
        auto status = callback->onStateChanged(state);
        if (!status.isOk()) {
            LOG(WARNING) << "Failed to notify callback";
        }
    }
}

bool Led::writeToHardware(LedType type, const LedColor& color, bool on) {
    // Real implementation writes to sysfs:
    //   echo "255" > /sys/class/leds/notification/brightness
    //   echo "255 0 0" > /sys/class/leds/notification/multi_intensity
    LOG(INFO) << "HW Write: LED " << static_cast<int>(type)
              << " on=" << on
              << " color=(" << color.red << "," << color.green
              << "," << color.blue << ")";
    return true;
}

}  // namespace aidl::android::hardware::led
```

### Step 7 — Framework Client (Java — System Service)

**`frameworks/base/services/core/java/com/android/server/led/LedManagerService.java`**

```java
package com.android.server.led;

import android.content.Context;
import android.hardware.led.ILed;
import android.hardware.led.ILedCallback;
import android.hardware.led.LedColor;
import android.hardware.led.LedState;
import android.hardware.led.LedType;
import android.os.RemoteException;
import android.os.ServiceManager;
import android.util.Log;

public class LedManagerService {
    private static final String TAG = "LedManagerService";
    private ILed mLedHal;

    public LedManagerService(Context context) {
        connectToHal();
    }

    private void connectToHal() {
        String serviceName = ILed.DESCRIPTOR + "/default";
        var binder = ServiceManager.waitForService(serviceName);

        if (binder != null) {
            mLedHal = ILed.Stub.asInterface(binder);
            Log.i(TAG, "Connected to LED HAL");

            try {
                // Register for death notifications
                binder.linkToDeath(() -> {
                    Log.e(TAG, "LED HAL died! Reconnecting...");
                    mLedHal = null;
                    connectToHal();
                }, 0);

                mLedHal.registerCallback(new LedCallbackImpl());
            } catch (RemoteException e) {
                Log.e(TAG, "Failed to set up LED HAL", e);
            }
        } else {
            Log.e(TAG, "LED HAL service not found!");
        }
    }

    /** Called by NotificationManagerService to set notification LED */
    public void setNotificationLed(int red, int green, int blue,
                                    int onMs, int offMs) {
        if (mLedHal == null) {
            Log.w(TAG, "LED HAL not available");
            return;
        }

        try {
            LedColor color = new LedColor();
            color.red = red;
            color.green = green;
            color.blue = blue;
            color.brightness = 255;

            if (onMs > 0 && offMs > 0) {
                mLedHal.setFlashing(LedType.NOTIFICATION, color, onMs, offMs);
            } else {
                mLedHal.setLedOn(LedType.NOTIFICATION, color);
            }
        } catch (RemoteException e) {
            Log.e(TAG, "Failed to set notification LED", e);
        }
    }

    public void turnOffNotificationLed() {
        if (mLedHal == null) return;
        try {
            mLedHal.setLedOff(LedType.NOTIFICATION);
        } catch (RemoteException e) {
            Log.e(TAG, "Failed to turn off notification LED", e);
        }
    }

    private class LedCallbackImpl extends ILedCallback.Stub {
        @Override
        public void onStateChanged(LedState state) {
            Log.i(TAG, "LED state changed: type=" + state.type
                    + " isOn=" + state.isOn);
        }

        @Override
        public void onError(int type, int errorCode) {
            Log.e(TAG, "LED error: type=" + type + " error=" + errorCode);
        }

        @Override
        public int getInterfaceVersion() { return VERSION; }

        @Override
        public String getInterfaceHash() { return HASH; }
    }
}
```

## 6. Traditional AIDL (Framework) — Example

Classic AIDL used within the Android framework for App ↔ System Service communication.

### AIDL Interface

**`frameworks/base/core/java/android/app/ICustomService.aidl`**

package android.app;

/**
 * Traditional AIDL - no @VintfStability needed
 * Used within the framework only
 */
interface ICustomService {
    String getDeviceInfo();
    void setConfiguration(in String key, in String value);
    boolean isFeatureEnabled(in String featureName);
    oneway void logEvent(in String eventName);  // async, fire-and-forget
}
```

package com.android.server;

    @Override
    public String getDeviceInfo() {

    @Override
    public void setConfiguration(String key, String value) {
        mContext.enforceCallingPermission(

    public boolean isFeatureEnabled(String featureName) {
        return "feature_x".equals(featureName);
    }

    @Override
    public void logEvent(String eventName) {
        // 'oneway' — client doesn't wait for completion
        android.util.Log.d("CustomService", "Event: " + eventName);

## 8. AIDL HAL vs HIDL HAL Comparison

| Feature | HIDL | Stable AIDL |
|---|---|---|
| File extension | `.hal` | `.aidl` |
| Package naming | `@1.0`, `@2.1` | `version:` in Android.bp |
| Versioning | Package-level | Interface-level |
| Inheritance | Interface `extends` | Methods appended |
| Error handling | `Return<T>`, Status enum | `ScopedAStatus`, exceptions |
| Binder | `hwbinder` (`/dev/hwbinder`) | `vndbinder` (`/dev/vndbinder`) |
| Transport | hwbinder or passthrough | Binder only |
| Base class | `BnXxx` (HIDL gen) | `BnXxx` (AIDL gen) |
| Manifest tag | `<hal format="hidl">` | `<hal format="aidl">` |
| Backend languages | C++, Java | C++, Java, Rust, NDK |
| Parcelables | `struct` in `.hal` | Separate `.aidl` files |
| Callbacks | Separate `.hal` interface | Separate `.aidl` interface |
| Annotations | None | `@VintfStability`, etc. |
| Status (2024) | **Deprecated** | Active, preferred |
| Passthrough | Supported | NOT supported |

## 1. What is AIDL?

**AIDL = Android Interface Definition Language**

A mechanism for **Inter-Process Communication (IPC)** — allowing one process to call methods in another process as if they were local calls.

```
┌─────────────┐         Binder IPC          ┌─────────────┐
│   Client     │ ──────────────────────────► │   Server     │
│  (App/Fwk)   │  uses generated Proxy       │  (Service)   │
│              │ ◄────────────────────────── │              │
└─────────────┘     returns result           └─────────────┘
```

---

## 2. Why HIDL was Replaced with AIDL

### The Problem with HIDL

> **Analogy:** A company where the Software dept speaks English (AIDL) and the Hardware dept speaks French (HIDL). Every time they need to talk, they need a translator. The company maintains two language training programs, two dictionaries, two sets of grammar rules.

```
Before Android 11:
┌──────────────────────────────────────────────┐
│              Android Framework               │
│         (Uses AIDL for IPC)                  │  ← Language 1: AIDL
├──────────────────────────────────────────────┤
│            HIDL Layer (HAL Interface)        │  ← Language 2: HIDL
├──────────────────────────────────────────────┤
│         Vendor HAL Implementations           │
└──────────────────────────────────────────────┘

Problems:
• Two different IDL languages to learn
• Two different code generators
• Two different build rules
• Two different testing tools
• HIDL had its own hwbinder (separate from binder)
• Conversion overhead between AIDL ↔ HIDL at boundaries
```

### The Solution: One Language for Everything

```
Android 11+ (AIDL HALs):
┌──────────────────────────────────────────────┐
│              Android Framework               │
│         (Uses AIDL for IPC)                  │  ← Same: AIDL
├──────────────────────────────────────────────┤
│         Stable AIDL HAL Interface            │  ← Same: AIDL ✓
├──────────────────────────────────────────────┤
│         Vendor HAL Implementations           │
└──────────────────────────────────────────────┘

Benefits:
• ONE language everywhere
• ONE binder (no separate hwbinder needed)
• ONE code generator
• ONE set of tools
• Simpler, less code, fewer bugs
```

### Concrete Example: Vibrator HAL

**Old way — HIDL** (`hardware/interfaces/vibrator/1.0/IVibrator.hal`):

```hidl
// HIDL syntax - unique to HALs only
package android.hardware.vibrator@1.0;

interface IVibrator {
    on(uint32_t timeoutMs) generates (Status vibratorOnRet);
    off() generates (Status vibratorOffRet);
    supportsAmplitudeControl() generates (bool supports);
    setAmplitude(uint8_t amplitude) generates (Status status);
};
```

**New way — AIDL** (`hardware/interfaces/vibrator/aidl/android/hardware/vibrator/IVibrator.aidl`):

```aidl
// Standard AIDL syntax - same as framework uses!
package android.hardware.vibrator;

@VintfStability
interface IVibrator {
    void on(in int timeoutMs);
    void off();
    boolean supportsAmplitudeControl();
    void setAmplitude(in int amplitude);
}
```

### Key Differences at a Glance

| Aspect | HIDL | AIDL |
|---|---|---|
| Return values | `generates (Type name)` | Normal Java/C++ style returns |
| Error handling | Return Status enum | Throws `ServiceSpecificException` |
| Binder | `hwbinder` (separate) | `/dev/binder` or `/dev/vndbinder` |
| Versioning | `@1.0`, `@2.0` (package level) | Interface-level with `version:` in build |
| Inheritance | Interface inheritance for versions | Method additions in new versions |
| Languages | C++, Java (limited) | C++, Java, Rust, NDK backend |
| Learning curve | Separate syntax to learn | Already known by framework devs |

**`hardware/interfaces/led/aidl/default/Led.cpp`**

```cpp
#include "Led.h"
#include <android-base/logging.h>

namespace aidl::android::hardware::led {

Led::Led() {
    LOG(INFO) << "LED HAL initialized";
    for (auto type : {LedType::NOTIFICATION, LedType::BATTERY}) {
        LedState state;
        state.type = type;
        state.color = {0, 0, 0, 0};
        state.isOn = false;
        state.flashOnMs = 0;
        state.flashOffMs = 0;
        mLedStates[type] = state;
    }
}

Led::~Led() {
    LOG(INFO) << "LED HAL destroyed";
}

ndk::ScopedAStatus Led::getSupportedTypes(
    std::vector<LedType>* _aidl_return) {
    *_aidl_return = {LedType::NOTIFICATION, LedType::BATTERY};
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::setLedOn(LedType type, const LedColor& color) {
    std::lock_guard<std::mutex> lock(mLock);

    LOG(INFO) << "setLedOn: type=" << static_cast<int>(type)
              << " R=" << color.red << " G=" << color.green
              << " B=" << color.blue << " brightness=" << color.brightness;

    if (mLedStates.find(type) == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1 /* UNSUPPORTED */);
    }

    if (!writeToHardware(type, color, true)) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-2 /* HW_ERROR */);
    }

    auto& state = mLedStates[type];
    state.color = color;
    state.isOn = true;
    state.flashOnMs = 0;
    state.flashOffMs = 0;

    notifyStateChanged(state);
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::setLedOff(LedType type) {
    std::lock_guard<std::mutex> lock(mLock);

    if (mLedStates.find(type) == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1);
    }

    LedColor offColor = {0, 0, 0, 0};
    writeToHardware(type, offColor, false);

    auto& state = mLedStates[type];
    state.isOn = false;
    state.flashOnMs = 0;
    state.flashOffMs = 0;

    notifyStateChanged(state);
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::setFlashing(
    LedType type, const LedColor& color,
    int32_t onMs, int32_t offMs) {

    std::lock_guard<std::mutex> lock(mLock);

    if (mLedStates.find(type) == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1);
    }

    if (onMs <= 0 || offMs <= 0) {
        return ndk::ScopedAStatus::fromExceptionCode(EX_ILLEGAL_ARGUMENT);
    }

    writeToHardware(type, color, true);

    auto& state = mLedStates[type];
    state.color = color;
    state.isOn = true;
    state.flashOnMs = onMs;
    state.flashOffMs = offMs;

    notifyStateChanged(state);
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::getLedState(
    LedType type, LedState* _aidl_return) {

    std::lock_guard<std::mutex> lock(mLock);
    auto it = mLedStates.find(type);
    if (it == mLedStates.end()) {
        return ndk::ScopedAStatus::fromServiceSpecificError(-1);
    }
    *_aidl_return = it->second;
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::registerCallback(
    const std::shared_ptr<ILedCallback>& callback) {

    std::lock_guard<std::mutex> lock(mLock);
    if (callback == nullptr) {
        return ndk::ScopedAStatus::fromExceptionCode(EX_ILLEGAL_ARGUMENT);
    }
    mCallbacks.push_back(callback);
    LOG(INFO) << "Callback registered, total: " << mCallbacks.size();
    return ndk::ScopedAStatus::ok();
}

ndk::ScopedAStatus Led::unregisterCallback(
    const std::shared_ptr<ILedCallback>& callback) {

    std::lock_guard<std::mutex> lock(mLock);
    mCallbacks.erase(
        std::remove_if(mCallbacks.begin(), mCallbacks.end(),
            [&](const std::shared_ptr<ILedCallback>& cb) {
                return cb->asBinder() == callback->asBinder();
            }),
        mCallbacks.end());
    LOG(INFO) << "Callback unregistered, remaining: " << mCallbacks.size();
    return ndk::ScopedAStatus::ok();
}

void Led::notifyStateChanged(const LedState& state) {
    for (const auto& callback : mCallbacks) {
        auto status = callback->onStateChanged(state);
        if (!status.isOk()) {
            LOG(WARNING) << "Failed to notify callback";
        }
    }
}

bool Led::writeToHardware(LedType type, const LedColor& color, bool on) {
    // Real implementation writes to sysfs:
    //   echo "255" > /sys/class/leds/notification/brightness
    //   echo "255 0 0" > /sys/class/leds/notification/multi_intensity
    LOG(INFO) << "HW Write: LED " << static_cast<int>(type)
              << " on=" << on
              << " color=(" << color.red << "," << color.green
              << "," << color.blue << ")";
    return true;
}

}  // namespace aidl::android::hardware::led

### Step 7 — Framework Client (Java — System Service)

**`frameworks/base/services/core/java/com/android/server/led/LedManagerService.java`**

```java
package com.android.server.led;

import android.content.Context;
import android.hardware.led.ILed;
import android.hardware.led.ILedCallback;
import android.hardware.led.LedColor;
import android.hardware.led.LedState;
import android.hardware.led.LedType;
import android.os.RemoteException;
import android.os.ServiceManager;
import android.util.Log;

public class LedManagerService {
    private static final String TAG = "LedManagerService";
    private ILed mLedHal;

    public LedManagerService(Context context) {
        connectToHal();
    }

    private void connectToHal() {
        String serviceName = ILed.DESCRIPTOR + "/default";
        var binder = ServiceManager.waitForService(serviceName);

        if (binder != null) {
            mLedHal = ILed.Stub.asInterface(binder);
            Log.i(TAG, "Connected to LED HAL");

            try {
                // Register for death notifications
                binder.linkToDeath(() -> {
                    Log.e(TAG, "LED HAL died! Reconnecting...");
                    mLedHal = null;
                    connectToHal();
                }, 0);

                mLedHal.registerCallback(new LedCallbackImpl());
            } catch (RemoteException e) {
                Log.e(TAG, "Failed to set up LED HAL", e);
            }
        } else {
            Log.e(TAG, "LED HAL service not found!");
        }
    }

    /** Called by NotificationManagerService to set notification LED */
    public void setNotificationLed(int red, int green, int blue,
                                    int onMs, int offMs) {
        if (mLedHal == null) {
            Log.w(TAG, "LED HAL not available");
            return;
        }

        try {
            LedColor color = new LedColor();
            color.red = red;
            color.green = green;
            color.blue = blue;
            color.brightness = 255;

            if (onMs > 0 && offMs > 0) {
                mLedHal.setFlashing(LedType.NOTIFICATION, color, onMs, offMs);
            } else {
                mLedHal.setLedOn(LedType.NOTIFICATION, color);
            }
        } catch (RemoteException e) {
            Log.e(TAG, "Failed to set notification LED", e);
        }
    }

    public void turnOffNotificationLed() {
        if (mLedHal == null) return;
        try {
            mLedHal.setLedOff(LedType.NOTIFICATION);
        } catch (RemoteException e) {
            Log.e(TAG, "Failed to turn off notification LED", e);
        }
    }

    private class LedCallbackImpl extends ILedCallback.Stub {
        @Override
        public void onStateChanged(LedState state) {
            Log.i(TAG, "LED state changed: type=" + state.type
                    + " isOn=" + state.isOn);
        }

        @Override
        public void onError(int type, int errorCode) {
            Log.e(TAG, "LED error: type=" + type + " error=" + errorCode);
        }

        @Override
        public int getInterfaceVersion() { return VERSION; }

        @Override
        public String getInterfaceHash() { return HASH; }
    }
}
```

## 8. AIDL HAL vs HIDL HAL Comparison

| Feature | HIDL | Stable AIDL |
|---|---|---|
| File extension | `.hal` | `.aidl` |
| Package naming | `@1.0`, `@2.1` | `version:` in Android.bp |
| Versioning | Package-level | Interface-level |
| Inheritance | Interface `extends` | Methods appended |
| Error handling | `Return<T>`, Status enum | `ScopedAStatus`, exceptions |
| Binder | `hwbinder` (`/dev/hwbinder`) | `vndbinder` (`/dev/vndbinder`) |
| Transport | hwbinder or passthrough | Binder only |
| Base class | `BnXxx` (HIDL gen) | `BnXxx` (AIDL gen) |
| Manifest tag | `<hal format="hidl">` | `<hal format="aidl">` |
| Backend languages | C++, Java | C++, Java, Rust, NDK |
| Parcelables | `struct` in `.hal` | Separate `.aidl` files |
| Callbacks | Separate `.hal` interface | Separate `.aidl` interface |
| Annotations | None | `@VintfStability`, etc. |
| Status (2024) | **Deprecated** | Active, preferred |
| Passthrough | Supported | NOT supported |

### Auto-Generated Code Structure

When you build the AIDL interface, the compiler generates:

```
out/soong/.intermediates/hardware/interfaces/led/aidl/
└── android.hardware.led-V1-ndk-source/gen/
    └── android/hardware/led/
        ├── ILed.h              ← Interface header
        ├── BnLed.h             ← Server base class (Bn = Binder Native)
        ├── BpLed.h             ← Client proxy class (Bp = Binder Proxy)
        ├── ILed.cpp            ← Marshaling/unmarshaling code
        ├── LedType.h           ← Enum
        ├── LedColor.h          ← Parcelable
        ├── LedState.h          ← Parcelable
        ├── ILedCallback.h      ← Callback interface
        ├── BnLedCallback.h     ← Callback server base
        └── BpLedCallback.h     ← Callback proxy

Key:
  BnLed → Your HAL service EXTENDS this
  BpLed → Generated automatically, used by framework client
  ILed  → Pure interface definition
```

## Summary

| Question | Answer |
|---|---|
| What is AIDL? | Interface definition language for Binder IPC |
| Why replace HIDL? | One language instead of two; simpler, less overhead |
| Where is Stable AIDL? | `hardware/interfaces/*/aidl/` |
| Where is Traditional AIDL? | `frameworks/base/core/java/android/**/*.aidl` |
| Key annotation? | `@VintfStability` marks HAL interfaces |
| Versioning? | Freeze API → append new methods → bump version |
| Backend languages? | Java, C++, NDK (C++), Rust |
| Android version? | Stable AIDL HAL from Android 11+, mandatory from 13+ for new HALs |
| HIDL status? | Deprecated — no new HIDL HALs allowed since Android 13 |
