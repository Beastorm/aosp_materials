## 1. What is a Socket?

A socket is a **communication endpoint** allowing two processes to exchange data. Think of it like a phone call — one side dials (client), the other picks up (server), then they talk back and forth.

In AOSP, sockets are used extensively for IPC between system services, daemons, HALs, and apps.

### Socket Types in AOSP

| Type | Description |
|------|-------------|
| Unix Domain Socket | Same-device IPC — most common in AOSP |
| Internet Socket (TCP/UDP) | Network communication |
| Netlink Socket | Kernel ↔ userspace notifications |

## 2. Unix Domain Socket (Most Common in AOSP)

**What:** Allows IPC between two processes on the **same device** without touching the network stack. Faster than TCP/IP — data never leaves the machine.

### Where It's Used in AOSP

```
/dev/socket/zygote          ← ActivityManagerService → Zygote (fork app)
/dev/socket/vold            ← StorageManagerService ↔ vold (volumes)
/dev/socket/netd            ← NetworkManagementService ↔ netd
/dev/socket/logd            ← All processes → logd (logging)
/dev/socket/installd        ← PackageManagerService ↔ installd
/dev/socket/property_service← All processes → init (set properties)
```

```
┌──────────┐    Unix Domain Socket    ┌──────────┐
│  Client  │ ─────────────────────── │  Server  │
│  Process │ ◄───────────────────── │  Daemon  │
└──────────┘    /dev/socket/xyz       └──────────┘
```

### AOSP Example: Zygote Socket

**Server — `ZygoteServer.java`:**

```java
    ZygoteServer() {
        // Socket name "zygote" maps to /dev/socket/zygote

            createFileDescriptor(getZygoteSocketFd())

    }

    Runnable runSelectLoop(String abiList) {
        while (true) {
            ZygoteConnection connection = acceptCommandPeer();
            // Each connection = one fork request from AMS
            boolean done = connection.processOneCommand(this);
        }
    }
}
```

## 3. Native C/C++ Unix Domain Socket

AOSP daemons written in C/C++ use POSIX socket APIs directly.

### Server (Daemon)

```cpp
// Method 1: AOSP helper (preferred — socket pre-created by init)

#include <cutils/sockets.h>

int start_server_aosp_way() {
    // "mydaemon" must match the socket name in the .rc file
    int server_fd = android_get_control_socket("mydaemon");
    if (server_fd < 0) { perror("Failed to get control socket"); return -1; }

    listen(server_fd, 8);
    printf("Listening on /dev/socket/mydaemon\n");

    while (true) {
        int client_fd = accept(server_fd, NULL, NULL);
        if (client_fd < 0) { perror("accept"); continue; }

        char buffer[256] = {0};
        ssize_t n = read(client_fd, buffer, sizeof(buffer) - 1);
        if (n > 0) {
            printf("Received: %s\n", buffer);
            write(client_fd, "Command received OK", 19);
        }
        close(client_fd);
    }
    return 0;
}
```

```cpp
// Method 2: Manual POSIX (for dynamically created sockets)

int start_server_manual_way() {
    int server_fd = socket(AF_UNIX, SOCK_STREAM, 0);
    if (server_fd < 0) { perror("socket"); return -1; }

    struct sockaddr_un addr;
    memset(&addr, 0, sizeof(addr));
    addr.sun_family = AF_UNIX;
    strncpy(addr.sun_path, "/dev/socket/mydaemon_manual", sizeof(addr.sun_path) - 1);

    unlink(addr.sun_path);  // remove stale socket file

    if (bind(server_fd, (struct sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind"); close(server_fd); return -1;
    }

    listen(server_fd, 5);

    while (true) {
        int client_fd = accept(server_fd, NULL, NULL);
        if (client_fd >= 0) {
            char buf[128];
            int n = read(client_fd, buf, sizeof(buf) - 1);
            if (n > 0) { buf[n] = '\0'; printf("Got: %s\n", buf); write(client_fd, "OK", 2); }
            close(client_fd);
        }
    }
    return 0;
}
```

## 4. Java LocalSocket (Framework Level)

Android provides `LocalSocket` / `LocalServerSocket` Java classes wrapping Unix domain sockets.

### Server

```java
// frameworks/base/services/core/java/com/android/server/MySocketServer.java

import android.net.LocalServerSocket;
import android.net.LocalSocket;

public class MySocketServer {

    private LocalServerSocket mServerSocket;
    private volatile boolean mRunning = true;

    public void startServer() throws IOException {
        // Abstract namespace — no filesystem file created
        mServerSocket = new LocalServerSocket("my_service");
        System.out.println("Server started, waiting for connections...");

        while (mRunning) {
            LocalSocket clientSocket = mServerSocket.accept();  // blocks
            new Thread(() -> handleClient(clientSocket)).start();
        }
    }

    private void handleClient(LocalSocket socket) {
        try {
            byte[] buffer = new byte[1024];
            int n = socket.getInputStream().read(buffer);

            if (n > 0) {
                String message = new String(buffer, 0, n);
                System.out.println("Client says: " + message);

                String response;
                if (message.equals("GET_STATUS"))         response = "STATUS: OK, Battery: 85%";
                else if (message.startsWith("SET_"))      response = "Setting applied";
                else                                       response = "Unknown command";

                socket.getOutputStream().write(response.getBytes());
            }
            socket.close();

        } catch (IOException e) { e.printStackTrace(); }
    }

    public void stopServer() {
        mRunning = false;
        try { if (mServerSocket != null) mServerSocket.close(); }
        catch (IOException e) { e.printStackTrace(); }
    }
}
```

### Client

```java
import android.net.LocalSocket;
import android.net.LocalSocketAddress;

public class MySocketClient {

    public String sendCommand(String command) {
        LocalSocket socket = null;
        try {
            socket = new LocalSocket();

            // Name must match what the server used
            socket.connect(new LocalSocketAddress(
                "my_service",
                LocalSocketAddress.Namespace.ABSTRACT
            ));

            socket.getOutputStream().write(command.getBytes());
            socket.getOutputStream().flush();

            byte[] buffer = new byte[1024];
            int n = socket.getInputStream().read(buffer);
            if (n > 0) return new String(buffer, 0, n);

        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            if (socket != null) try { socket.close(); } catch (IOException ignored) {}
        }
        return null;
    }
}
```

## 5. NativeDaemonConnector (Real AOSP Pattern)

`NativeDaemonConnector` is the bridge between Java framework services and native C/C++ daemons.

```
┌───────────────────┐                     ┌────────────────┐
│   Java Service    │                     │ Native Daemon  │
│  (system_server)  │                     │   (C/C++)      │
│                   │                     │                │
│ StorageManager    │◄── /dev/socket/vold ►│ vold          │
│ Service           │                     │                │
│ NetworkManagement │◄── /dev/socket/netd ►│ netd          │
│ Service           │                     │                │
└───────────────────┘                     └────────────────┘
  Uses NativeDaemonConnector               Uses libsysutils
```

### `StorageManagerService` connecting to `vold`

```java
// frameworks/base/services/core/java/com/android/server/StorageManagerService.java

public class StorageManagerService extends IStorageManager.Stub
        implements INativeDaemonConnectorCallbacks {

    private NativeDaemonConnector mConnector;

    public StorageManagerService(Context context) {
        mConnector = new NativeDaemonConnector(
            this,              // callback handler
            "vold",            // socket name → /dev/socket/vold
            500,               // max buffer size
            "VoldConnector",   // log tag
            25,                // command timeout (seconds)
            null
        );
        new Thread(mConnector, "VoldConnector").start();
    }

    // Called when vold sends an unsolicited async event
    @Override
    public boolean onEvent(int code, String raw, String[] parsed) {
        switch (code) {
            case 630:  // Volume state changed
                handleVolumeStateChanged(parsed[1], Integer.parseInt(parsed[2]));
                return true;
            case 640:  // New disk detected (USB plugged in)
                handleDiskCreated(parsed[1]);
                return true;
            default:
                return false;
        }
    }

    // Synchronous command — sends request, waits for response
    public void mountVolume(String volumeId) {
        try {
            NativeDaemonEvent event = mConnector.execute("volume", "mount", volumeId);
            if (event.getCode() == 200) System.out.println("Mounted!");
        } catch (NativeDaemonConnectorException e) {
            System.err.println("Mount failed: " + e.getMessage());
        }
    }
}
```

### `NativeDaemonConnector` internals (simplified)

```java
// frameworks/base/services/core/java/com/android/server/NativeDaemonConnector.java

public class NativeDaemonConnector implements Runnable {

    @Override
    public void run() {
        while (true) {
            try { listenToSocket(); }
            catch (Exception e) { sleep(5000); }  // retry on daemon restart
        }
    }

    private void listenToSocket() throws IOException {
        LocalSocket socket = new LocalSocket();
        socket.connect(new LocalSocketAddress(mSocket,
                       LocalSocketAddress.Namespace.RESERVED));

        mOutputStream = socket.getOutputStream();
        InputStream in = socket.getInputStream();
        byte[] buffer  = new byte[4096];

        while (true) {
            int count = in.read(buffer);
            if (count < 0) break;

            NativeDaemonEvent event = NativeDaemonEvent.parseRawEvent(
                new String(buffer, 0, count));

            if (event.isClassUnsolicited()) {
                // Async event (e.g. USB plugged in) → forward to callback
                mCallbacks.onEvent(event.getCode(), event.getRawEvent(),
                                   event.getMessage().split(" "));
            } else {
                // Response to a command → wake up waiting thread
                mResponseQueue.add(event);
            }
        }
    }

    public NativeDaemonEvent execute(String... args) throws IOException {
        int seqNum = mSequenceNumber++;
        StringBuilder cmd = new StringBuilder(seqNum + " ");
        for (String arg : args) cmd.append(arg).append(' ');
        cmd.append('\0');

        synchronized (mOutputStream) {
            mOutputStream.write(cmd.toString().getBytes());
            mOutputStream.flush();
        }

        return mResponseQueue.take();  // block until response arrives
    }
}
```

## 6. Internet Socket (TCP/UDP)

Standard network sockets for communication over WiFi or cellular.

### TCP Client

```java
import java.net.Socket;
import java.net.InetSocketAddress;
import java.io.*;

public class TcpClientExample {

    public void connectToServer() {
        try (Socket socket = new Socket()) {
            socket.connect(new InetSocketAddress("192.168.1.100", 8080), 5000);
            socket.setSoTimeout(10000);
            socket.setKeepAlive(true);

            PrintWriter writer  = new PrintWriter(socket.getOutputStream(), true);
            BufferedReader reader = new BufferedReader(
                new InputStreamReader(socket.getInputStream()));

            writer.println("GET /api/device/status HTTP/1.1");
            writer.println("Host: 192.168.1.100");
            writer.println("");

            StringBuilder response = new StringBuilder();
            String line;
            while ((line = reader.readLine()) != null) response.append(line).append('\n');

            System.out.println("Response: " + response);

        } catch (Exception e) { e.printStackTrace(); }
    }
}
```

```java
    }
}
```

### UDP Socket

```java
import java.net.*;

public class UdpExample {

    // Fire-and-forget sender
    public void sendUdpMessage(String message, String ip, int port) throws Exception {
        try (DatagramSocket socket = new DatagramSocket()) {
            byte[] data = message.getBytes();
            DatagramPacket packet = new DatagramPacket(
                data, data.length, InetAddress.getByName(ip), port);
            socket.send(packet);
            System.out.println("Sent to " + ip + ":" + port);
        }
    }

    // Receiver
    public void receiveUdpMessages(int port) throws Exception {
        try (DatagramSocket socket = new DatagramSocket(port)) {
            byte[] buffer = new byte[1024];
            while (true) {
                DatagramPacket packet = new DatagramPacket(buffer, buffer.length);
                socket.receive(packet);  // blocks
                String msg  = new String(packet.getData(), 0, packet.getLength());
                String from = packet.getAddress().getHostAddress() + ":" + packet.getPort();
                System.out.println(from + " → " + msg);
            }
        }
    }
}
```

## 7. Netlink Socket

Netlink sockets let userspace processes **receive notifications directly from the Linux kernel**.

```
┌──────────────────┐
│   Linux Kernel    │
│                   │
│  Network changes  │──── Netlink ────► NetlinkManager (system_server)
│  Battery events   │     Socket
│  USB hotplug      │
│  UEvent           │
└──────────────────┘
```

### Network Event Listener

```cpp
// system/netd/server/NetlinkManager.cpp

#include <sys/socket.h>
#include <linux/netlink.h>
#include <linux/rtnetlink.h>

int create_netlink_socket() {
    int sock = socket(AF_NETLINK, SOCK_DGRAM, NETLINK_ROUTE);
    if (sock < 0) { perror("netlink socket"); return -1; }

    struct sockaddr_nl addr = {0};
    addr.nl_family = AF_NETLINK;
    addr.nl_pid    = getpid();
    addr.nl_groups = RTMGRP_LINK          // interface up/down
                   | RTMGRP_IPV4_IFADDR   // IPv4 address changes
                   | RTMGRP_IPV6_IFADDR   // IPv6 address changes
                   | RTMGRP_IPV4_ROUTE;   // route changes

    bind(sock, (struct sockaddr*)&addr, sizeof(addr));

    char buffer[4096];
    while (1) {
        int len = recv(sock, buffer, sizeof(buffer), 0);
        if (len < 0) break;

        struct nlmsghdr *nlh = (struct nlmsghdr*)buffer;
        while (NLMSG_OK(nlh, len)) {
            switch (nlh->nlmsg_type) {
                case RTM_NEWLINK: printf("Interface change\n");  break;
                case RTM_DELLINK: printf("Interface removed\n"); break;
                case RTM_NEWADDR: printf("New IP assigned\n");   break;
                case RTM_DELADDR: printf("IP removed\n");        break;
                case RTM_NEWROUTE:printf("Route added\n");       break;
            }
            nlh = NLMSG_NEXT(nlh, len);
        }
    }
    close(sock);
    return 0;
}
```

### UEvent Socket (Hardware Hotplug)

```cpp
// system/core/init/ueventd.cpp

int monitor_hardware_events() {
    // NETLINK_KOBJECT_UEVENT = USB, battery, headphone plug events
    int sock = socket(AF_NETLINK, SOCK_DGRAM, NETLINK_KOBJECT_UEVENT);
    if (sock < 0) { perror("uevent socket"); return -1; }

    struct sockaddr_nl addr = { .nl_family = AF_NETLINK,
                                .nl_pid = getpid(), .nl_groups = 1 };
    bind(sock, (struct sockaddr*)&addr, sizeof(addr));

    char buffer[4096];
    while (1) {
        int len = recv(sock, buffer, sizeof(buffer) - 1, 0);
        if (len <= 0) continue;
        buffer[len] = '\0';

        // Format: "ACTION@DEVPATH\0KEY=VALUE\0..."
        // Example: "add@/devices/platform/usb/usb_device"
        if      (strstr(buffer, "add@"))    printf("Device added:   %s\n", buffer);
        else if (strstr(buffer, "remove@")) printf("Device removed: %s\n", buffer);
        else if (strstr(buffer, "change@")) printf("Device changed: %s\n", buffer);
        // ueventd uses this to: create /dev/ nodes, set permissions, load firmware
    }
    close(sock);
    return 0;
}
```

## 8. Socket Namespaces in AOSP

```java
// AOSP supports three socket namespaces:

// 1. RESERVED — /dev/socket/<name>
//    Created by init from .rc files. Only privileged processes.
LocalSocketAddress reservedAddr = new LocalSocketAddress(
    "vold",
    LocalSocketAddress.Namespace.RESERVED   // → /dev/socket/vold
);

// 2. ABSTRACT — no filesystem file
//    Lives only in kernel memory. Disappears when all users close it.
//    Any process can create one — used for app-to-app communication.
LocalSocketAddress abstractAddr = new LocalSocketAddress(
    "my_app_socket",
    LocalSocketAddress.Namespace.ABSTRACT   // no file created
);

// 3. FILESYSTEM — actual file on disk
//    Persists until deleted. Access controlled by file permissions.
LocalSocketAddress filesystemAddr = new LocalSocketAddress(
    "/data/misc/my_socket",
    LocalSocketAddress.Namespace.FILESYSTEM // file at that path
);
```

| Namespace | File Created? | Who Can Create | Persistence |
|-----------|--------------|----------------|-------------|
| `RESERVED` | ✅ `/dev/socket/` | `init` only | Until init removes it |
| `ABSTRACT` | ❌ | Any process | Until last user closes |
| `FILESYSTEM` | ✅ Custom path | Any (with permission) | Until deleted |

## 9. Passing File Descriptors Over Sockets

Unix domain sockets can **pass open file descriptors** between processes — the receiver gets its own fd pointing to the same kernel object.

**Used in AOSP for:** GPU buffer handles (SurfaceFlinger ↔ apps), ashmem regions, open file handles across privilege boundaries.

```java
// SENDER: opens a file and passes the fd
public void sendFileDescriptor() throws Exception {
    LocalSocket socket = new LocalSocket();
    socket.connect(new LocalSocketAddress("fd_receiver",
                   LocalSocketAddress.Namespace.ABSTRACT));

    ParcelFileDescriptor pfd = ParcelFileDescriptor.open(
        new java.io.File("/data/misc/shared_data.bin"),
        ParcelFileDescriptor.MODE_READ_ONLY
    );

    // Attach fd as ancillary data
    socket.setFileDescriptorsForSend(new FileDescriptor[]{ pfd.getFileDescriptor() });

    // Must write regular data to trigger the send
    socket.getOutputStream().write("fd_attached".getBytes());
    socket.close();
}

// RECEIVER: gets a new fd pointing to the same file
public void receiveFileDescriptor() throws Exception {
    LocalServerSocket server = new LocalServerSocket("fd_receiver");
    LocalSocket client = server.accept();

    byte[] buf = new byte[64];
    client.getInputStream().read(buf);

    // New fd in OUR process — same underlying file
    FileDescriptor[] fds = client.getAncillaryFileDescriptors();

    if (fds != null && fds.length > 0) {
        // Read the file without knowing its path!
        FileInputStream fis = new FileInputStream(fds[0]);
        byte[] data = new byte[1024];
        int n = fis.read(data);
        System.out.println("Read " + n + " bytes from shared fd");
        fis.close();
    }
    client.close();
    server.close();
}
```

## 10. SELinux Policy for Sockets

In AOSP, SELinux enforces which processes can **create, bind, and connect to** sockets — regardless of Unix file permissions.

```te
# system/sepolicy/private/mydaemon.te

type mydaemon,      domain;
type mydaemon_exec, exec_type, file_type;

init_daemon_domain(mydaemon)

# Allow mydaemon to own its socket
allow mydaemon mydaemon_socket:sock_file         { create setattr unlink };
allow mydaemon mydaemon_socket:unix_stream_socket { create bind listen accept read write getattr };

# Allow system_server to connect to mydaemon
allow system_server mydaemon_socket:unix_stream_socket connectto;
allow system_server mydaemon_socket:sock_file          write;

# File context label (system/sepolicy/private/file_contexts):
# /dev/socket/mydaemon    u:object_r:mydaemon_socket:s0
```

**When policy is missing, the kernel log shows:**

```
avc: denied { connectto } for pid=1234 comm="system_server"
    scontext=u:r:system_server:s0
    tcontext=u:r:mydaemon:s0
    tclass=unix_stream_socket
```

```cpp
// device/mycompany/mydevice/battery_extra_daemon/main.cpp

#define LOG_TAG "BatteryExtraDaemon"
#include <cutils/sockets.h>
#include <log/log.h>
#include <sys/socket.h>
#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <pthread.h>
#include <errno.h>

#define BATTERY_HEALTH_PATH "/sys/class/power_supply/battery/health"
#define BATTERY_TEMP_PATH   "/sys/class/power_supply/battery/temp"
#define BATTERY_CYCLE_PATH  "/sys/class/power_supply/battery/cycle_count"

int read_sysfs_string(const char* path, char* buf, size_t size) {
    FILE* fp = fopen(path, "r");
    if (!fp) { ALOGE("Cannot open %s: %s", path, strerror(errno)); return -1; }
    if (!fgets(buf, size, fp)) { fclose(fp); return -1; }
    size_t len = strlen(buf);
    if (len > 0 && buf[len-1] == '\n') buf[len-1] = '\0';
    fclose(fp);
    return 0;
}

// Protocol: client sends "<seq> <cmd> <subcmd>", server replies "<code> <seq> <result>"
void process_command(int client_fd, const char* command) {
    char response[512], value[256];
    int seq; char cmd[64]={0}, subcmd[64]={0};
    sscanf(command, "%d %s %s", &seq, cmd, subcmd);

    if (strcmp(cmd, "battery") == 0) {
        const char* path = NULL;
        if      (strcmp(subcmd, "health")      == 0) path = BATTERY_HEALTH_PATH;
        else if (strcmp(subcmd, "temperature") == 0) path = BATTERY_TEMP_PATH;
        else if (strcmp(subcmd, "cycles")      == 0) path = BATTERY_CYCLE_PATH;

        if (path && read_sysfs_string(path, value, sizeof(value)) == 0) {
            if (strcmp(subcmd, "temperature") == 0)
                snprintf(response, sizeof(response), "200 %d %.1f", seq, atoi(value)/10.0f);
            else
                snprintf(response, sizeof(response), "200 %d %s", seq, value);
        } else {
            snprintf(response, sizeof(response), "500 %d Error reading %s", seq, subcmd);
        }
    } else {
        snprintf(response, sizeof(response), "400 %d Unknown command: %s", seq, cmd);
    }

    write(client_fd, response, strlen(response));
}

void* handle_client(void* arg) {
    int client_fd = *(int*)arg; free(arg);
    char buffer[1024];

    while (1) {
        memset(buffer, 0, sizeof(buffer));
        ssize_t n = read(client_fd, buffer, sizeof(buffer) - 1);
        if (n <= 0) break;
        process_command(client_fd, buffer);
    }
    close(client_fd);
    return NULL;
}

int main() {
    ALOGI("BatteryExtraDaemon starting...");

    int server_fd = android_get_control_socket("battery_extra");
    if (server_fd < 0) { ALOGE("Failed to get socket: %s", strerror(errno)); return 1; }

    listen(server_fd, 4);
    ALOGI("Listening on /dev/socket/battery_extra");

    while (1) {
        int client_fd = accept(server_fd, NULL, NULL);
        if (client_fd < 0) { ALOGE("accept: %s", strerror(errno)); continue; }

        pthread_t thread;
        int* fd_ptr = (int*)malloc(sizeof(int));
        *fd_ptr = client_fd;
        pthread_create(&thread, NULL, handle_client, fd_ptr);
        pthread_detach(thread);
    }
    return 0;
}
```

```java
public class BatteryExtraService extends IBatteryExtra.Stub {

    private static final String TAG         = "BatteryExtraService";
    private static final String SOCKET_NAME = "battery_extra";

    private LocalSocket    mSocket;
    private OutputStream   mOut;
    private InputStream    mIn;
    private int            mSeq  = 0;
    private final Object   mLock = new Object();

    public BatteryExtraService(Context context) { connectToDaemon(); }

    private void connectToDaemon() {
        try {
            mSocket = new LocalSocket();
            mSocket.connect(new LocalSocketAddress(SOCKET_NAME,
                            LocalSocketAddress.Namespace.RESERVED));
            mOut = mSocket.getOutputStream();
            mIn  = mSocket.getInputStream();
            Slog.i(TAG, "Connected to battery_extra_daemon");
        } catch (IOException e) { Slog.e(TAG, "Connection failed", e); }
    }

    private String executeCommand(String cmd, String subcmd) {
        synchronized (mLock) {
            try {
                if (mSocket == null || !mSocket.isConnected()) connectToDaemon();

                String fullCmd = (mSeq++) + " " + cmd + " " + subcmd;
                mOut.write(fullCmd.getBytes()); mOut.flush();

                byte[] buf = new byte[512];
                int n = mIn.read(buf);
                if (n > 0) {
                    String response = new String(buf, 0, n);
                    String[] parts  = response.split(" ", 3);
                    if (Integer.parseInt(parts[0]) == 200 && parts.length >= 3)
                        return parts[2];
                }
            } catch (IOException e) {
                Slog.e(TAG, "IO error", e);
                try { mSocket.close(); } catch (IOException ignored) {}
                mSocket = null;
            }
            return null;
        }
    }

    @Override public String getBatteryHealth()      { return executeCommand("battery", "health"); }
    @Override public String getBatteryTemperature() { return executeCommand("battery", "temperature"); }
    @Override public String getBatteryCycleCount()  { return executeCommand("battery", "cycles"); }
```

# 📞 POSIX Socket API in AOSP — Simple Explanation

---

## What is POSIX Socket API?

**POSIX** = Portable Operating System Interface — a standard set of C functions for socket programming that works on Linux, Unix, Android, and more.

### Phone System Analogy

| Function | Analogy |
|----------|---------|
| `socket()` | Buy a phone |
| `bind()` | Get a phone number assigned |
| `listen()` | Turn on the ringer / wait for calls |
| `accept()` | Pick up when someone calls |
| `connect()` | Dial someone's number |
| `write()` | Talk / speak |
| `read()` | Listen / hear |
| `close()` | Hang up |

---

## POSIX Socket Functions — One by One

---

### 1. `socket()` — Create a Socket

```c
#include <sys/socket.h>

int fd = socket(
    AF_UNIX,      // Domain: AF_UNIX    = local (same device)
                  //         AF_INET    = IPv4 network
                  //         AF_NETLINK = kernel communication

    SOCK_STREAM,  // Type: SOCK_STREAM   = reliable + ordered (like TCP)
                  //       SOCK_DGRAM    = unreliable packets (like UDP)
                  //       SOCK_SEQPACKET= reliable + message boundaries

    0             // Protocol: 0 = auto-select from domain + type
);

// Returns:
//   fd >= 0  → success
//   fd == -1 → failure; check errno
//
// Common errors:
//   EACCES = permission denied
//   EMFILE = too many open files
//   ENOMEM = out of memory
```

**Real AOSP — `logd`:**

```c
// logd creates a socket so any process can send log messages to it
// Real file: system/logging/logd/LogReader.cpp

int log_socket = socket(AF_UNIX, SOCK_SEQPACKET, 0);
// → becomes /dev/socket/logdw
// Every Log.d() / Log.e() call in Java eventually writes here
```

### 2. `bind()` — Assign an Address

```c
#include <sys/socket.h>
#include <sys/un.h>

struct sockaddr_un addr;
memset(&addr, 0, sizeof(addr));           // always clear first!
addr.sun_family = AF_UNIX;
strncpy(addr.sun_path, "/dev/socket/myservice", sizeof(addr.sun_path) - 1);

int result = bind(
    fd,                          // socket from socket()
    (struct sockaddr*)&addr,     // address (cast to generic type)
    sizeof(addr)
);

// Common errors:
//   EADDRINUSE = socket file already exists
//   EACCES     = no permission to create file at that path
//   EINVAL     = socket already bound
```

**Real AOSP — `installd`:**

```c
// installd binds so PackageManagerService can send install/uninstall commands
// Real file: frameworks/native/cmds/installd/installd.cpp

struct sockaddr_un addr;
memset(&addr, 0, sizeof(addr));
addr.sun_family = AF_UNIX;
strcpy(addr.sun_path, "/dev/socket/installd");

unlink(addr.sun_path);  // remove stale file from previous run
bind(installd_socket, (struct sockaddr*)&addr, sizeof(addr));

// After bind:  ls -la /dev/socket/
// srw-rw---- 1 root install ... installd   ← socket file created
```

### 3. `listen()` — Wait for Connections

```c
int backlog = 5;  // max number of connections queued while we're busy

int result = listen(fd, backlog);

// After listen():
//   Socket is now "passive" — others can connect to it
//   Incoming connections queue up (up to backlog)
//   You must call accept() to dequeue each one
```

**Real AOSP — `vold`:**

```c
// Real file: system/vold/main.cpp
// Only a few system services talk to vold at once, so backlog=4 is enough

listen(vold_socket, 4);
```

### 4. `accept()` — Accept an Incoming Connection

```c
struct sockaddr_un client_addr;
socklen_t client_len = sizeof(client_addr);

// BLOCKS here until a client connects
int client_fd = accept(
    server_fd,                       // the listening socket
    (struct sockaddr*)&client_addr,  // client's address (output)
    &client_len                      // address size (input/output)
);

// Returns a NEW fd for this specific client.
// server_fd keeps listening for more connections.
//
// Common errors:
//   EINTR  = interrupted by signal — not an error, just retry
//   EAGAIN = no connection ready (non-blocking mode only)
```

**Before and after `accept()`:**

```
Before accept():
┌─────────────┐
│  server_fd  │  ← listening on /dev/socket/myservice
└─────────────┘

Client A connects → accept() returns:

┌─────────────┐        ┌──────────────┐
│  server_fd  │        │   Client A   │
│  (still     │        └──────┬───────┘
│  listening) │               │
└─────────────┘        ┌──────▼───────┐
                        │  client_fd  │  ← talk to A here
                        └─────────────┘
```

**Real AOSP — `logd`:**

```c
// Real file: system/logging/logd/main.cpp
// Every Log.d(), Log.e() etc. goes through this loop

while (true) {
    int client_fd = accept(log_socket_fd, NULL, NULL);
    if (client_fd >= 0) {
        handle_log_entry(client_fd);   // read and store the log
        close(client_fd);
    }
}
```

### 5. `connect()` — Connect to a Server

```c
// Client side — no bind() needed; kernel assigns a temporary address

int fd = socket(AF_UNIX, SOCK_STREAM, 0);

struct sockaddr_un server_addr;
memset(&server_addr, 0, sizeof(server_addr));
server_addr.sun_family = AF_UNIX;
strncpy(server_addr.sun_path, "/dev/socket/myservice",
        sizeof(server_addr.sun_path) - 1);

int result = connect(
    fd,
    (struct sockaddr*)&server_addr,
    sizeof(server_addr)
);

// result == 0  → connected; can now read() and write()
//
// Common errors:
//   ECONNREFUSED = server not running
//   ENOENT       = socket file doesn't exist
//   EACCES       = permission denied (SELinux may also block this!)
//   ETIMEDOUT    = connection timed out
```

**Real AOSP — `rild` connects to modem:**

```c
strcpy(modem_addr.sun_path, "/dev/socket/rild-debug");
```

### 6. `write()` / `send()` — Send Data

```c
const char* message = "mount emulated 0";
size_t msg_len = strlen(message);

// Method 1: write() — simple
ssize_t sent = write(client_fd, message, msg_len);

// Method 2: send() — with flags
ssize_t sent2 = send(client_fd, message, msg_len,
    MSG_NOSIGNAL  // don't send SIGPIPE if connection breaks — essential in Android
);

// ⚠ write() may send FEWER bytes than requested!
// Always check and send the remainder:
if (sent < (ssize_t)msg_len)
    write(client_fd, message + sent, msg_len - sent);
```

**Helper for reliable write (used throughout AOSP):**

```c
ssize_t write_all(int fd, const void* buf, size_t count) {
    const char* ptr = (const char*)buf;
    size_t remaining = count;

    while (remaining > 0) {
        ssize_t sent = write(fd, ptr, remaining);

        if (sent < 0) {
            if (errno == EINTR) continue;  // signal interrupted, retry
            return -1;                     // real error
        }
        if (sent == 0) break;              // connection closed

        ptr       += sent;
        remaining -= sent;
    }

    return count - remaining;
}

// Usage — guaranteed to send all 11 bytes:
write_all(fd, "hello world", 11);
```

### 7. `read()` / `recv()` — Receive Data

```c
char buffer[1024];
memset(buffer, 0, sizeof(buffer));

ssize_t n = read(
    client_fd,
    buffer,
    sizeof(buffer) - 1   // leave room for null terminator
);

if (n < 0) {
    perror("read() failed");
    // EAGAIN/EWOULDBLOCK = no data yet (non-blocking mode)
    // EINTR              = interrupted by signal — retry
}

if (n == 0) {
    // Other side closed the connection
    printf("Connection closed by peer\n");
    close(client_fd);
}

if (n > 0) {
    buffer[n] = '\0';
    printf("Received %zd bytes: %s\n", n, buffer);
}

// recv() with flags:
ssize_t n2 = recv(client_fd, buffer, sizeof(buffer),
    MSG_WAITALL  // wait until ALL requested bytes arrive
);
```

---

### 8. `close()` — Close the Socket

```c
close(client_fd);   // close client connection
close(server_fd);   // close server socket

// For Unix domain sockets — also remove the filesystem file
unlink("/dev/socket/myservice");

// Optional: shutdown() closes one direction before close()
shutdown(fd, SHUT_RD);    // stop receiving
shutdown(fd, SHUT_WR);    // stop sending
shutdown(fd, SHUT_RDWR);  // stop both (then call close())
```

> ⚠️ **Always close sockets!** Android limits each process to ~1024 open file descriptors. Leaking them eventually causes `open()` / `socket()` to fail.

## Complete AOSP-Style Example

### Server (Daemon)

```c
// my_daemon/main.c

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/socket.h>
#include <sys/un.h>
#include <errno.h>

#define SOCKET_PATH "/dev/socket/my_daemon"
#define MAX_CLIENTS 5
#define BUFFER_SIZE 256

const char* process_command(const char* cmd) {
    if (strcmp(cmd, "GET_VERSION") == 0) return "200 VERSION 1.0";
    if (strcmp(cmd, "GET_STATUS")  == 0) return "200 STATUS running";
    if (strcmp(cmd, "PING")        == 0) return "200 PONG";
    return "400 UNKNOWN_COMMAND";
}

int main() {
    // Step 1: create socket
    int server_fd = socket(AF_UNIX, SOCK_STREAM, 0);
    if (server_fd < 0) { perror("socket"); return 1; }

    // Step 2: address
    struct sockaddr_un addr;
    memset(&addr, 0, sizeof(addr));
    addr.sun_family = AF_UNIX;
    strncpy(addr.sun_path, SOCKET_PATH, sizeof(addr.sun_path) - 1);
    unlink(SOCKET_PATH);

    // Step 3: bind
    if (bind(server_fd, (struct sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind"); close(server_fd); return 1;
    }

    // Step 4: listen
    if (listen(server_fd, MAX_CLIENTS) < 0) {
        perror("listen"); close(server_fd); return 1;
    }
    printf("[Daemon] Listening on %s\n", SOCKET_PATH);

    // Step 5: main loop
    while (1) {
        int client_fd = accept(server_fd, NULL, NULL);
        if (client_fd < 0) {
            if (errno == EINTR) continue;   // retry on signal
            perror("accept"); continue;
        }

        // Step 6: read command
        char buffer[BUFFER_SIZE];
        memset(buffer, 0, sizeof(buffer));
        ssize_t n = read(client_fd, buffer, sizeof(buffer) - 1);
        if (n <= 0) { close(client_fd); continue; }
        buffer[n] = '\0';

        // Step 7: respond
        const char* response = process_command(buffer);
        write(client_fd, response, strlen(response));
        printf("[Daemon] %s → %s\n", buffer, response);

        // Step 8: close client
        close(client_fd);
    }

    close(server_fd);
    unlink(SOCKET_PATH);
    return 0;
}
```

### Client

```c
// my_client/main.c

#include <string.h>
#include <unistd.h>

int send_command(const char* command, char* response, size_t resp_size) {
    // Step 1: create socket
    int fd = socket(AF_UNIX, SOCK_STREAM, 0);
    if (fd < 0) { perror("socket"); return -1; }

    // Step 2: server address
    struct sockaddr_un addr;

    addr.sun_family = AF_UNIX;

    // Step 4: send
    write(fd, command, strlen(command));

    // Step 5: receive
    memset(response, 0, resp_size);
    ssize_t n = read(fd, response, resp_size - 1);

    // Step 6: close

    return 0;
}
```

## AOSP Prefers `android_get_control_socket()`

In real AOSP, daemons **don't call `socket()` + `bind()` themselves**. Instead:

1. `init.rc` declares the socket
2. `init` (running as root) creates `/dev/socket/<name>` at boot
3. The daemon calls `android_get_control_socket()` to retrieve the ready-made fd

```c
// In init.rc:
//   service my_daemon /system/bin/my_daemon
//       socket my_daemon stream 660 system system
//       ↑ init creates /dev/socket/my_daemon

// In the daemon:
#include <cutils/sockets.h>

int main() {
    // Get the fd init already created — no socket()/bind() needed
    int server_fd = android_get_control_socket("my_daemon");
    if (server_fd < 0) { ALOGE("Failed: %s", strerror(errno)); return 1; }

    listen(server_fd, 4);

    while (true) {
        int client_fd = accept(server_fd, NULL, NULL);
        // handle client...
        close(client_fd);
    }
}
```

**Why this approach?**

| Reason | Detail |
|--------|--------|
| Privilege separation | `init` runs as root; daemon can run as `system` or lower |
| Correct SELinux labels | `init` applies the right file context at creation time |
| Cleaner daemon code | No manual `socket()` / `bind()` / `unlink()` boilerplate |

---

## Summary

| Function | Purpose | AOSP Example |
|----------|---------|--------------|
| `socket()` | Create socket fd | `logd`, `vold`, `netd` create their listening sockets |
| `bind()` | Assign path/address | `installd` binds to `/dev/socket/installd` |
| `listen()` | Accept connections passively | `zygote` waits for fork requests from `system_server` |
| `accept()` | Dequeue next client | `logd` accepts each log-message sender |
| `connect()` | Connect to server | `rild` connects to the modem socket |
| `write()` / `send()` | Send data | `PackageManager` sends install commands to `installd` |
| `read()` / `recv()` | Receive data | `vold` reads mount commands from `StorageManagerService` |
| `close()` | Release the socket | Every daemon closes `client_fd` after handling each request |

> POSIX socket API is the **backbone of native IPC in AOSP**. Every native daemon uses these same eight functions — just wrapped in different helper libraries for convenience.
