# IPC in Android: Files Mechanism
### Complete In-Depth Guide

---

## 1. Overview

Inter-Process Communication (IPC) using Files means one process writes data to a file, and another process reads from that same file.

```
┌─────────────────────────────────────────────────────────┐
│                    ANDROID OS                           │
│                                                         │
│  ┌──────────────┐                ┌──────────────┐       │
│  │  Process A   │                │  Process B   │       │
│  │  (App 1)     │                │  (App 2)     │       │
│  │              │   WRITE        │              │       │
│  │  Writer ─────┼───────────┐    │              │       │
│  └──────────────┘           │    └──────┬───────┘       │
│                             ▼           │ READ          │
│                    ┌────────────────┐   │               │
│                    │  SHARED FILE   │◄──┘               │
│                    │  (on disk /    │                    │
│                    │   storage)     │                    │
│                    └────────────────┘                    │
└─────────────────────────────────────────────────────────┘
```

## 4. Mechanism 1: Internal Storage (Same App, Different Processes)

```
┌───────────────────────────────────────────────────────┐
│              SAME APPLICATION                         │
│              (android:process=":remote")              │
│                                                       │
│  ┌─────────────────┐     ┌─────────────────┐         │
│  │  Main Process    │     │  :remote Process │         │
│  │                  │     │                  │         │
│  │  Activity        │     │  Service         │         │
│  │    │ write()     │     │    ▲ read()      │         │
│  └────┬─────────────┘     └────┼─────────────┘         │
│       ▼                        │                       │
│  ┌─────────────────────────────┴──┐                    │
│  │  /data/data/com.example/       │                    │
│  │       files/ipc_data.txt       │                    │
│  └────────────────────────────────┘                    │
└───────────────────────────────────────────────────────┘
```

**AndroidManifest.xml**

```xml
<application>
```

**WriterActivity.java (Main Process)**

```java
public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        writeDataToFile("Hello from Main Process! PID: " + android.os.Process.myPid());
        startService(new Intent(this, RemoteService.class));
    }

    private void writeDataToFile(String data) {
        try {
            FileOutputStream fos = openFileOutput("ipc_data.txt", Context.MODE_PRIVATE);
            fos.write(data.getBytes());
            fos.flush();
            fos.close();
            Log.d("IPC_WRITER", "Data written: " + data);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

**RemoteService.java (Separate Process — `:remote`)**

```java
public class RemoteService extends Service {

    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        Log.d("IPC_READER", "Service PID: " + android.os.Process.myPid());
        Log.d("IPC_READER", "Data read: " + readDataFromFile());
        return START_NOT_STICKY;
    }

    private String readDataFromFile() {
        StringBuilder sb = new StringBuilder();
        try {
            FileInputStream fis = openFileInput("ipc_data.txt");
            BufferedReader reader = new BufferedReader(new InputStreamReader(fis));
            String line;
            while ((line = reader.readLine()) != null) sb.append(line);
            reader.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
        return sb.toString();
    }

    @Override public IBinder onBind(Intent intent) { return null; }
}
```

## 7. Mechanism 4: FileProvider (Secure Cross-App File Sharing)

```
┌────────────────────────────────────────────────────────────────┐
│                                                                │
│  ┌──────────────────┐  Intent (URI + flags)  ┌──────────────┐ │
│  │  APP A (Sender)   │──────────────────────►│ APP B        │ │
│  │  1. Create file   │                        │ 5. Receive   │ │
│  │  2. Get content:// │                       │ 6. Open URI  │ │
│  │     URI from      │                        │ 7. Read file │ │
│  │     FileProvider  │                        └──────────────┘ │
│  │  3. Grant URI perm│                                         │
│  │  4. Send Intent   │                                         │
│  └──────────────────┘                                         │
│                                                                │
│  content://com.example.app/shared_files/image.jpg             │
│                     │                                          │
│                     ▼                                          │
│             FileProvider (maps URI → actual path)             │
│                     │                                          │
│                     ▼                                          │
│  /data/data/com.example.app/files/shared/image.jpg            │
└────────────────────────────────────────────────────────────────┘
```

**Step 1: Configure FileProvider**

```xml
<!-- AndroidManifest.xml (Sender App) -->
<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="com.example.sender.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>
```

**Step 2: Define shared paths**

```xml
<!-- res/xml/file_paths.xml -->
<?xml version="1.0" encoding="utf-8"?>
<paths>
    <files-path        name="shared_files"   path="shared/" />
    <cache-path        name="shared_cache"   path="shared_cache/" />
    <external-files-path name="external_shared" path="shared/" />
</paths>
```

```
Path Mapping:
  <files-path>           → Context.getFilesDir()
  <cache-path>           → Context.getCacheDir()
  <external-path>        → Environment.getExternalStorageDir()
  <external-files-path>  → Context.getExternalFilesDir()
  <external-cache-path>  → Context.getExternalCacheDir()

Example:
  files-path name="shared_files" path="shared/"
  Actual: /data/data/com.example/files/shared/image.jpg
  URI:    content://com.example.sender.fileprovider/shared_files/image.jpg
```

**Step 3: Sender App**

```java
private void shareFileWithOtherApp() {
    try {
        File sharedDir = new File(getFilesDir(), "shared");
        if (!sharedDir.exists()) sharedDir.mkdirs();
        File sharedFile = new File(sharedDir, "data.txt");

        FileWriter writer = new FileWriter(sharedFile);
        writer.write("This is shared data!\n");
        writer.write("Timestamp: " + System.currentTimeMillis() + "\n");
        writer.write("From: " + getPackageName() + "\n");
        writer.close();

        // Get content:// URI
        Uri contentUri = FileProvider.getUriForFile(
                this, "com.example.sender.fileprovider", sharedFile);
        // → content://com.example.sender.fileprovider/shared_files/data.txt

        Intent shareIntent = new Intent(Intent.ACTION_SEND);
        shareIntent.setType("text/plain");
        shareIntent.putExtra(Intent.EXTRA_STREAM, contentUri);
        shareIntent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION);

        startActivity(Intent.createChooser(shareIntent, "Share file via"));
    } catch (IOException e) {
        e.printStackTrace();
    }
}

// Send to specific app
private void sendToSpecificApp() throws Exception {
    File sharedFile = new File(new File(getFilesDir(), "shared"), "data.txt");
    Uri contentUri = FileProvider.getUriForFile(
            this, "com.example.sender.fileprovider", sharedFile);

    Intent intent = new Intent(Intent.ACTION_VIEW);
    intent.setDataAndType(contentUri, "text/plain");
    intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION);

    grantUriPermission("com.example.receiver", contentUri,
            Intent.FLAG_GRANT_READ_URI_PERMISSION);
    intent.setPackage("com.example.receiver");
    startActivity(intent);
}
```

## 8. Mechanism 5: ParcelFileDescriptor (Pipe-based File IPC)

```
┌─────────────────────────────────────────────────────────────┐
│                 PIPE-BASED FILE IPC                          │
│                                                             │
│  ┌───────────────────┐  PIPE   ┌───────────────────┐        │
│  │  Writer Thread    │────────►│  Reader Thread    │        │
│  │  (Process A)      │         │  (Process B)      │        │
│  │  PFD[1] Write End │         │  PFD[0] Read End  │        │
│  └───────────────────┘         └───────────────────┘        │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │   OS KERNEL PIPE BUFFER (no actual file on disk!)    │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

```java
public void demonstratePipeIPC() {
    try {
        ParcelFileDescriptor[] pipe = ParcelFileDescriptor.createPipe();
        ParcelFileDescriptor readEnd  = pipe[0];
        ParcelFileDescriptor writeEnd = pipe[1];

        new Thread(() -> {
            try {
                FileOutputStream fos = new FileOutputStream(writeEnd.getFileDescriptor());
                fos.write(("Hello via Pipe IPC! PID: " + android.os.Process.myPid()).getBytes());
                fos.close();
                writeEnd.close();
            } catch (IOException e) { e.printStackTrace(); }
        }).start();

        new Thread(() -> {
            try {
                FileInputStream fis = new FileInputStream(readEnd.getFileDescriptor());
                byte[] buffer = new byte[1024];
                int bytesRead = fis.read(buffer);
                Log.d("PIPE_READER", "Read: " + new String(buffer, 0, bytesRead));
                fis.close();
                readEnd.close();
            } catch (IOException e) { e.printStackTrace(); }
        }).start();

    } catch (IOException e) {
        e.printStackTrace();
    }
}
```

**ParcelFileDescriptor with ContentProvider**

```java
public class PipeContentProvider extends ContentProvider {

    @Override
    public ParcelFileDescriptor openFile(Uri uri, String mode) throws FileNotFoundException {
        try {
            ParcelFileDescriptor[] pipe = ParcelFileDescriptor.createPipe();
            new TransferThread(pipe[1]).start();
            return pipe[0];  // Return read end to caller
        } catch (IOException e) {
            throw new FileNotFoundException("Could not create pipe");
        }
    }

    private class TransferThread extends Thread {
        private final ParcelFileDescriptor writeSide;

        TransferThread(ParcelFileDescriptor writeSide) { this.writeSide = writeSide; }

        @Override
        public void run() {
            try {
                FileOutputStream fos = new FileOutputStream(writeSide.getFileDescriptor());
                fos.write("{ \"status\": \"ok\", \"data\": [1,2,3] }".getBytes());
                fos.close();
                writeSide.close();
            } catch (IOException e) { e.printStackTrace(); }
        }
    }

    @Override public boolean onCreate() { return true; }
    @Override public String getType(Uri uri) { return "application/json"; }
    @Override public Cursor query(Uri u, String[] p, String s, String[] sa, String so) { return null; }
    @Override public Uri insert(Uri u, ContentValues v) { return null; }
    @Override public int delete(Uri u, String s, String[] sa) { return 0; }
    @Override public int update(Uri u, ContentValues v, String s, String[] sa) { return 0; }
}
```

```java
// Writer
public void writeUsingMemoryMap(Context context) {
    try {
        File file = new File(context.getExternalFilesDir(null), "mmap_ipc.dat");
        RandomAccessFile raf = new RandomAccessFile(file, "rw");
        raf.setLength(1024);

        MappedByteBuffer mappedBuffer = raf.getChannel().map(
                FileChannel.MapMode.READ_WRITE, 0, 1024);

        byte[] data = ("Memory-mapped IPC! Time: " + System.currentTimeMillis())
                .getBytes(StandardCharsets.UTF_8);
        mappedBuffer.putInt(data.length);
        mappedBuffer.put(data);
        mappedBuffer.force();  // Flush to disk
        raf.close();
    } catch (IOException e) { e.printStackTrace(); }
}

// Reader
public String readUsingMemoryMap(Context context) {
    try {
        File file = new File(context.getExternalFilesDir(null), "mmap_ipc.dat");
        if (!file.exists()) return "File not found";

        RandomAccessFile raf = new RandomAccessFile(file, "r");
        MappedByteBuffer mappedBuffer = raf.getChannel().map(
                FileChannel.MapMode.READ_ONLY, 0, 1024);

        int length = mappedBuffer.getInt();
        byte[] data = new byte[length];
        mappedBuffer.get(data);
        raf.close();

        return new String(data, StandardCharsets.UTF_8);
    } catch (IOException e) {
        return "Error: " + e.getMessage();
    }
}
```

## 10. Concurrency and Synchronization

```
RACE CONDITION SCENARIO:

  Time ──────────────────────────────────────────────►

  Process A:  WRITE["Hel"]  WRITE["lo"]
  Process B:       READ ──► Gets "Hel" only!  ← CORRUPT

  Expected: "Hello"
  Actual:   "Hel"  (partial read)
```

### Solution: File Locking

```java
public class ThreadSafeFileIPC {

    public void safeWrite(Context context, String data) {
        File file = new File(context.getFilesDir(), "ipc_data.json");
        try {
            RandomAccessFile raf = new RandomAccessFile(file, "rw");
            FileChannel channel = raf.getChannel();
            FileLock lock = channel.lock();  // EXCLUSIVE lock

            try {
                channel.truncate(0);
                channel.write(ByteBuffer.wrap(data.getBytes(StandardCharsets.UTF_8)));
                channel.force(true);
            } finally {
                lock.release();
                channel.close();
                raf.close();
            }
        } catch (IOException e) { e.printStackTrace(); }
    }

    public String safeRead(Context context) {
        File file = new File(context.getFilesDir(), "ipc_data.json");
        if (!file.exists()) return null;
        try {
            RandomAccessFile raf = new RandomAccessFile(file, "r");
            FileChannel channel = raf.getChannel();
            FileLock lock = channel.lock(0, Long.MAX_VALUE, true);  // SHARED lock

            try {
                ByteBuffer buffer = ByteBuffer.allocate((int) channel.size());
                channel.read(buffer);
                buffer.flip();
                return StandardCharsets.UTF_8.decode(buffer).toString();
            } finally {
                lock.release();
                channel.close();
                raf.close();
            }
        } catch (IOException e) {
            return null;
        }
    }
}
```

### Lock Types

```
EXCLUSIVE LOCK (Write Lock):
  Process A ── LOCK (exclusive) ──► Only A can access
  Process B ── BLOCKED ──────────► Waits until A unlocks
  Process C ── BLOCKED ──────────► Waits until A unlocks

SHARED LOCK (Read Lock):
  Process A ── LOCK (shared) ────► A can read
  Process B ── LOCK (shared) ────► B can read too!
  Process C ── WRITE attempt ───► BLOCKED (readers active)
```

**Storage Access Framework Example**

```java
public class SAFIPCActivity extends AppCompatActivity {

    private static final int REQUEST_CREATE_FILE = 1;
    private static final int REQUEST_OPEN_FILE   = 2;

    private void createSharedDocument() {
        Intent intent = new Intent(Intent.ACTION_CREATE_DOCUMENT);
        intent.addCategory(Intent.CATEGORY_OPENABLE);
        intent.setType("application/json");
        intent.putExtra(Intent.EXTRA_TITLE, "shared_ipc_data.json");
        startActivityForResult(intent, REQUEST_CREATE_FILE);
    }

    private void openSharedDocument() {
        Intent intent = new Intent(Intent.ACTION_OPEN_DOCUMENT);
        intent.addCategory(Intent.CATEGORY_OPENABLE);
        intent.setType("*/*");
        intent.putExtra(Intent.EXTRA_MIME_TYPES, new String[]{"application/json", "text/plain"});
        startActivityForResult(intent, REQUEST_OPEN_FILE);
    }

    @Override
    protected void onActivityResult(int requestCode, int resultCode, Intent data) {
        super.onActivityResult(requestCode, resultCode, data);
        if (resultCode != RESULT_OK || data == null) return;

        Uri uri = data.getData();

        switch (requestCode) {
            case REQUEST_CREATE_FILE:
                writeToUri(uri);
                getContentResolver().takePersistableUriPermission(uri,
                        Intent.FLAG_GRANT_READ_URI_PERMISSION |
                        Intent.FLAG_GRANT_WRITE_URI_PERMISSION);
                break;
            case REQUEST_OPEN_FILE:
                readFromUri(uri);
                getContentResolver().takePersistableUriPermission(uri,
                        Intent.FLAG_GRANT_READ_URI_PERMISSION);
                break;
        }
    }

    private void writeToUri(Uri uri) {
        try {
            OutputStream os = getContentResolver().openOutputStream(uri);
            if (os != null) {
                JSONObject json = new JSONObject();
                json.put("sender", getPackageName());
                json.put("message", "IPC via Storage Access Framework");
                json.put("timestamp", System.currentTimeMillis());
                os.write(json.toString(2).getBytes());
                os.close();
            }
        } catch (Exception e) { e.printStackTrace(); }
    }

    private void readFromUri(Uri uri) {
        try {
            InputStream is = getContentResolver().openInputStream(uri);
            if (is != null) {
                BufferedReader reader = new BufferedReader(new InputStreamReader(is));
                StringBuilder sb = new StringBuilder();
                String line;
                while ((line = reader.readLine()) != null) sb.append(line);
                reader.close();
                JSONObject json = new JSONObject(sb.toString());
                Log.d("SAF_IPC", "Read: " + json.toString(2));
            }
        } catch (Exception e) { e.printStackTrace(); }
    }
}
```

```java
public class FileObserverIPC {

    private FileObserver fileObserver;

    public void startWatching(Context context) {
        String watchPath = new File(context.getFilesDir(), "ipc_data.txt").getAbsolutePath();

        fileObserver = new FileObserver(watchPath,
                FileObserver.MODIFY | FileObserver.CREATE | FileObserver.CLOSE_WRITE) {

            @Override
            public void onEvent(int event, @Nullable String path) {
                if (event == FileObserver.CLOSE_WRITE || event == FileObserver.MODIFY) {
                    readUpdatedContent(watchPath);
                }
            }
        };

        fileObserver.startWatching();
    }

    private void readUpdatedContent(String filePath) {
        try {
            BufferedReader reader = new BufferedReader(new FileReader(filePath));
            StringBuilder sb = new StringBuilder();
            String line;
            while ((line = reader.readLine()) != null) sb.append(line).append("\n");
            reader.close();
            Log.d("FILE_OBSERVER", "New content: " + sb.toString());
        } catch (IOException e) { e.printStackTrace(); }
    }

    public void stopWatching() {
        if (fileObserver != null) fileObserver.stopWatching();
    }
}
```

```java
public class FileChatManager {

    private final Context context;
    private final String appName;
    private final File chatFile;
    private FileObserver observer;
    private OnMessageReceivedListener listener;

    public interface OnMessageReceivedListener {
        void onNewMessage(String sender, String text, long timestamp);
    }

    public FileChatManager(Context context, String appName) {
        this.context  = context;
        this.appName  = appName;
        File chatDir = new File(
                Environment.getExternalStoragePublicDirectory(
                        Environment.DIRECTORY_DOCUMENTS), "chat");
        if (!chatDir.exists()) chatDir.mkdirs();
        this.chatFile = new File(chatDir, "messages.json");
    }

    public synchronized void sendMessage(String text) {
        try {
            RandomAccessFile raf = new RandomAccessFile(chatFile, "rw");
            FileChannel channel = raf.getChannel();
            FileLock lock = channel.lock();

            try {
                JSONObject root;
                JSONArray messages;

                if (chatFile.length() > 0) {
                    byte[] existing = new byte[(int) chatFile.length()];
                    raf.readFully(existing);
                    root     = new JSONObject(new String(existing));
                    messages = root.getJSONArray("messages");
                } else {
                    root     = new JSONObject();
                    messages = new JSONArray();
                }

                JSONObject newMessage = new JSONObject();
                newMessage.put("sender", appName);
                newMessage.put("text", text);
                newMessage.put("timestamp", System.currentTimeMillis());
                messages.put(newMessage);
                root.put("messages", messages);

                channel.truncate(0);
                channel.position(0);
                channel.write(ByteBuffer.wrap(root.toString(2).getBytes(StandardCharsets.UTF_8)));
                channel.force(true);
            } finally {
                lock.release();
                channel.close();
                raf.close();
            }
        } catch (Exception e) { e.printStackTrace(); }
    }

    public void startListening(OnMessageReceivedListener listener) {
        this.listener = listener;

        observer = new FileObserver(chatFile.getParentFile().getAbsolutePath(),
                FileObserver.CLOSE_WRITE) {

            private int lastMessageCount = 0;

            @Override
            public void onEvent(int event, @Nullable String path) {
                if ("messages.json".equals(path)) checkForNewMessages();
            }

            private void checkForNewMessages() {
                try {
                    RandomAccessFile raf = new RandomAccessFile(chatFile, "r");
                    FileChannel channel = raf.getChannel();
                    FileLock lock = channel.lock(0, Long.MAX_VALUE, true);

                    try {
                        byte[] data = new byte[(int) chatFile.length()];
                        raf.readFully(data);
                        JSONArray messages = new JSONObject(new String(data))
                                .getJSONArray("messages");

                        for (int i = lastMessageCount; i < messages.length(); i++) {
                            JSONObject msg = messages.getJSONObject(i);
                            String sender  = msg.getString("sender");
                            if (!sender.equals(appName) && listener != null) {
                                listener.onNewMessage(sender,
                                        msg.getString("text"), msg.getLong("timestamp"));
                            }
                        }
                        lastMessageCount = messages.length();
                    } finally {
                        lock.release();
                        channel.close();
                        raf.close();
                    }
                } catch (Exception e) { e.printStackTrace(); }
            }
        };
        observer.startWatching();
    }

    public void stopListening() {
        if (observer != null) observer.stopWatching();
    }
}
```

## 15. Advantages and Disadvantages

**Advantages ✓**
- Simple to implement
- Can share large amounts of data
- Data persists across app restarts
- Works with any format (JSON, XML, binary)
- No AIDL or Binder complexity
- FileProvider is secure and well-supported
- Good for sharing media files

**Disadvantages ✗**
- Slower than in-memory IPC (Binder, Messenger)
- Race conditions without proper locking
- No built-in notification (need FileObserver or polling)
- External storage is insecure
- Scoped Storage (Android 10+) restricts access
- Not suitable for real-time communication
- File I/O can fail (disk full, permissions)
- Complex synchronization for concurrent access
- No type safety (raw bytes)

---

## 16. Best Practices

```
1. 🔒 Always use FileProvider for cross-app file sharing
   (Never use MODE_WORLD_READABLE/WRITABLE)

2. 🔐 Use FileLock for concurrent access
   (Prevents race conditions and data corruption)

3. 📁 Prefer internal storage for sensitive data
   (External storage readable by all apps on <Android 10)

4. 🧹 Clean up temporary files
   (Use cache directory for temp files)

5. 🔄 Use atomic operations
   (Write to temp file, then rename)

6. 📱 Handle Scoped Storage for Android 10+
   (Use MediaStore or SAF)

7. ⚡ Perform file I/O on background threads
   (Never on main/UI thread)

8. 🔍 Validate data after reading
   (File might be corrupted or tampered with)
```

**Atomic Write Pattern**

```java
public void atomicWrite(File targetFile, String data) throws IOException {
    File tempFile = new File(targetFile.getParent(), targetFile.getName() + ".tmp");

    FileWriter writer = new FileWriter(tempFile);
    writer.write(data);
    writer.flush();
    writer.close();

    // Atomic rename — either succeeds completely or fails
    if (!tempFile.renameTo(targetFile))
        throw new IOException("Failed to rename temp file");
}
```
