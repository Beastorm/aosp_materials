## 1. What are Signals?

Signals are **software interrupts** sent to a process to notify it of an event — a core IPC mechanism in Linux/Android.

```
┌──────────────────┐          Signal           ┌──────────────────┐
│   Process A       │ ────────────────────────► │   Process B       │
│  (or Kernel)      │      (e.g. SIGKILL)       │   (recipient)     │
└──────────────────┘                            └──────────────────┘
```

### Signal Lifecycle

```
Signal Generated ──► Signal Delivered ──► Signal Handled
       │                    │                   │
       ▼                    ▼                   ▼
  by kernel,          pending until         default action,
  another process,    process is ready      ignore, or
  or self                                   custom handler
```

## 2. Signal Basics

### Three Ways to Handle a Signal

```c
signal(SIGTERM, SIG_DFL);   // 1. DEFAULT — let the system handle it
signal(SIGINT,  SIG_IGN);   // 2. IGNORE  — discard the signal
signal(SIGINT,  my_handler); // 3. CUSTOM  — run your own handler
```

### Minimal Example

```c
#include <stdio.h>
#include <signal.h>
#include <unistd.h>

void my_handler(int signum) {
    printf("Caught signal %d (SIGINT)\n", signum);
}

int main() {
    signal(SIGINT, my_handler);   // Register handler for Ctrl+C

    printf("Running... Press Ctrl+C\n");
    while (1) {
        sleep(1);
        printf("Working...\n");
    }
    return 0;
}
```

```
Running... Press Ctrl+C
Working...
Working...
^C Caught signal 2 (SIGINT)    ← Ctrl+C pressed
Working...
```

## 3. Common Signals in AOSP

| Signal | # | Default Action | Usage in AOSP |
|--------|---|---------------|---------------|
| `SIGHUP` | 1 | Terminate | Reload configuration |
| `SIGINT` | 2 | Terminate | Ctrl+C interrupt |
| `SIGQUIT` | 3 | Core dump | ANR dump (AMS) |
| `SIGABRT` | 6 | Core dump | `abort()` / native crash |
| `SIGBUS` | 7 | Core dump | Bus error |
| `SIGKILL` | 9 | Terminate | Force kill (lmkd, AMS) — **uncatchable** |
| `SIGSEGV` | 11 | Core dump | Segfault / null pointer |
| `SIGPIPE` | 13 | Terminate | Broken pipe |
| `SIGALRM` | 14 | Terminate | Timer alarm |
| `SIGTERM` | 15 | Terminate | Graceful termination |
| `SIGSTKFLT` | 16 | Terminate | Used by ART GC |
| `SIGCHLD` | 17 | Ignore | Child process died (init / zygote) |
| `SIGCONT` | 18 | Continue | Resume frozen process |
| `SIGSTOP` | 19 | Stop | Freeze process |

### AOSP Signal Map

```
SIGKILL  (9)  ◄── ActivityManagerService  (OOM kill)
SIGKILL  (9)  ◄── lmkd                   (low memory kill)
SIGQUIT  (3)  ◄── AMS                    (ANR — dump traces)
SIGABRT  (6)  ◄── native crash           → debuggerd
SIGSEGV (11)  ◄── null pointer           → debuggerd
SIGCHLD (17)  ◄── init                   (reap zombie processes)
SIGSTOP (19)  ◄── Freezer cgroup         (freeze)
SIGCONT (18)  ◄── Freezer cgroup         (thaw)
```

## 4. Signal Handling Mechanisms

### 4.1 `signal()` — Simple but Deprecated

```c
#include <signal.h>

void handler(int sig) { /* handle signal */ }

int main() {
    signal(SIGTERM, handler);
}
```

### 4.2 `sigaction()` — Recommended (used throughout AOSP)

```c
#include <signal.h>
#include <string.h>

void handler(int sig, siginfo_t *info, void *context) {
    // sig     = signal number
    // info    = detailed info (sender PID, fault address, etc.)
    // context = CPU registers at time of signal
    printf("Signal %d from PID %d\n", sig, info->si_pid);
    printf("Fault address: %p\n", info->si_addr);   // useful for SIGSEGV
}

int main() {
    struct sigaction sa;
    memset(&sa, 0, sizeof(sa));

    sa.sa_sigaction = handler;
    sa.sa_flags     = SA_SIGINFO;       // enable 3-arg handler + siginfo_t
    sigemptyset(&sa.sa_mask);           // don't block other signals

    sigaction(SIGSEGV, &sa, NULL);
    sigaction(SIGABRT, &sa, NULL);

    int *ptr = NULL;
    *ptr = 42;  // triggers SIGSEGV
    return 0;
}
```

### 4.3 `signal()` vs `sigaction()` Comparison

| Feature | `signal()` | `sigaction()` |
|---------|-----------|--------------|
| API complexity | Simple | Verbose but precise |
| Portability | Not portable | POSIX standard |
| Handler lifetime | Resets after each call | Persists |
| Extra fault info | ❌ None | ✅ `siginfo_t` |
| Signal masking | ❌ No | ✅ Yes |
| Thread safety | ❌ Race conditions | ✅ Safe |
| Used in AOSP | Rarely | ★ Everywhere |

### 4.4 Signal Masks — Blocking Signals

```c
#include <signal.h>

void block_signals_example() {
    sigset_t mask, old_mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGINT);
    sigaddset(&mask, SIGTERM);

    sigprocmask(SIG_BLOCK, &mask, &old_mask);  // block; save old mask

    // ── Critical section ──────────────────────────────────────
    // SIGINT and SIGTERM are blocked here → become PENDING
    printf("Doing critical work...\n");
    sleep(5);
    // ─────────────────────────────────────────────────────────

    sigprocmask(SIG_SETMASK, &old_mask, NULL); // restore → pending signals delivered now
}
```

### 4.5 Dedicated Signal Handler Thread (Pattern used in ART)

```c
#include <signal.h>
#include <pthread.h>

void* signal_handler_thread(void* arg) {
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGQUIT);

    while (1) {
        int sig;
        sigwait(&mask, &sig);                  // blocks until SIGQUIT arrives
        printf("Thread received signal %d\n", sig);
        // → dump stack traces (like ART does for ANR)
    }
    return NULL;
}

int main() {
    // Block SIGQUIT in all threads first
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGQUIT);
    pthread_sigmask(SIG_BLOCK, &mask, NULL);

    // Only the dedicated thread will handle it via sigwait()
    pthread_t thread;
    pthread_create(&thread, NULL, signal_handler_thread, NULL);

    while (1) sleep(1);
    return 0;
}
```

## 5. AOSP-Specific Signal Usage

### 5.1 ANR Detection — `SIGQUIT` (Signal 3)

When an ANR occurs, AMS sends `SIGQUIT` to the target process to dump thread stacks.

```
┌──────────────┐  SIGQUIT(3)  ┌───────────────────────────┐
│     AMS      │ ───────────► │       App Process          │
│ (system_     │              │                            │
│  server)     │              │  SignalCatcher thread      │
│              │              │  → dumps all thread stacks │
│              │              │  → writes to /data/anr/    │
└──────────────┘              └───────────────────────────┘
```

**AMS side — `ProcessList.java`:**

```java
// frameworks/base/services/core/java/com/android/server/am/ProcessList.java
public static void sendSignalQuiet(int pid, int signal) {
    Process.sendSignal(pid, Process.SIGNAL_QUIT);  // SIGNAL_QUIT = 3
}
```

**ART side — `signal_catcher.cc`:**

```cpp
// art/runtime/signal_catcher.cc
void* SignalCatcher::Run(void* arg) {
    SignalCatcher* signal_catcher = reinterpret_cast<SignalCatcher*>(arg);

    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGQUIT);

    while (true) {
        int signal_number;
        sigwait(&mask, &signal_number);          // blocks until SIGQUIT

        if (signal_number == SIGQUIT) {
            signal_catcher->HandleSigQuit();     // dump to /data/anr/traces.txt
        }
    }
}

void SignalCatcher::HandleSigQuit() {
    Runtime* runtime = Runtime::Current();
    std::ostringstream os;
    runtime->GetThreadList()->Dump(os);          // all thread stacks
    // written to /data/anr/traces.txt
}
```

### 5.2 Native Crash Handling — `SIGSEGV`, `SIGABRT`, `SIGBUS`, `SIGFPE`

```
┌─────────────┐  SIGSEGV / SIGABRT  ┌──────────────────────┐
│ App Process  │ ──────────────────► │     debuggerd         │
│ (Bionic      │                     │                      │
│  handler)    │                     │  generates:          │
│              │                     │  ├── tombstone file  │
│              │                     │  ├── stack backtrace │
│              │                     │  └── logcat output   │
└─────────────┘                     └──────────────────────┘
```

**Bionic crash handler setup — `linker_debuggerd_android.cpp`:**

```cpp
// bionic/linker/linker_debuggerd_android.cpp
static void debuggerd_init() {
    struct sigaction action;
    memset(&action, 0, sizeof(action));

    sigfillset(&action.sa_mask);                        // block all signals during handler
    action.sa_sigaction = debuggerd_signal_handler;
    action.sa_flags = SA_SIGINFO                        // provide siginfo_t
                    | SA_ONSTACK                        // use alternate stack
                    | SA_NODEFER;                       // allow nested signals

    sigaction(SIGABRT, &action, &old_actions[SIGABRT]);
    sigaction(SIGBUS,  &action, &old_actions[SIGBUS]);
    sigaction(SIGFPE,  &action, &old_actions[SIGFPE]);
    sigaction(SIGSEGV, &action, &old_actions[SIGSEGV]);
    sigaction(SIGTRAP, &action, &old_actions[SIGTRAP]);
}
```

**The signal handler — `debuggerd_handler.cpp`:**

```cpp
// bionic/debuggerd/handler/debuggerd_handler.cpp
static void debuggerd_signal_handler(int signal_number,
                                     siginfo_t* info,
                                     void* context) {
    pid_t tid = gettid();
    pid_t pid = getpid();

    // 1. Log the crash (async-signal-safe)
    async_safe_format_log(ANDROID_LOG_FATAL, "libc",
        "Fatal signal %d (%s), code %d, fault addr %p in tid %d, pid %d",
        signal_number, get_signame(signal_number),
        info->si_code, info->si_addr, tid, pid);

    // 2. Connect to crash_dump via socket
    int pipe_fd = connect_to_crash_dump();

    // 3. Send crash info
    CrashInfo crash_info = { .pid = pid, .tid = tid,
                              .signo = signal_number, .siginfo = *info };
    write(pipe_fd, &crash_info, sizeof(crash_info));

    // 4. Wait for crash_dump to generate tombstone + backtrace
    wait_for_crash_dump(pipe_fd);

    // 5. Re-raise with default handler → process dies
    signal(signal_number, SIG_DFL);
    raise(signal_number);
}
```

### 5.3 init Process — `SIGCHLD` Handling

`init` is PID 1; it must reap all dead child processes using `signalfd` + `epoll`:

```cpp
// system/core/init/init.cpp
static void InstallSignalFdHandler(Epoll* epoll) {
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGCHLD);

    sigprocmask(SIG_BLOCK, &mask, nullptr);        // block normal delivery

    // signalfd converts signals into readable fd events
    signal_fd = signalfd(-1, &mask, SFD_CLOEXEC);

    epoll->RegisterHandler(signal_fd, HandleSignalFd);
}

static void HandleSignalFd() {
    signalfd_siginfo siginfo;
    read(signal_fd, &siginfo, sizeof(siginfo));

    if (siginfo.ssi_signo == SIGCHLD) {
        ReapAnyOutstandingChildren();
    }
}

void ReapAnyOutstandingChildren() {
    while (true) {
        int status;
        pid_t pid = waitpid(-1, &status, WNOHANG);  // non-blocking
        if (pid <= 0) break;

        auto service = ServiceList::GetInstance().FindService(pid);
        if (service) {
            LOG(INFO) << "Service '" << service->name()
                      << "' (pid " << pid << ") died";
            service->Reap(siginfo);                  // restart if configured
        }
    }
}
```

### 5.6 ART Runtime — `SIGSEGV` for Implicit Null Checks

ART **deliberately omits null checks** in compiled code and converts the resulting `SIGSEGV` into a Java `NullPointerException`:

```cpp
// art/runtime/fault_handler.cc
class FaultManager {
public:
    void Init() {
        struct sigaction action;
        action.sa_sigaction = art_fault_handler;
        action.sa_flags = SA_SIGINFO | SA_ONSTACK;
        sigfillset(&action.sa_mask);
        sigaction(SIGSEGV, &action, &old_action_);
    }

    static void art_fault_handler(int sig, siginfo_t* info, void* context) {
        FaultManager* manager = GetFaultManager();

        if (manager->HandleNullCheck(info, context)) {
            // Modify context's return address → throw NullPointerException
            return;   // resume execution at Java exception handler
        }

        if (manager->HandleStackOverflow(info, context)) {
            // Convert to StackOverflowError
            return;
        }

        // Not ours — chain to debuggerd
        old_action_.sa_sigaction(sig, info, context);
    }
};
```

**SIGSEGV flow inside ART:**

```
Java: obj.method()  (obj == null)
       │
       ▼
Compiled native: LOAD [x0, #0]   (x0 = 0x0)
       │
       ▼
CPU: "Memory access violation!"
       │
       ▼
Kernel sends SIGSEGV
       │
       ▼
┌─── ART fault_handler ────────────┐
│                                  │
│  Is this an implicit null check? │
│                                  │
├── YES ───────────────────────────┤
│  Modify return address in context│
│  → NullPointerException in Java  │
│                                  │
├── NO ────────────────────────────┤
│  Chain to debuggerd              │
│  → Tombstone + crash             │
└──────────────────────────────────┘
```

### Example 1 — Native Crash Simulation

```cpp
// test_crash.cpp — simulates what Bionic/debuggerd does on a crash

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <string.h>

void crash_handler(int sig, siginfo_t* info, void* context) {
    const char* sig_name;
    switch (sig) {
        case SIGSEGV: sig_name = "SIGSEGV"; break;
        case SIGABRT: sig_name = "SIGABRT"; break;
        case SIGBUS:  sig_name = "SIGBUS";  break;
        case SIGFPE:  sig_name = "SIGFPE";  break;
        default:      sig_name = "UNKNOWN"; break;
    }

    char buf[256];
    int len = snprintf(buf, sizeof(buf),
        "\n*** FATAL SIGNAL ***\n"
        "Signal   : %d (%s)\n"
        "Code     : %d\n"
        "Fault addr: %p\n"
        "PID: %d  TID: %d\n",
        sig, sig_name, info->si_code, info->si_addr,
        getpid(), gettid());
    write(STDERR_FILENO, buf, len);

    // Re-raise with default to terminate
    signal(sig, SIG_DFL);
    raise(sig);
}

void setup_crash_handlers() {
    struct sigaction sa;
    memset(&sa, 0, sizeof(sa));
    sa.sa_sigaction = crash_handler;
    sa.sa_flags = SA_SIGINFO | SA_ONSTACK;
    sigfillset(&sa.sa_mask);

    sigaction(SIGSEGV, &sa, NULL);
    sigaction(SIGABRT, &sa, NULL);
    sigaction(SIGBUS,  &sa, NULL);
    sigaction(SIGFPE,  &sa, NULL);
}

int main() {
    setup_crash_handlers();
    printf("Causing a null pointer dereference...\n");
    int* ptr = NULL;
    *ptr = 42;   // → SIGSEGV
    return 0;
}
```

### Example 2 — ANR-Style SignalCatcher Thread

```cpp
// signal_catcher_demo.cpp — simulates ART's SignalCatcher thread

#include <stdio.h>
#include <signal.h>
#include <pthread.h>
#include <unistd.h>
#include <execinfo.h>

static volatile bool running = true;

void* signal_catcher_thread(void* arg) {
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGQUIT);

    printf("[SignalCatcher] Thread started (tid=%d)\n", gettid());

    while (running) {
        int sig;
        if (sigwait(&mask, &sig) == 0 && sig == SIGQUIT) {
            printf("\n[SignalCatcher] SIGQUIT received — dumping traces\n");
            printf("────────────────────────────────────────\n");

            void* buffer[30];
            int nframes = backtrace(buffer, 30);
            char** symbols = backtrace_symbols(buffer, nframes);
            for (int i = 0; i < nframes; i++)
                printf("  #%02d %s\n", i, symbols[i]);
            free(symbols);

            printf("────────────────────────────────────────\n\n");
        }
    }
    return NULL;
}

void* worker_thread(void* arg) {
    int id = *(int*)arg;
    printf("[Worker %d] Started (tid=%d)\n", id, gettid());
    while (running) sleep(1);
    return NULL;
}

int main() {
    // Block SIGQUIT in all threads
    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGQUIT);
    pthread_sigmask(SIG_BLOCK, &mask, NULL);

    // Only the catcher thread handles SIGQUIT via sigwait()
    pthread_t catcher;
    pthread_create(&catcher, NULL, signal_catcher_thread, NULL);

    pthread_t workers[3];
    int ids[] = {1, 2, 3};
    for (int i = 0; i < 3; i++)
        pthread_create(&workers[i], NULL, worker_thread, &ids[i]);

    printf("\n[Main] PID=%d — trigger with: kill -3 %d\n\n", getpid(), getpid());

    for (int i = 0; i < 30; i++) sleep(1);
    running = false;
    return 0;
}
```

### Example 3 — `init`-Style `SIGCHLD` with `signalfd` + `epoll`

```cpp
// init_sigchld_demo.cpp — simulates Android init's service supervisor

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <sys/signalfd.h>
#include <sys/wait.h>
#include <sys/epoll.h>
#include <stdlib.h>

struct Service {
    const char* name;
    pid_t       pid;
    bool        should_restart;
};

Service services[] = {
    {"surfaceflinger",  -1, true},
    {"audioserver",     -1, true},
    {"one-shot-service",-1, false},
};

void start_service(Service* svc) {
    pid_t pid = fork();
    if (pid == 0) {
        printf("[%s] Started (pid=%d)\n", svc->name, getpid());
        sleep(2 + rand() % 3);
        printf("[%s] Exiting\n", svc->name);
        exit(0);
    }
    svc->pid = pid;
    printf("[init] Launched '%s' → pid %d\n", svc->name, pid);
}

void handle_sigchld(int signal_fd) {
    struct signalfd_siginfo siginfo;
    read(signal_fd, &siginfo, sizeof(siginfo));

    while (true) {
        int status;
        pid_t pid = waitpid(-1, &status, WNOHANG);
        if (pid <= 0) break;

        for (auto& svc : services) {
            if (svc.pid != pid) continue;

            printf("[init] '%s' (pid %d) died", svc.name, pid);
            if (WIFEXITED(status))   printf(" — exit code %d", WEXITSTATUS(status));
            if (WIFSIGNALED(status)) printf(" — signal %d",    WTERMSIG(status));
            printf("\n");

            svc.pid = -1;
            if (svc.should_restart) {
                printf("[init] Restarting '%s'\n", svc.name);
                start_service(&svc);
            }
            break;
        }
    }
}

int main() {
    printf("[init] Simulator started (pid=%d)\n\n", getpid());

    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGCHLD);
    sigprocmask(SIG_BLOCK, &mask, NULL);

    int signal_fd = signalfd(-1, &mask, SFD_CLOEXEC);
    int epoll_fd  = epoll_create1(EPOLL_CLOEXEC);

    struct epoll_event ev = { .events = EPOLLIN, .data.fd = signal_fd };
    epoll_ctl(epoll_fd, EPOLL_CTL_ADD, signal_fd, &ev);

    for (auto& svc : services) start_service(&svc);
    printf("\n[init] Entering main loop...\n\n");

    struct epoll_event events[10];
    for (int round = 0; round < 20; round++) {
        int nfds = epoll_wait(epoll_fd, events, 10, 1000);
        for (int i = 0; i < nfds; i++)
            if (events[i].data.fd == signal_fd)
                handle_sigchld(signal_fd);
    }

    close(signal_fd);
    close(epoll_fd);
    return 0;
}
```

[init] Launched 'one-shot-service' → pid 1003

## 7. Debuggerd & Crash Handling Flow

```
NATIVE CRASH — END-TO-END
──────────────────────────────────────────────────────────────

  1.  Fault occurs (e.g. null pointer dereference)
       │
  2.  CPU generates hardware exception
       │
  3.  Kernel delivers SIGSEGV to the process
       │
  4.  Bionic's debuggerd_signal_handler runs
       ├──► Logs "Fatal signal 11 (SIGSEGV)..." to logcat
       ├──► Forks crash_dump64 process
       └──► Waits for crash_dump to complete
                │
  5.  crash_dump process:
       ├──► ptrace(ATTACH) to crashed process
       ├──► Reads registers, memory, maps
       ├──► Unwinds stack  (libunwindstack)
       ├──► Writes tombstone  (/data/tombstones/tombstone_XX)
       ├──► Logs backtrace to logcat
       └──► Notifies AMS via socket
                │
  6.  AMS receives crash notification:
       ├──► Shows "App has stopped" dialog
       ├──► Writes to DropBox
       └──► Broadcasts ACTION_APP_ERROR
                │
  7.  Signal handler re-raises with SIG_DFL → process terminates
```

## 8. Bionic's Signal Implementation

### 8.1 Alternate Signal Stack

Every thread gets a **separate signal stack**. Without it, a stack-overflow `SIGSEGV` handler would run on the already-overflowed stack and crash again.

```cpp
// bionic/libc/bionic/pthread_create.cpp
static void __init_alternate_signal_stack(pthread_internal_t* thread) {
    void* stack = mmap(NULL, SIGNAL_STACK_SIZE,
                       PROT_READ | PROT_WRITE,
                       MAP_PRIVATE | MAP_ANONYMOUS, -1, 0);

    stack_t ss = { .ss_sp = stack, .ss_size = SIGNAL_STACK_SIZE, .ss_flags = 0 };
    sigaltstack(&ss, NULL);                   // tell kernel to use this for handlers

    thread->alternate_signal_stack = stack;
}
```

### 8.2 Async-Signal-Safe Functions

Inside a signal handler only **async-signal-safe** functions may be called:

| ✅ Safe to call | ❌ Not safe (will deadlock / corrupt) |
|----------------|--------------------------------------|
| `write()` | `printf()` — uses malloc + locks |
| `_exit()` | `malloc()` / `free()` — internal locks |
| `signal()`, `sigaction()` | `syslog()` — uses stdio |
| `kill()`, `getpid()`, `gettid()` | `pthread_*()` — thread locks |

> AOSP uses `async_safe_format_log()` instead of `printf` / `ALOG` inside handlers:
>
> ```cpp
> // bionic/libc/async_safe/async_safe_log.cpp
> // Lock-free, writes directly to /dev/kmsg or logd socket
> async_safe_format_log(ANDROID_LOG_FATAL, "libc", "Fatal signal %d...", sig);
> ```

## 1. What is Signal-Based IPC?

| IPC Method | Use Case |
|------------|----------|
| Binder | Rich data, method calls |
| Socket | Stream data, local comms |
| Pipe | Parent-child data |
| Shared Memory | Large data sharing |
| ★ **Signals** | **Simple notifications / events** |

### Signal IPC Properties

| Property | Value |
|----------|-------|
| Direction | One-way (no return value) |
| Timing | Asynchronous (sender doesn't wait) |
| Overhead | Lightweight (just a number) |
| Payload | None by default (use `sigqueue()` for a small int) |

## 2. Basic Signal IPC Between Processes

```
Process A                     Process B
   │                              │
   │  kill(pid_B, SIGUSR1)        │
   │────────────────────────────► │
   │                              │
   │  (continues immediately)     │  handler runs
   │                              │  "Got notification!"
```

### Receiver (Process B)

```c
// process_b.c
#include <stdio.h>
#include <signal.h>
#include <unistd.h>

void notification_handler(int sig) {
    write(STDOUT_FILENO, "Process B: Got notification!\n", 29);
}

int main() {
    struct sigaction sa = {0};
    sa.sa_handler = notification_handler;
    sigaction(SIGUSR1, &sa, NULL);

    printf("Process B started. PID = %d\n", getpid());
    printf("Waiting for signals...\n");

    while (1) pause();   // sleep until any signal arrives
    return 0;
}
```

### Sender (Process A)

```c
// process_a.c
#include <stdio.h>
#include <signal.h>
#include <stdlib.h>

int main(int argc, char* argv[]) {
    if (argc < 2) { printf("Usage: %s <pid>\n", argv[0]); return 1; }

    pid_t target_pid = atoi(argv[1]);
    printf("Process A: Sending SIGUSR1 to PID %d\n", target_pid);

    int result = kill(target_pid, SIGUSR1);   // ← the IPC

    if (result == 0) printf("Process A: Signal sent!\n");
    else             perror("kill failed");

    return 0;
}
```

## 3. Signal IPC with Data — `sigqueue()`

Regular `kill()` carries no payload. `sigqueue()` attaches a small integer or pointer.

```
Process A                                  Process B
   │                                           │
   │  sigqueue(pid, SIGUSR1, {.sival_int=42})  │
   │─────────────────────────────────────────► │
   │                                           │
   │                              handler(sig, siginfo_t* info, ...)
   │                              info->si_value.sival_int == 42
```

```c
// sigqueue_demo.c

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>

// ── RECEIVER ──────────────────────────────────────────────────

void data_handler(int sig, siginfo_t* info, void* context) {
    char buf[128];
    int len = snprintf(buf, sizeof(buf),
        "Receiver: signal %d, data = %d (from PID %d)\n",
        sig,
        info->si_value.sival_int,   // ← the data
        info->si_pid);              // ← who sent it
    write(STDOUT_FILENO, buf, len);
}

void receiver() {
    struct sigaction sa;
    memset(&sa, 0, sizeof(sa));
    sa.sa_sigaction = data_handler;
    sa.sa_flags = SA_SIGINFO;       // ← required to get siginfo_t
    sigaction(SIGUSR1, &sa, NULL);

    printf("Receiver PID = %d\n", getpid());
    for (int i = 0; i < 10; i++) pause();
}

// ── SENDER ────────────────────────────────────────────────────

void sender(pid_t target_pid) {
    sleep(1);   // let receiver start

    for (int i = 1; i <= 5; i++) {
        union sigval value;
        value.sival_int = i * 10;   // payload: 10, 20, 30, 40, 50

        printf("Sender: sending signal with data = %d\n", value.sival_int);
        sigqueue(target_pid, SIGUSR1, value);
        usleep(100000);
    }
}

int main() {
    pid_t pid = fork();
    if (pid == 0) {
        receiver();
    } else {
        sender(pid);
        int status;
        waitpid(pid, &status, 0);
    }
    return 0;
}
```

**Output:**

```
Receiver PID = 1235
Sender: sending signal with data = 10
Receiver: signal 10, data = 10 (from PID 1234)
Sender: sending signal with data = 20
Receiver: signal 10, data = 20 (from PID 1234)
...
```

    sigset_t mask;
    sigemptyset(&mask);
    sigaddset(&mask, SIGQUIT);

### 4.2 lmkd → App Process — Memory Pressure via `SIGKILL`

```
┌──────────────────────────────────────────────────────────────┐
│                 Memory Pressure IPC Flow                     │
│                                                              │
│   Kernel               lmkd               App Process       │
│     │                    │                     │            │
│     │  memory pressure!  │                     │            │
│     │───────────────────►│                     │            │
│     │                    │  pick victim        │            │
│     │                    │  (highest oom_adj)  │            │
│     │                    │                     │            │
│     │                    │  kill(pid, SIGKILL)─►│           │
│     │                    │                     │ ← dies     │
│     │   memory freed!    │                     │            │
│     │◄───────────────────│                     │            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

```cpp
// lmkd_simulation.cpp

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <stdlib.h>
#include <string.h>
#include <sys/wait.h>
#include <vector>

struct ProcessInfo {
    pid_t  pid;
    char   name[64];
    int    oom_adj;       // higher = kill first
    long   memory_kb;
};

std::vector<ProcessInfo> process_list;

// ── LMKD ──────────────────────────────────────────────────────

class LMKD {
public:
    void register_process(pid_t pid, const char* name,
                          int oom_adj, long mem_kb) {
        ProcessInfo info = { pid, {}, oom_adj, mem_kb };
        strncpy(info.name, name, sizeof(info.name));
        process_list.push_back(info);
        printf("[lmkd] Registered: %s (pid=%d, oom_adj=%d, mem=%ldKB)\n",
               name, pid, oom_adj, mem_kb);
    }

    void handle_memory_pressure(int level) {
        printf("\n[lmkd] ⚠  Memory pressure level %d!\n", level);

        ProcessInfo* victim = find_victim();
        if (victim) kill_process(victim);
    }

private:
    ProcessInfo* find_victim() {
        ProcessInfo* best = nullptr;
        int highest_adj = -1000;
        for (auto& p : process_list) {
            if (p.oom_adj > highest_adj && p.pid > 0) {
                highest_adj = p.oom_adj;
                best = &p;
            }
        }
        return best;
    }

    void kill_process(ProcessInfo* p) {
        printf("[lmkd] Victim: %s (pid=%d, oom_adj=%d, mem=%ldKB)\n",
               p->name, p->pid, p->oom_adj, p->memory_kb);

        // ← SIGNAL IPC — SIGKILL cannot be caught or ignored
        int ret = kill(p->pid, SIGKILL);

        if (ret == 0) {
            waitpid(p->pid, NULL, 0);
            printf("[lmkd] ✓ PID %d killed — memory freed\n", p->pid);
            p->pid = -1;
        }
    }
};

// ── APP SIDE ──────────────────────────────────────────────────

void simulate_app(const char* name, int oom_adj) {
    // SIGTERM can be caught; SIGKILL cannot
    signal(SIGTERM, [](int) {
        write(STDOUT_FILENO, "[App] SIGTERM: cleaning up...\n", 30);
        _exit(0);
    });
    printf("[%s pid=%d] Started (oom_adj=%d)\n", name, getpid(), oom_adj);
    while (1) sleep(1);
}

int main() {
    printf("══════════════════════════════\n");
    printf("   LMKD Signal IPC Simulation\n");
    printf("══════════════════════════════\n\n");

    LMKD lmkd;

    struct { const char* name; int oom_adj; long mem_kb; } apps[] = {
        {"com.android.launcher3",  0,   50000},
        {"com.google.maps",       200, 150000},
        {"com.instagram",         600, 200000},
        {"com.old.game",          900, 300000},
    };

    for (auto& app : apps) {
        pid_t pid = fork();
        if (pid == 0) { simulate_app(app.name, app.oom_adj); exit(0); }
        lmkd.register_process(pid, app.name, app.oom_adj, app.mem_kb);
    }

    sleep(2);
    lmkd.handle_memory_pressure(1);  // kills com.old.game
    sleep(2);
    lmkd.handle_memory_pressure(2);  // kills com.instagram

    printf("\n[lmkd] Memory pressure resolved\n");
    for (auto& p : process_list) if (p.pid > 0) kill(p.pid, SIGKILL);
    while (waitpid(-1, NULL, WNOHANG) > 0);
    return 0;
}
```

    };

public:
    int signal_fd, epoll_fd;

    void setup() {
        sigset_t mask;
        sigemptyset(&mask);
        sigaddset(&mask, SIGCHLD);
        sigprocmask(SIG_BLOCK, &mask, NULL);

        signal_fd = signalfd(-1, &mask, SFD_CLOEXEC);
        epoll_fd  = epoll_create1(EPOLL_CLOEXEC);

        struct epoll_event ev = { .events = EPOLLIN, .data.fd = signal_fd };
        epoll_ctl(epoll_fd, EPOLL_CTL_ADD, signal_fd, &ev);
    }

    void start_service(Service* svc) {
        pid_t pid = fork();
        if (pid == 0) { svc->entry(); exit(1); }
        svc->pid = pid;
        printf("[init] ✓ Started '%s' (pid=%d)\n", svc->name, pid);
    }

    void start_all() { for (auto& svc : services) start_service(&svc); }

    void reload_config(const char* name) {
        for (auto& svc : services) {
            if (strcmp(svc.name, name) == 0 && svc.pid > 0) {
                printf("[init] SIGHUP → '%s' (pid=%d)\n", svc.name, svc.pid);
                kill(svc.pid, SIGHUP);          // ← Signal IPC
            }
        }
    }

    void stop_service(const char* name) {
        for (auto& svc : services) {
            if (strcmp(svc.name, name) != 0 || svc.pid <= 0) continue;

            printf("[init] SIGTERM → '%s'\n", svc.name);
            kill(svc.pid, SIGTERM);             // ← Signal IPC #1

            for (int i = 0; i < 5; i++) {
                sleep(1);
                if (kill(svc.pid, 0) == -1) {
                    printf("[init] '%s' stopped gracefully\n", svc.name);
                    svc.pid = -1;
                    svc.restart_on_death = false;
                    return;
                }
            }

            printf("[init] SIGTERM ignored — SIGKILL → '%s'\n", svc.name);
            kill(svc.pid, SIGKILL);             // ← Signal IPC #2
            svc.pid = -1; svc.restart_on_death = false;
        }
    }

    void handle_child_deaths() {
        struct signalfd_siginfo sinfo;
        read(signal_fd, &sinfo, sizeof(sinfo));

        while (true) {
            int status;
            pid_t pid = waitpid(-1, &status, WNOHANG);
            if (pid <= 0) break;

            for (auto& svc : services) {
                if (svc.pid != pid) continue;
                printf("[init] '%s' (pid=%d) died", svc.name, pid);
                if (WIFEXITED(status))   printf(" — exit %d\n",   WEXITSTATUS(status));
                if (WIFSIGNALED(status)) printf(" — signal %d\n", WTERMSIG(status));
                svc.pid = -1;
                if (svc.restart_on_death) {
                    printf("[init] Restarting '%s'\n", svc.name);
                    sleep(1);
                    start_service(&svc);
                }
            }
        }
    }
};

int main() {
    printf("═══════════════════════════════════\n");
    printf("  init Service Lifecycle Simulation\n");
    printf("═══════════════════════════════════\n\n");

    ServiceManager mgr;
    mgr.setup();
    mgr.start_all();
    sleep(2);

    printf("\n[init] Property 'audio.policy' changed\n");
    mgr.reload_config("audioserver");
    sleep(1);

    printf("\n[init] Display config changed\n");
    mgr.reload_config("surfaceflinger");
    sleep(2);

    printf("\n[init] Stopping audioserver for update\n");
    mgr.stop_service("audioserver");

    // Run epoll loop to observe SIGCHLD + auto-restart
    for (int i = 0; i < 50; i++) {
        struct epoll_event events[10];
        int nfds = epoll_wait(mgr.epoll_fd, events, 10, 100);
        for (int j = 0; j < nfds; j++)
            if (events[j].data.fd == mgr.signal_fd)
                mgr.handle_child_deaths();
    }

    printf("\n[init] Shutting down\n");
    return 0;
}
```

## 5. Signal IPC Patterns

### Pattern 1 — Bidirectional (Request / Response)

```
Process A              Process B
   │                       │
   │  SIGUSR1 (request) ──►│
   │                       │  (processes request)
   │◄── SIGUSR2 (done) ────│
```

```c
// bidirectional_signal_ipc.c

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <sys/wait.h>

volatile int response_received = 0;
volatile int request_received  = 0;

void on_sigusr1(int sig) { request_received  = 1; }
void on_sigusr2(int sig) { response_received = 1; }

void process_a(pid_t b_pid) {
    signal(SIGUSR2, on_sigusr2);

    printf("[A] Sending request to B (PID=%d)\n", b_pid);
    kill(b_pid, SIGUSR1);                   // ← Signal IPC: request

    printf("[A] Waiting for response...\n");
    while (!response_received) pause();

    printf("[A] ✓ Got response!\n");
}

void process_b(pid_t a_pid) {
    signal(SIGUSR1, on_sigusr1);

    printf("[B] Waiting for request from A\n");
    while (!request_received) pause();

    printf("[B] Processing...\n");
    sleep(1);

    printf("[B] Sending response to A\n");
    kill(a_pid, SIGUSR2);                   // ← Signal IPC: response
}

int main() {
    pid_t parent_pid = getpid();
    pid_t child_pid  = fork();

    if (child_pid == 0) { process_b(parent_pid); }
    else { sleep(1); process_a(child_pid); waitpid(child_pid, NULL, 0); }
    return 0;
}
```

### Pattern 2 — Signal as Semaphore (Synchronization)

```c
// signal_semaphore.c

#include <stdio.h>
#include <signal.h>
#include <unistd.h>

volatile int ready_flag = 0;

void on_ready(int sig) { ready_flag = 1; }

int main() {
    pid_t parent_pid = getpid();
    signal(SIGUSR1, on_ready);

    pid_t child = fork();
    if (child == 0) {
        printf("[Child] Initializing...\n");
        sleep(2);
        printf("[Child] Ready — signaling parent\n");
        kill(parent_pid, SIGUSR1);          // ← "I'm ready" IPC
        while (1) sleep(1);
    } else {
        printf("[Parent] Waiting for child...\n");
        while (!ready_flag) pause();
        printf("[Parent] ✓ Child ready — starting work\n");
        kill(child, SIGKILL);
    }
    return 0;
}

### Pattern 3 — Broadcast to Process Group

```c
// broadcast_signal.c

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <sys/wait.h>

void child_handler(int sig) {
    char buf[64];
    int len = snprintf(buf, sizeof(buf),
        "[Child pid=%d] Received broadcast!\n", getpid());
    write(STDOUT_FILENO, buf, len);
}

int main() {
    setpgrp();
    pid_t pgid = getpgrp();
    printf("[Parent] Process group: %d\n", pgid);

    for (int i = 0; i < 4; i++) {
        if (fork() == 0) {
            signal(SIGUSR1, child_handler);
            printf("[Child %d pid=%d] Ready\n", i, getpid());
            pause();
            exit(0);
        }
    }

    sleep(1);
    printf("\n[Parent] Broadcasting SIGUSR1 to all children\n\n");
    kill(-pgid, SIGUSR1);   // ← negative pgid = broadcast to group

    sleep(1);
    while (waitpid(-1, NULL, WNOHANG) > 0);
    return 0;
}

## 6. Zygote ↔ App Process Signal IPC

```
┌──────────────────────────────────────────────────────────────┐
│                    Zygote Signal IPC                         │
│                                                              │
│   Zygote                      Forked App Process            │
│    │                                 │                       │
│    │  fork() ───────────────────────►│  app starts          │
│    │                                 │                       │
│    │◄──────────────────────────────── SIGCHLD (app died)    │
│    │                                 │                       │
│    │  waitpid(pid)                   │                       │
│    │  → notify AMS via socket        │                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

```cpp
// zygote_signal_ipc.cpp

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <sys/wait.h>
#include <map>
#include <string>

std::map<pid_t, std::string> forked_apps;
int ams_pipe[2];

void sigchld_handler(int) {
    char byte = 1;
    write(ams_pipe[1], &byte, 1);   // wake up main loop (async-signal-safe)
}

class ZygoteServer {
public:
    void setup() {
        pipe(ams_pipe);

        struct sigaction sa = {0};
        sa.sa_handler = sigchld_handler;
        sa.sa_flags   = SA_NOCLDSTOP;   // only on death, not stop
        sigaction(SIGCHLD, &sa, NULL);

        printf("[Zygote] Ready (PID=%d)\n", getpid());
    }

    pid_t fork_app(const char* package_name) {
        pid_t pid = fork();
        if (pid == 0) {
            printf("[%s pid=%d] App started\n", package_name, getpid());
            sleep(1 + rand() % 3);
            printf("[%s pid=%d] App exiting\n", package_name, getpid());
            exit(0);
        }
        forked_apps[pid] = package_name;
        printf("[Zygote] Forked '%s' → pid=%d\n", package_name, pid);
        return pid;
    }

    void run_event_loop() {
        printf("\n[Zygote] Event loop running\n\n");
        fd_set fds;
        while (true) {
            FD_ZERO(&fds);
            FD_SET(ams_pipe[0], &fds);
            select(ams_pipe[0] + 1, &fds, NULL, NULL, NULL);

            char byte;
            read(ams_pipe[0], &byte, 1);
            handle_child_deaths();
        }
    }

private:
    void handle_child_deaths() {
        while (true) {
            int status;
            pid_t pid = waitpid(-1, &status, WNOHANG);
            if (pid <= 0) break;

            auto it = forked_apps.find(pid);
            if (it == forked_apps.end()) continue;

            printf("[Zygote] App died: %s (pid=%d)", it->second.c_str(), pid);
            if (WIFEXITED(status))   printf(" — exit %d",   WEXITSTATUS(status));
            if (WIFSIGNALED(status)) printf(" — signal %d", WTERMSIG(status));
            printf("\n[Zygote] → Notified AMS\n\n");

            forked_apps.erase(it);
        }
    }
};

int main() {
    printf("════════════════════════════════\n");
    printf("   Zygote Signal IPC Simulation\n");
    printf("════════════════════════════════\n\n");

    ZygoteServer zygote;
    zygote.setup();
    zygote.fork_app("com.google.maps");
    zygote.fork_app("com.instagram");
    zygote.fork_app("com.whatsapp");

    alarm(10);
    signal(SIGALRM, [](int) { exit(0); });
    zygote.run_event_loop();
    return 0;
}
```

## 7. Complete Signal IPC Reference

### Sending APIs

```c
// ── 1. kill() — send to process or group ──────────────────────
kill(pid, sig);     // specific process
kill(-pgid, sig);   // broadcast to entire process group
kill(0, sig);       // send to own process group
kill(-1, sig);      // send to ALL processes (dangerous!)

// ── 2. tgkill() — target a specific thread ────────────────────
tgkill(pid, tid, sig);

// ── 3. sigqueue() — send with data payload ────────────────────
union sigval val;
val.sival_int = 42;
sigqueue(pid, SIGUSR1, val);

// ── 4. raise() — send to yourself ─────────────────────────────
raise(SIGABRT);     // equivalent to kill(getpid(), SIGABRT)

// ── 5. alarm() — timer-triggered signal to yourself ───────────
alarm(5);           // sends SIGALRM to self in 5 seconds
```

### AOSP Quick Reference

| From | Signal | To / Purpose |
|------|--------|-------------|
| AMS | `SIGQUIT` (3) | App → "Dump ANR traces" |
| AMS | `SIGKILL` (9) | App → "Force stop" |
| lmkd | `SIGKILL` (9) | App → "OOM kill" |
| init | `SIGHUP` (1) | Service → "Reload config" |
| init | `SIGTERM` (15) | Service → "Stop gracefully" |
| init | `SIGKILL` (9) | Service → "Force stop" |
| App crash | `SIGSEGV` (11) | → debuggerd: native crash |
| App crash | `SIGABRT` (6) | → debuggerd: `abort()` called |
| Zygote | `SIGCHLD` (17) | → self: "An app died" |
| init | `SIGCHLD` (17) | → self: "A service died" |
| Freezer | `SIGSTOP` (19) | App → "Freeze" |
| Freezer | `SIGCONT` (18) | App → "Resume" |

### When to Use Signal IPC vs Others

| Use Signals when… | Use Binder when… | Use Sockets when… |
|-------------------|-----------------|------------------|
| Simple notifications (start/stop/reload) | Method calls with return values | Stream data |
| Process lifecycle events | Rich structured data exchange | Long-lived connections |
| Emergency / out-of-band events | Synchronous request-response | `property_service`, `debuggerd` |
| Target process may be deadlocked | Most Android framework IPC | init ↔ services |
| Cross-privilege (AMS→app, init→svc) | | |

# 🔔 SIGUSR1 — Complete Guide

---

## What is SIGUSR1?

| Property | Value |
|----------|-------|
| Signal number | `10` |
| Full name | User Defined Signal 1 |
| Default action | **Terminate** the process |
| Can be caught? | ✅ Yes |
| Can be ignored? | ✅ Yes |
| Predefined meaning? | ❌ None — **you decide** |

### Analogy

```
Think of signals like doorbells:

SIGKILL  = Fire alarm   → Must evacuate (can't ignore)
SIGTERM  = Doorbell     → Someone wants you to leave
SIGSEGV  = Smoke alarm  → Something went wrong

SIGUSR1  = Custom bell  → YOU decide what it means!
           ├── "Reload your config!"
           ├── "Print your status!"
           ├── "Start doing something!"
           └── "Wake up!"

SIGUSR2  = Second custom bell (same idea, different signal)
```

### Why Do We Need It?

All other signals have fixed meanings (`SIGKILL` = always kill, `SIGSEGV` = always segfault, etc.).
`SIGUSR1` and `SIGUSR2` are **reserved for you** — no predefined meaning means total freedom.

## Example 5 — Process-to-Process IPC

```
Parent tells child "start" via SIGUSR1.
Child tells parent "done" via SIGUSR2.
```

```c
// ipc_example.c

#include <stdio.h>
#include <signal.h>
#include <unistd.h>
#include <sys/wait.h>

volatile int start_signal = 0;   // child watches
volatile int done_signal  = 0;   // parent watches

void child_handler(int sig)  { start_signal = 1; }
void parent_handler(int sig) { done_signal  = 1; }

void process_a(pid_t b_pid) {
    signal(SIGUSR2, parent_handler);

    printf("[A] Sending start signal to B (pid=%d)\n", b_pid);
    kill(b_pid, SIGUSR1);               // ← Signal IPC: request

    printf("[A] Waiting for response...\n");
    while (!done_signal) pause();

    printf("[A] ✓ Got SIGUSR2 — B is done!\n");
}

void process_b(pid_t a_pid) {
    signal(SIGUSR1, child_handler);

    printf("[B] Waiting for SIGUSR1 from A\n");
    while (!start_signal) pause();

    printf("[B] Got SIGUSR1! Working...\n");
    sleep(2);
    printf("[B] Done — sending SIGUSR2 to A\n");
    kill(a_pid, SIGUSR2);               // ← Signal IPC: response
}

int main() {
    pid_t parent_pid = getpid();
    pid_t child_pid  = fork();

    if (child_pid == 0) {
        process_b(parent_pid);
    } else {
        sleep(1);
        process_a(child_pid);
        waitpid(child_pid, NULL, 0);
    }
    return 0;
}
```

[A] Sending start signal to B (pid=1235)
[A] Waiting for response...
[B] Got SIGUSR1! Working...
[B] Done — sending SIGUSR2 to A
[A] ✓ Got SIGUSR2 — B is done!
```

## AOSP Usage — ART Force GC

```
Purpose: Force Garbage Collection in an app process

Who sends:  debugging tools / adb
Who gets:   app process (ART runtime)

adb shell kill -10 <app_pid>
                │
                ▼
         App Process (ART)
         receives SIGUSR1
         → forces GC to run immediately
         → useful for memory debugging
```

```cpp
// Simplified ART SIGUSR1 handler — art/runtime/runtime.cc

void Runtime::InitSignalChain() {
    struct sigaction sa;
    sa.sa_handler = [](int sig) {
        Runtime::Current()->GetHeap()->CollectGarbage(false);
    };
    sigaction(SIGUSR1, &sa, NULL);
}
```

```bash
# Force GC in a running app:
$ adb shell ps | grep com.example.app
$ adb shell kill -10 <pid>
```

## Summary

| Point | Detail |
|-------|--------|
| Signal number | `10` (`SIGUSR2` = `12`) |
| Meaning | None built-in — you define it |
| Default action | **Terminate** (must register handler before use!) |
| Common uses | Reload config · Print status · Toggle debug · Custom IPC |
| AOSP / ART use | `SIGUSR1` → force GC · `SIGUSR2` → Simpleperf stack sampling |

> **One-line summary:** SIGUSR1 is a "blank check" signal — no built-in meaning, total freedom to use as a lightweight custom notification channel between processes.
