# Semaphore IPC in Android

## What is a Semaphore?

A **Semaphore** is a synchronization mechanism that controls access to shared resources using a simple counter.

> **Analogy:** Like a parking lot — the counter = available spots. A car (thread) can enter only if spots are available. Entering decrements the counter; leaving increments it.

---

## Core Concepts

### Types of Semaphores

```
┌─────────────────────────────────────────────────────┐
│                  SEMAPHORE TYPES                     │
├─────────────────────┬───────────────────────────────┤
│   Binary Semaphore  │   Counting Semaphore           │
│   (Counter: 0 or 1) │   (Counter: 0 to N)            │
│                     │                               │
│   Like a bathroom   │   Like a parking lot           │
│   with 1 key        │   with N spots                 │
│                     │                               │
│   Only 1 thread     │   Up to N threads              │
│   at a time         │   at a time                    │
└─────────────────────┴───────────────────────────────┘
```

### Two Fundamental Operations

```
acquire() / P() / wait()
  if (counter > 0) → counter--  → proceed
  else             → BLOCK & wait

release() / V() / signal()
  counter++  → wake up a waiting thread
```

## How Semaphore Works — Visual Flow

### Binary Semaphore (Permits = 1)

```
Initial: Semaphore(1)  Counter = 1

Thread A: acquire() → Counter=1 → Counter > 0? YES → Counter=0 → ✅ ENTERS
Thread B: acquire() → Counter=0 → Counter > 0? NO  → 🚫 BLOCKED 💤
Thread A: release() → Counter=0 → Counter++ → Counter=1 → 🔔 Wake Thread B!
Thread B: (wakes) → Counter=1 → Counter-- → Counter=0 → ✅ ENTERS
```

### Counting Semaphore (Permits = 3)

```
Semaphore(3) — Swimming pool with 3 lanes

Time  Counter  Action
────  ───────  ───────────────────────────
t0      3      Initial state
t1      2      Thread A acquires ✅ 🏊
t2      1      Thread B acquires ✅ 🏊
t3      0      Thread C acquires ✅ 🏊
t4      0      Thread D tries → BLOCKED 🚫💤
t5      0      Thread E tries → BLOCKED 🚫💤
t6      1      Thread A releases → Thread D wakes up!
t7      0      Thread D acquires ✅ 🏊
```

## Implementation in Android

### 1. Basic Binary Semaphore

```java
import java.util.concurrent.Semaphore;

public class SharedPrinter {
    private final Semaphore semaphore = new Semaphore(1);

    public void printDocument(String document, String threadName) {
        try {
            System.out.println(threadName + " → Waiting for printer...");
            semaphore.acquire();  // 🔒 Lock
            System.out.println(threadName + " → PRINTING: " + document);
            Thread.sleep(2000);
            System.out.println(threadName + " → Done printing!");
        } catch (InterruptedException e) {
            e.printStackTrace();
        } finally {
            semaphore.release();  // 🔓 Unlock
        }
    }
}
```

```
Output Timeline:
Thread-1 → PRINTING: Report.pdf   ← Only Thread-1 uses printer
Thread-1 → Done printing!
Thread-2 → PRINTING: Invoice.pdf  ← Now Thread-2 gets access
Thread-3 → PRINTING: Photo.jpg    ← Finally Thread-3
```

### 3. Producer-Consumer Pattern

```java
public class ProducerConsumerExample {

    private final Queue<String> buffer = new LinkedList<>();
    private static final int BUFFER_SIZE = 5;

    private final Semaphore emptySlots  = new Semaphore(BUFFER_SIZE); // empty slots
    private final Semaphore filledSlots = new Semaphore(0);           // filled slots
    private final Semaphore mutex       = new Semaphore(1);           // buffer lock

    public void produce(String item) throws InterruptedException {
        emptySlots.acquire();   // Wait for empty slot
        mutex.acquire();        // Lock buffer
        buffer.add(item);
        mutex.release();        // Unlock buffer
        filledSlots.release();  // Signal: new item available
    }

    public String consume() throws InterruptedException {
        filledSlots.acquire();  // Wait for filled slot
        mutex.acquire();        // Lock buffer
        String item = buffer.poll();
        mutex.release();        // Unlock buffer
        emptySlots.release();   // Signal: new empty slot
        return item;
    }
}
```

```
Semaphore States:
Time    emptySlots   filledSlots   Buffer Content
────    ──────────   ───────────   ──────────────
t0         5             0         []
t1         4             1         [A]
t2         3             2         [A,B]
t3         2             3         [A,B,C]
t4(eat)    3             2         [B,C]
t5         2             3         [B,C,D]
```

### 4. API Rate Limiter

```java
public class ApiRateLimiter {

    private final Semaphore apiSemaphore = new Semaphore(5);
    private final OkHttpClient client    = new OkHttpClient();

    public void makeApiCall(String url, ApiCallback callback) {
        new Thread(() -> {
            try {
                if (apiSemaphore.tryAcquire(10, TimeUnit.SECONDS)) {
                    try {
                        Response response = client.newCall(
                                new Request.Builder().url(url).build()).execute();
                        callback.onSuccess(response.body().string());
                    } finally {
                        apiSemaphore.release();
                    }
                } else {
                    callback.onError("Too many requests. Try again later.");
                }
            } catch (Exception e) {
                apiSemaphore.release();
                callback.onError(e.getMessage());
            }
        }).start();
    }
}
```

```java
        });
    }
```

## Semaphore in Android IPC (Between Processes)

```
┌─────────────────────────────────────────────────────────────┐
│                     ANDROID IPC WITH SEMAPHORE              │
│                                                             │
│  ┌──────────────┐         Shared           ┌──────────────┐│
│  │   Process A   │        Memory           │   Process B   ││
│  │  Producer ────────→  Buffer/Counter  ←──── Consumer    ││
│  │  sem acquire/release              sem acquire/release   ││
│  └──────────────┘                          └──────────────┘│
│                                                             │
│  At Native Level (NDK):                                     │
│  sem_open() / sem_wait() / sem_post()  (POSIX named sems)  │
└─────────────────────────────────────────────────────────────┘
```

```c
// Process A (Producer)
#include <semaphore.h>
#include <fcntl.h>

sem_t *sem = sem_open("/my_semaphore", O_CREAT, 0644, 1);

sem_wait(sem);  // acquire
// ... write to shared memory ...
sem_post(sem);  // release

sem_close(sem);
sem_unlink("/my_semaphore");
```

```c
// Process B (Consumer)
sem_t *sem = sem_open("/my_semaphore", 0);  // Open existing

sem_wait(sem);  // acquire
// ... read from shared memory ...
sem_post(sem);  // release

sem_close(sem);
```

## Real-World Use Cases

### Bluetooth Connection Manager

```java
public class BluetoothConnectionManager {
    private final Semaphore btSemaphore = new Semaphore(7); // max 7 BT connections

    public BluetoothSocket connect(BluetoothDevice device)
            throws InterruptedException, IOException {
        btSemaphore.acquire();
        try {
            BluetoothSocket socket = device.createRfcommSocketToServiceRecord(MY_UUID);
            socket.connect();
            return socket;
        } catch (IOException e) {
            btSemaphore.release();
            throw e;
        }
    }

    public void disconnect(BluetoothSocket socket) throws IOException {
        try { socket.close(); }
        finally { btSemaphore.release(); }
    }
}
```

### Camera Frame Processing Pipeline

```java
public class CameraFrameProcessor {

    private final Semaphore frameSemaphore = new Semaphore(2);
    private final ExecutorService processingPool = Executors.newFixedThreadPool(4);

    public void onFrameReceived(byte[] frameData) {
        if (frameSemaphore.tryAcquire()) {  // Non-blocking!
            processingPool.submit(() -> {
                try   { detectFaces(frameData); }
                finally { frameSemaphore.release(); }
            });
        } else {
            Log.d("CAM", "Frame dropped — processing busy");
        }
    }
}
```


## Common Pitfalls & Best Practices

```
❌ DEADLOCK: Forgetting to release
  semaphore.acquire();
  doWork();           // throws exception!
  semaphore.release();  // NEVER REACHED → Deadlock!

✅ FIX: Always use try-finally
  semaphore.acquire();
  try   { doWork(); }
  finally { semaphore.release(); }  // Always runs ✅

❌ OVER-RELEASE: Releasing more than acquiring
   Counter goes above initial value → too many threads!

❌ STARVATION: Unfair semaphore
✅ FIX: new Semaphore(n, true)  // fair=true, FIFO order

❌ Using on Main Thread → ANR!
✅ FIX: Always use semaphore on background threads
```

# When to Use and When NOT to Use Semaphores

## ✅ When to Use

### 1. Resource Pool Management

```java
// ✅ GOOD: DB connection pool
private final Semaphore connectionPool = new Semaphore(3);

public void queryDatabase() throws InterruptedException {
    connectionPool.acquire();
    try   { /* use DB connection */ }
    finally { connectionPool.release(); }
}
```

### 2. Rate Limiting / Throttling

```
WITHOUT Semaphore: 100 requests hit server simultaneously 💥 → CRASH
WITH Semaphore(5): 5 pass ✅, 95 wait 💤 → Server stays alive 🟢
```

### 3. Producer-Consumer Pattern

```
emptySlots = Semaphore(5)  ← controls producer
filledSlots = Semaphore(0) ← controls consumer
Both work TOGETHER to sync perfectly ✅
```

### 4. Signaling Between Threads

```java
// ✅ GOOD: Thread A signals Thread B
Semaphore signal = new Semaphore(0);  // Start at 0!

new Thread(() -> { downloadFile(); signal.release(); }).start();  // Thread A
new Thread(() -> { signal.acquire(); displayFile(); }).start();   // Thread B waits for A
```

### 5. Non-blocking Try with Timeout

```java
// ✅ GOOD: Non-blocking with fallback
if (semaphore.tryAcquire(2, TimeUnit.SECONDS)) {
    try   { callApi(); }
    finally { semaphore.release(); }
} else {
    showCachedData();  // fallback
}
```

## ❌ When NOT to Use

### ❌ 1. Simple Mutual Exclusion

```java
// ❌ BAD: Semaphore(1) overkill for a counter
Semaphore sem = new Semaphore(1);
sem.acquire();
counter++;
sem.release();

// ✅ GOOD:
synchronized(lock) { counter++; }
// OR: AtomicInteger counter = new AtomicInteger();
//     counter.incrementAndGet();
```

### ❌ 2. Unrelated Processes (anonymous pipe)

```
App A (Package 1)    pipe fd[0]=3    App B (Package 2)
→ Anonymous pipe is IMPOSSIBLE across unrelated apps
✅ USE INSTEAD: Named Pipe, Socket, Binder
```

### ❌ 3. Bidirectional Communication (deadlock risk)

```
A writes to pipe1 (full, blocks)
B writes to pipe2 (full, blocks)
Both waiting → DEADLOCK! 💀
✅ USE INSTEAD: Binder (AIDL), Socket
```

### ❌ 4. Complex Condition-Based Waiting

```java
// ❌ BAD: Semaphore can't express complex conditions
semaphore.acquire();  // only knows: counter > 0 or not

// ✅ GOOD:
synchronized(lock) {
    while (list.isEmpty() || list.size() <= 5 || hasError)
        lock.wait();
    process(list);
}
```

### ❌ 5. Read-Write Lock Scenarios

```java
// ❌ BAD: Semaphore(1) makes ALL readers wait
// ✅ GOOD:
ReadWriteLock rwLock = new ReentrantReadWriteLock();

rwLock.readLock().lock();   // Multiple readers simultaneously ✅
try   { readConfig(); }
finally { rwLock.readLock().unlock(); }

rwLock.writeLock().lock();  // Only 1 writer, blocks readers
try   { writeConfig(); }
finally { rwLock.writeLock().unlock(); }
```

### ❌ 6. Android Main Thread (UI Thread)

```java
// ❌ NEVER DO THIS → ANR!
button.setOnClickListener(v -> {
    semaphore.acquire();  // 💥 BLOCKS UI THREAD
    doNetworkCall();
});

// ✅ ALWAYS DO THIS
button.setOnClickListener(v -> {
    executor.submit(() -> {
        semaphore.acquire();
        try   { doNetworkCall(); runOnUiThread(() -> updateUI()); }
        finally { semaphore.release(); }
    });
});
```

### ❌ 7. Reentrant (Same Thread, Multiple acquires)

```java
// ❌ BAD: Recursive deadlock!
void processNode(Node n) {
    sem.acquire();         // counter=0
    processNode(n.child);  // CALLS ITSELF
        sem.acquire();     // 💀 DEADLOCK! counter=0, blocks forever

// ✅ GOOD:
ReentrantLock lock = new ReentrantLock();
void processNode(Node n) {
    lock.lock();           // hold count=1
    processNode(n.child);
        lock.lock();       // ✅ Same thread! hold count=2
        lock.unlock();     // hold count=1
    lock.unlock();         // hold count=0
}
```

### ❌ 8. Modern Coroutine World

```kotlin
// ❌ OLD WAY
val sem = Semaphore(0)
Thread { result = fetchData(); sem.release() }.start()
sem.acquire()  // blocking wait

// ✅ MODERN WAY
viewModelScope.launch {
    val result = withContext(Dispatchers.IO) { fetchData() }
    useResult(result)
}
```

```
│  JAVA                    │  C++ POSIX       │  C++20         │
```

### Named Semaphore (True IPC — C++ Only)

```cpp
// C++ POSIX — visible to other processes ✅
sem_t *sem = sem_open(
    "/my_semaphore",   // lives in /dev/shm/
    O_CREAT,
    0644,              // rw-r--r--
    1                  // initial value
);

// Process B opens same semaphore:
sem_t *sem = sem_open("/my_semaphore", 0);  // just open
```

```
Named Semaphore Visibility:
  /dev/shm/my_semaphore ← POSIX named semaphore

  Process A ──sem_open()──► /dev/shm/my_sem ◄──sem_open()── Process B
  Process A ──sem_wait()──► counter         ◄──sem_wait()── Process B
  Process A ──sem_post()──►                 ◄──sem_post()── Process B

  JAVA: ❌ Cannot do this natively
  C++:  ✅ Native support
```

```
│ Release/Post │ sem.release()     │ sem_post(&s)     │ s.release()    │
│ Try (no wait)│ sem.tryAcquire()  │ sem_trywait(&s)  │ s.try_acquire()│
│ Try+timeout  │ sem.tryAcquire(   │ sem_timedwait    │ s.try_acquire_ │
│              │  n, TimeUnit.X)   │ (&s, &time)      │  for(duration) │
│ Get count    │ sem.available     │ sem_getvalue     │ ❌ None        │
│              │  Permits()        │ (&s, &val)       │                │
│ Destroy      │ GC handles it ✅  │ sem_destroy() ⚠️  │ RAII auto ✅   │
└──────────────┴───────────────────┴──────────────────┴────────────────┘
```

## 4. Memory Management — Big Difference

```
JAVA:                                C++:
─────                                ────
new Semaphore(3)                     sem_t sem;
      │                              sem_init(&sem, 0, 3);
      ▼                                    │
  Heap Object                         Stack or Heap
      │
  Garbage Collector                  YOU must call:
  handles cleanup ✅                 sem_destroy(&sem)   ⚠️
                                     sem_close(sem)
                                     sem_unlink(name)
Forget to destroy? No problem.    Forget? → Memory LEAK! 💥
```

### C++ RAII Wrapper (Safe Like Java)

```cpp
class SafeSemaphore {
    sem_t sem_;
    bool initialized_ = false;

public:
    explicit SafeSemaphore(int initial) {
        if (sem_init(&sem_, 0, initial) != 0)
            throw std::runtime_error("sem_init failed");
        initialized_ = true;
    }

    ~SafeSemaphore() {  // RAII — auto cleanup!
        if (initialized_) sem_destroy(&sem_);
    }

    void acquire() {
        while (sem_wait(&sem_) != 0)
            if (errno != EINTR)  // EINTR = signal interrupted, retry
                throw std::runtime_error("sem_wait failed");
    }

    bool tryAcquire() { return sem_trywait(&sem_) == 0; }

    void release() {
        if (sem_post(&sem_) != 0)
            throw std::runtime_error("sem_post failed");
    }

    // No copy!
    SafeSemaphore(const SafeSemaphore&) = delete;
    SafeSemaphore& operator=(const SafeSemaphore&) = delete;
};
```

## 5. Error Handling

```java
// JAVA — forced to handle InterruptedException
try {
    sem.acquire();   // throws InterruptedException (must catch!)
    doWork();
} catch (InterruptedException e) {
    Thread.currentThread().interrupt();
} finally {
    sem.release();
}
```

```cpp
// C++ POSIX — easy to ignore return codes ⚠️
int ret = sem_wait(&sem);   // returns 0 or -1
if (ret != 0) {
    switch(errno) {
        case EINTR:   /* interrupted, retry */ break;
        case EINVAL:  /* invalid semaphore  */ break;
        case EDEADLK: /* deadlock detected  */ break;
    }
}
```

## 6. IPC — The Biggest Difference

```
╔═══════════════════════════════════════════════════════════════╗
║  JAVA Semaphore:                                              ║
║  ✅ Works within ONE JVM process                              ║
║  ❌ CANNOT cross process boundaries natively                  ║
║                                                               ║
║  C++ POSIX Named Semaphore:                                   ║
║  ✅ Named semaphores work across DIFFERENT processes          ║
║  ✅ Process A and Process B share the SAME semaphore          ║
║  ✅ Survives process restart (until unlinked)                 ║
║  ✅ True OS-level IPC                                         ║
╚═══════════════════════════════════════════════════════════════╝
```

### C++ IPC Example

```cpp
// PROGRAM A (Writer)
int main() {
    int shm_fd = shm_open("/shared_mem", O_CREAT | O_RDWR, 0666);
    ftruncate(shm_fd, 1024);
    char* shared = (char*)mmap(NULL, 1024, PROT_READ|PROT_WRITE, MAP_SHARED, shm_fd, 0);

    sem_t *sem = sem_open("/data_ready", O_CREAT, 0644, 0);  // Start at 0!

    strcpy(shared, "Hello from Process A!");
    sem_post(sem);   // Signal B

    sem_close(sem); sem_unlink("/data_ready");
    return 0;
}

// PROGRAM B (Reader)
int main() {
    int shm_fd = shm_open("/shared_mem", O_RDONLY, 0666);
    char* shared = (char*)mmap(NULL, 1024, PROT_READ, MAP_SHARED, shm_fd, 0);

    sem_t *sem = sem_open("/data_ready", 0);

    printf("B: Waiting...\n");
    sem_wait(sem);  // Block until A posts!
    printf("B: Received: %s\n", shared);  // "Hello from Process A!" ✅

    sem_close(sem);
    return 0;
}
```

## 7. NDK Bridge — C++ Semaphore from Android Java

```cpp
// native-lib.cpp
#include <jni.h>
#include <semaphore.h>
#include <android/log.h>

static sem_t g_semaphore;
static bool g_initialized = false;

extern "C" {

JNIEXPORT void JNICALL
Java_com_example_app_MainActivity_initSemaphore(JNIEnv*, jobject, jint count) {
    if (!g_initialized) {
        sem_init(&g_semaphore, 0, count);
        g_initialized = true;
    }
}

JNIEXPORT jboolean JNICALL
Java_com_example_app_MainActivity_nativeAcquire(JNIEnv*, jobject) {
    return sem_wait(&g_semaphore) == 0 ? JNI_TRUE : JNI_FALSE;
}

JNIEXPORT void JNICALL
Java_com_example_app_MainActivity_nativeRelease(JNIEnv*, jobject) {
    sem_post(&g_semaphore);
}

JNIEXPORT void JNICALL
Java_com_example_app_MainActivity_destroySemaphore(JNIEnv*, jobject) {
    if (g_initialized) { sem_destroy(&g_semaphore); g_initialized = false; }
}

}  // extern "C"
```

```java
// MainActivity.java
public class MainActivity extends AppCompatActivity {
    static { System.loadLibrary("native-lib"); }

    private native void initSemaphore(int count);
    private native boolean nativeAcquire();
    private native void nativeRelease();
    private native void destroySemaphore();

    @Override protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        initSemaphore(3);

        for (int i = 1; i <= 5; i++) {
            final int id = i;
            executor.submit(() -> {
                if (nativeAcquire()) {
                    try { Thread.sleep(1000); }
                    catch (InterruptedException e) {}
                    finally { nativeRelease(); }
                }
            });
        }
    }

    @Override protected void onDestroy() {
        super.onDestroy();
        destroySemaphore();  // Must destroy C++ semaphore!
    }
}
```

## 8. Kotlin Coroutines — The Modern Android Way

```kotlin
import kotlinx.coroutines.sync.Semaphore
import kotlinx.coroutines.sync.withPermit

val semaphore = Semaphore(3)

suspend fun doWork(id: Int) {
    semaphore.withPermit {           // auto acquired & released
        Log.d("SEM", "Worker $id running")
        delay(1000)                  // Non-blocking! (vs Thread.sleep)
    }
}

fun main() = runBlocking {
    val jobs = (1..10).map { id -> launch { doWork(id) } }
    jobs.forEach { it.join() }
}
```

```
Java Thread Semaphore:           Kotlin Coroutine Semaphore:
sem.acquire()                    semaphore.withPermit {
try {                                delay(1000)  ← SUSPENDS (not blocks)
    Thread.sleep(1000) ← BLOCKS  }
} finally { sem.release() }

OS Thread blocked 😴             Coroutine suspended, thread FREE 🏃
Memory: ~1MB per thread          Memory: ~1KB per coroutine
```
