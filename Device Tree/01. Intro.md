## 1. What is Device Tree?

### Definition

A **Device Tree (DT)** is a data structure (a tree of nodes and properties) that describes the hardware components of a system so the OS kernel doesn't need to hard-code hardware details.

### Why Do We Need It?

```
WITHOUT Device Tree:
┌─────────────────────────────┐
│ Linux Kernel                │
│ ┌─────────────────────────┐ │
│ │ Board-specific code     │ │  ← Hard-coded for EACH board
│ │ (compiled into kernel)  │ │  ← Need new kernel per device
│ └─────────────────────────┘ │
└─────────────────────────────┘

WITH Device Tree:
┌─────────────────────────────┐
│ Linux Kernel (Generic)      │
│         +                   │
│ Device Tree Blob (.dtb)     │  ← Hardware description separate
│ (loaded at boot time)       │  ← Same kernel, different DTB per device
└─────────────────────────────┘
```

### Device Tree Compilation Flow

```
 .dts (Source)          .dtsi (Include files)
      │                       │
      └───────┬───────────────┘
              │
              ▼
     ┌────────────────┐
     │  DTC Compiler  │    (Device Tree Compiler)
     └────────────────┘
              │
              ▼
     .dtb (Binary Blob)     ← This is what bootloader loads
```

### Basic Syntax

```dts
/* device-tree-source (.dts) file */
/dts-v1/;              // Version declaration

/ {                     // Root node
    model = "My Custom Board";
    compatible = "vendor,board-name";

    #address-cells = <1>;
    #size-cells = <1>;

    memory@80000000 {
        device_type = "memory";
        reg = <0x80000000 0x40000000>;  // base: 0x80000000, size: 1GB
    };

    cpus {
        #address-cells = <1>;
        #size-cells = <0>;

        cpu@0 {
            device_type = "cpu";
            compatible = "arm,cortex-a53";
            reg = <0>;
            clock-frequency = <1200000000>;  // 1.2 GHz
        };

        cpu@1 {
            device_type = "cpu";
            compatible = "arm,cortex-a53";
            reg = <1>;
            clock-frequency = <1200000000>;
        };
    };

    uart0: serial@7e201000 {
        compatible = "arm,pl011", "arm,primecell";
        reg = <0x7e201000 0x200>;
        interrupts = <2 25>;
        clock-frequency = <3000000>;
        status = "okay";
    };
};
```

### Key Concepts

#### a) Nodes

```dts
// Node format: node-name@unit-address
uart0: serial@7e201000 {
//  │      │       │
//  │      │       └── Unit address (matches reg property)
//  │      └────────── Node name
//  └───────────────── Label (for referencing)
    ...
};
```

#### b) Properties

```dts
node {
    compatible = "vendor,device";                   // String
    compatible = "vendor,device-v2", "vendor,device"; // String list
    reg = <0x1000 0x100>;                           // Integer (32-bit cells)
    read-only;                                      // Boolean
    mac-address = [00 11 22 33 44 55];              // Byte array
    interrupt-parent = <&gic>;                      // Phandle reference
    example = "string", <0x1234>, [0a 0b];          // Mixed
};
```

#### c) Include Files (.dtsi)

```dts
/* soc-base.dtsi - Base SoC definition */
/ {
    soc {
        compatible = "simple-bus";
        #address-cells = <1>;
        #size-cells = <1>;
        ranges;

        gpio: gpio@ff200000 {
            compatible = "vendor,soc-gpio";
            reg = <0xff200000 0x1000>;
            #gpio-cells = <2>;
            gpio-controller;
            status = "disabled";
        };

        i2c0: i2c@ff300000 {
            compatible = "vendor,soc-i2c";
            reg = <0xff300000 0x1000>;
            #address-cells = <1>;
            #size-cells = <0>;
            clock-frequency = <100000>;
            status = "disabled";
        };
    };
};
```

```dts
/* board.dts - Board-specific file */
/dts-v1/;
#include "soc-base.dtsi"

/ {
    model = "My Custom Board v2";
    compatible = "myvendor,custom-board";

    &gpio {
        status = "okay";
    };

    &i2c0 {
        status = "okay";
        clock-frequency = <400000>;

        touchscreen@48 {
            compatible = "ti,tsc2007";
            reg = <0x48>;
            interrupt-parent = <&gpio>;
            interrupts = <5 2>;
        };

        accelerometer@1d {
            compatible = "nxp,mma8452";
            reg = <0x1d>;
            interrupt-parent = <&gpio>;
            interrupts = <7 2>;
        };
    };
};
```

## 2. What is Device Tree Overlay?

### Definition

A **Device Tree Overlay (DTO)** allows you to modify the base device tree at runtime without changing the original DT. It can add nodes, modify properties, or delete nodes.

### Why Overlays?

```
PROBLEM WITHOUT OVERLAYS:
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ SoC Vendor   │  │ ODM          │  │ OEM          │
│ (Qualcomm)   │  │ (Board Mfr)  │  │ (Phone Brand)│
│              │  │              │  │              │
│ base.dtb     │──│ Must modify  │──│ Must modify  │
│              │  │ source & re- │  │ again &      │
│              │  │ compile      │  │ recompile    │
└──────────────┘  └──────────────┘  └──────────────┘
                  ← Needs source →  ← Needs source →

SOLUTION WITH OVERLAYS:
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ SoC Vendor   │  │ ODM          │  │ OEM          │
│              │  │              │  │              │
│ base.dtb     │  │ odm.dtbo     │  │ oem.dtbo     │
│ (compiled    │  │ (overlay     │  │ (overlay     │
│  binary)     │  │  binary)     │  │  binary)     │
└──────┬───────┘  └──────┬───────┘  └──────┬───────┘
       │                 │                 │
       └────────┬────────┘                 │
                └──────────┬───────────────┘
                           ▼
                ┌──────────────────┐
                │ Bootloader merges│
                │ base + overlays  │
                │ = final DT       │
                └──────────────────┘
```

### Overlay Syntax

```dts
/* overlay.dts */
/dts-v1/;
/plugin/;              // ← Marks it as an overlay

/ {
    fragment@0 {
        target = <&uart0>;
        __overlay__ {
            status = "okay";
            pinctrl-names = "default";
            pinctrl-0 = <&uart0_pins>;
        };
    };

    fragment@1 {
        target = <&i2c0>;
        __overlay__ {
            #address-cells = <1>;
            #size-cells = <0>;

            sensor@68 {
                compatible = "invensense,mpu6050";
                reg = <0x68>;
                interrupt-parent = <&gpio>;
                interrupts = <4 1>;
            };
        };
    };
};

/* Modern simplified syntax (equivalent): */
/dts-v1/;
/plugin/;

&uart0 {
    status = "okay";
    pinctrl-names = "default";
    pinctrl-0 = <&uart0_pins>;
};

&i2c0 {
    #address-cells = <1>;
    #size-cells = <0>;

    sensor@68 {
        compatible = "invensense,mpu6050";
        reg = <0x68>;
        interrupt-parent = <&gpio>;
        interrupts = <4 1>;
    };
};
```

### Overlay Compilation

```bash
# Compile overlay to .dtbo
dtc -@ -I dts -O dtb -o overlay.dtbo overlay.dts

# The -@ flag preserves symbol information needed for overlay resolution

# Merge overlay with base (for testing)
fdtoverlay -i base.dtb -o merged.dtb overlay.dtbo
```

## 3. Architecture & Flow in AOSP

### Complete Boot Flow with DT/DTO

```
┌─────────────────────────────────────────────────────────────┐
│                        BOOT FLOW                            │
│                                                             │
│  ┌──────────┐                                               │
│  │ Power On │                                               │
│  └────┬─────┘                                               │
│       ▼                                                     │
│  ┌──────────────────────────────────────┐                   │
│  │ 1. Bootloader (e.g., ABL/LK/U-Boot) │                   │
│  │    - Loads base DTB from dtb         │                   │
│  │      partition                       │                   │
│  │    - Loads DTBO from dtbo partition  │                   │
│  │    - Merges: base DTB + DTBO         │                   │
│  │    - Places merged DT in memory      │                   │
│  └────┬─────────────────────────────────┘                   │
│       ▼                                                     │
│  ┌──────────────────────────────────────┐                   │
│  │ 2. Kernel Boot                       │                   │
│  │    - Reads merged DT from memory     │                   │
│  │    - Probes devices described in DT  │                   │
│  │    - Loads matching drivers          │                   │
│  └────┬─────────────────────────────────┘                   │
│       ▼                                                     │
│  ┌──────────────────────────────────────┐                   │
│  │ 3. Android Init                      │                   │
│  │    - Reads /proc/device-tree/        │                   │
│  │    - HALs interact with drivers      │                   │
│  └──────────────────────────────────────┘                   │
└─────────────────────────────────────────────────────────────┘
```

### Partition Layout

```
┌────────────────────────────────────────┐
│           Flash/eMMC Layout            │
├────────────────────────────────────────┤
│  boot        │ Kernel + ramdisk        │
├──────────────┼─────────────────────────┤
│  dtb         │ Base Device Tree (.dtb) │  ← SoC vendor provides
├──────────────┼─────────────────────────┤
│  dtbo        │ DT Overlays (.dtbo)     │  ← ODM/OEM customizations
├──────────────┼─────────────────────────┤
│  vendor      │ Vendor HALs, libs       │
├──────────────┼─────────────────────────┤
│  system      │ Android framework       │
├──────────────┼─────────────────────────┤
│  odm         │ ODM customizations      │
└──────────────┴─────────────────────────┘

Note: In newer AOSP (Android 12+), DTB can also be embedded
in the vendor_boot partition.
```

### AOSP DT/DTO Responsibility Matrix

```
┌─────────────────────────────────────────────────────────────────┐
│  Layer         │ Provides        │ Contains                     │
├────────────────┼─────────────────┼──────────────────────────────┤
│ SoC Vendor     │ Base DTB        │ SoC-level: CPUs, buses,      │
│ (e.g. Qualcomm)│ (.dtb)          │ memory controllers, GPU,     │
│                │                 │ basic peripherals             │
├────────────────┼─────────────────┼──────────────────────────────┤
│ ODM            │ ODM Overlay     │ Board-level: sensors, camera │
│ (Board Maker)  │ (.dtbo)         │ modules, display, touch      │
│                │                 │ controller, audio codec       │
├────────────────┼─────────────────┼──────────────────────────────┤
│ OEM            │ OEM Overlay     │ Product-specific: LED config, │
│ (Brand)        │ (.dtbo)         │ button mapping, NFC, custom   │
│                │                 │ peripherals                   │
└────────────────┴─────────────────┴──────────────────────────────┘
```

## 4. Directory Structure in AOSP

### Typical AOSP Device Tree Directory

```
device/
└── <vendor>/
    └── <device>/
        ├── AndroidProducts.mk
        ├── BoardConfig.mk
        ├── device.mk
        ├── vendorsetup.sh
        │
        ├── dt/                          # Device Tree Sources
        │   ├── base/
        │   │   ├── soc.dtsi             # SoC-level definitions
        │   │   ├── board-base.dts       # Board base DT
        │   │   └── Makefile
        │   │
        │   └── overlays/
        │       ├── camera-overlay.dts   # Camera overlay
        │       ├── display-overlay.dts  # Display overlay
        │       ├── audio-overlay.dts    # Audio overlay
        │       └── Makefile
        │
        ├── kernel/                      # Prebuilt kernel
        │   ├── Image.gz
        │   └── dtb                      # Prebuilt DTB
        │
        ├── sepolicy/                    # SELinux policies
        ├── init.device.rc               # Init scripts
        └── fstab.device                 # Filesystem table
```

### Real-World Example: Qualcomm Device

```
device/
└── qualcomm/
    └── sdm845/
        ├── BoardConfig.mk
        │
        └── dtb/
            ├── sdm845.dtsi              # SoC base
            ├── sdm845-v2.dtsi           # SoC revision
            ├── sdm845-pinctrl.dtsi      # Pin control
            ├── sdm845-camera.dtsi       # Camera subsystem
            ├── sdm845-audio.dtsi        # Audio subsystem
            └── boards/
                ├── sdm845-mtp.dts       # MTP board
                ├── sdm845-cdp.dts       # CDP board
                └── overlays/

```

## 5. Detailed Examples

### Example 1: Complete SoC Base DTSI

```dts
/* soc-base.dtsi */
/ {
    model = "Example SoC";
    compatible = "example,soc-v1";

    #address-cells = <2>;
    #size-cells = <2>;

    /* ============ CPUs ============ */
    cpus {
        #address-cells = <2>;
        #size-cells = <0>;

        cpu-map {
            cluster0 {
                core0 { cpu = <&cpu0>; };
                core1 { cpu = <&cpu1>; };
                core2 { cpu = <&cpu2>; };
                core3 { cpu = <&cpu3>; };
            };
            cluster1 {
                core0 { cpu = <&cpu4>; };
                core1 { cpu = <&cpu5>; };
            };
        };

        cpu0: cpu@0 {
            device_type = "cpu";
            compatible = "arm,cortex-a55";
            reg = <0x0 0x0>;
            enable-method = "psci";
            clock-frequency = <1800000000>;
            operating-points-v2 = <&cpu0_opp_table>;
        };

        /* ... cpu1–cpu3 similar ... */

        cpu4: cpu@10000 {
            device_type = "cpu";
            compatible = "arm,cortex-a76";
            reg = <0x0 0x10000>;
            enable-method = "psci";
            clock-frequency = <2400000000>;
        };
    };

    /* ============ OPP Table ============ */
    cpu0_opp_table: opp-table-0 {
        compatible = "operating-points-v2";

        opp-600000000  { opp-hz = /bits/ 64 <600000000>;  opp-microvolt = <800000>; };
        opp-1200000000 { opp-hz = /bits/ 64 <1200000000>; opp-microvolt = <900000>; };
        opp-1800000000 { opp-hz = /bits/ 64 <1800000000>; opp-microvolt = <1050000>; };
    };

    /* ============ PSCI ============ */
    psci {
        compatible = "arm,psci-1.0";
        method = "smc";
    };

    /* ============ Timer ============ */
    timer {
        compatible = "arm,armv8-timer";
        interrupts = <1 13 0xf08>, <1 14 0xf08>, <1 11 0xf08>, <1 10 0xf08>;
    };

    /* ============ Reserved Memory ============ */
    reserved-memory {
        #address-cells = <2>;
        #size-cells = <2>;
        ranges;

        bl31_region: memory@80000000 {
            reg = <0x0 0x80000000 0x0 0x200000>;
            no-map;
        };

        framebuffer_region: memory@90000000 {
            reg = <0x0 0x90000000 0x0 0x2000000>;
            no-map;
        };

        shmem_region: memory@95000000 {
            compatible = "shared-dma-pool";
            reg = <0x0 0x95000000 0x0 0x1000000>;
            no-map;
        };
    };

    /* ============ SoC Peripherals ============ */
    soc {
        compatible = "simple-bus";
        #address-cells = <2>;
        #size-cells = <2>;
        ranges;

        gic: interrupt-controller@10000000 {
            compatible = "arm,gic-v3";
            #interrupt-cells = <3>;
            interrupt-controller;
            reg = <0x0 0x10000000 0x0 0x10000>,
                  <0x0 0x10100000 0x0 0x100000>;
        };

        clock_controller: clock-controller@11000000 {
            compatible = "example,soc-clk";
            reg = <0x0 0x11000000 0x0 0x1000>;
            #clock-cells = <1>;
        };

        pinctrl: pinctrl@12000000 {
            compatible = "example,soc-pinctrl";
            reg = <0x0 0x12000000 0x0 0x2000>;

            uart0_pins: uart0-pins {
                pins = "gpio0", "gpio1";
                function = "uart0";
                drive-strength = <8>;
                bias-pull-up;
            };

            i2c0_pins: i2c0-pins {
                pins = "gpio10", "gpio11";
                function = "i2c0";
                drive-strength = <4>;
                bias-pull-up;
            };
        };

        gpio0: gpio@13000000 {
            compatible = "example,soc-gpio";
            reg = <0x0 0x13000000 0x0 0x1000>;
            gpio-controller;
            #gpio-cells = <2>;
            interrupt-controller;
            #interrupt-cells = <2>;
            interrupts = <0 32 4>;
            interrupt-parent = <&gic>;
        };

        uart0: serial@14000000 {
            compatible = "example,soc-uart";
            reg = <0x0 0x14000000 0x0 0x100>;
            interrupts = <0 33 4>;
            interrupt-parent = <&gic>;
            clocks = <&clock_controller 10>;
            clock-names = "uart_clk";
            pinctrl-names = "default";
            pinctrl-0 = <&uart0_pins>;
            status = "disabled";
        };

        i2c0: i2c@15000000 {
            compatible = "example,soc-i2c";
            reg = <0x0 0x15000000 0x0 0x1000>;
            interrupts = <0 40 4>;
            interrupt-parent = <&gic>;
            clocks = <&clock_controller 20>;
            clock-names = "i2c_clk";
            #address-cells = <1>;
            #size-cells = <0>;
            pinctrl-names = "default";
            pinctrl-0 = <&i2c0_pins>;
            status = "disabled";
        };

        spi0: spi@16000000 {

            interrupts = <0 50 4>;
            #address-cells = <1>;

        };

        usb0: usb@17000000 {
            compatible = "example,dwc3";
            reg = <0x0 0x17000000 0x0 0x10000>;
            interrupts = <0 60 4>;

            phy-names = "usb3-phy";
            dr_mode = "otg";
            status = "disabled";
        };

        display: display-controller@18000000 {
            compatible = "example,display-ctrl";
            reg = <0x0 0x18000000 0x0 0x10000>;
```


### 7.2 Bootloader Overlay Selection Logic

```c
/* Simplified bootloader logic for overlay selection */

struct dt_entry {
    uint32_t dt_size;
    uint32_t dt_offset;
    uint32_t id;        // board_id
    uint32_t rev;       // board_rev
    uint32_t custom[4];
};

void apply_device_tree_overlays(void *base_dtb) {
    struct dtbo_header *header;
    struct dt_entry *entries;
    void *merged_dtb = base_dtb;

    header  = read_partition("dtbo");
    entries = (struct dt_entry *)((uint8_t *)header + header->dt_entries_offset);

    uint32_t board_id  = read_board_id();
    uint32_t board_rev = read_board_revision();

    for (int i = 0; i < header->dt_entry_count; i++) {
        if (entries[i].id == board_id && entries[i].rev == board_rev) {
            void *overlay = (uint8_t *)header + entries[i].dt_offset;

            int ret = fdt_overlay_apply(merged_dtb, overlay);
            if (ret != 0)
                printf("ERROR: Failed to apply overlay %d: %d\n", i, ret);
            else
                printf("Applied overlay %d successfully\n", i);
        }
    }

    boot_linux(kernel_addr, merged_dtb);
}
```

```c
#include <linux/of.h>
#include <linux/of_device.h>

static int my_sensor_probe(struct platform_device *pdev)
{
    struct device_node *np = pdev->dev.of_node;
    struct resource *res;
    u32 clock_freq;
    int irq;
    const char *label;

    res = platform_get_resource(pdev, IORESOURCE_MEM, 0);
    void __iomem *base = devm_ioremap_resource(&pdev->dev, res);

    irq = platform_get_irq(pdev, 0);

    if (of_property_read_u32(np, "clock-frequency", &clock_freq))
        clock_freq = 100000;

    of_property_read_string(np, "label", &label);

    int reset_gpio = of_get_named_gpio(np, "reset-gpios", 0);
    bool has_wakeup = of_property_read_bool(np, "wakeup-source");
```

### 7.6 Runtime DT Access from Android Userspace

```java
// Java (Android Framework)
public class DeviceTreeUtils {
    private static final String DT_PATH = "/proc/device-tree/";

    public static String getModel()         { return readDtProperty("model"); }
    public static String getCompatible()    { return readDtProperty("compatible"); }
    public static String getBoardRevision() { return readDtProperty("board-revision"); }

    private static String readDtProperty(String property) {
        try {
            byte[] bytes = Files.readAllBytes(Paths.get(DT_PATH + property));
            return new String(bytes).trim();
        } catch (IOException e) {
            return null;
        }
    }
}
```

```cpp
// C++ (HAL layer)
#include <fstream>
#include <string>

std::string readDtProperty(const std::string& property) {
    std::ifstream file("/proc/device-tree/" + property);
    if (file.is_open()) {
        std::string value;
        std::getline(file, value);
        if (!value.empty() && value.back() == '\0')
            value.pop_back();
        return value;
    }
    return "";
}

void detectHardware() {
    std::string model = readDtProperty("model");
    std::string soc   = readDtProperty("soc/compatible");

    struct stat st;
    if (stat("/proc/device-tree/soc/nfc@1a000000", &st) == 0)
        enableNfcHal();
}
```

|---|---|---|---|
| Device Tree | Describes ALL hardware | `.dts` / `.dtsi` → `.dtb` | `dtb` or `vendor_boot` |
| DT Overlay | Modifies/extends base DT | `.dts` (with `/plugin/`) → `.dtbo` | `dtbo` |
| DTC | Compiles DT sources | Tool | N/A |
| mkdtboimg | Packages multiple DTBOs | Tool | N/A |
| Bootloader | Merges base + overlays | Runtime logic | N/A |

> **Key Takeaway:** Device Trees separate hardware description from kernel code. Overlays allow modular, layered hardware customization across the SoC vendor → ODM → OEM supply chain — without sharing or modifying source code.
