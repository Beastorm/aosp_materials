# Device Tree Probing — Complete Deep Dive

## What is Probing?

```
┌─────────────────────────────────────────────────────────────────────┐
│  PROBING = The process where kernel MATCHES a device                │
│            (described in DT) with its DRIVER and                   │
│            INITIALIZES the hardware                                 │
│                                                                     │
│  ANALOGY — Job Fair:                                                │
│  Companies (Drivers)     bring their "skills list" (of_match_table)│
│  Job Seekers (DT Devices) have their "resume" (compatible string)  │
│  Matchmaker (Kernel Bus)  connects them                            │
│  Interview (probe())      = actual hardware initialization         │
└─────────────────────────────────────────────────────────────────────┘
```

---

## Complete Probing Flow Overview

```
DTB in Memory
      │
      ▼
unflatten_device_tree()
[Binary FDT → Linked Tree of device_node structs]
      │
      ▼
of_platform_populate()
[Walk DT tree → Create platform_device for each node]
      │
      ▼
platform_device registered to platform_bus
      │
      ▼
Bus match() called
[Compare device compatible ↔ driver of_match_table]
      │
      ├── NO MATCH → device waits
      │
      └── MATCH FOUND
              │
              ▼
         driver->probe(device) called
              │
              ├── probe() SUCCESS          → device operational
              ├── probe() returns -EPROBE_DEFER → deferred list → retried later
              └── probe() returns ERROR    → device init failed
```

## Step 1: DT Binary to Kernel Tree Structure

```
INPUT:  Flat Device Tree Binary (FDT) in memory
OUTPUT: Linked tree of device_node structs

FDT BINARY (flat blob):          KERNEL TREE (linked structs):
┌──────────────────────┐         ┌─────────────────────────┐
│ magic: 0xd00dfeed    │         │  device_node: "/"        │
│ totalsize: 0x5000    │  ──→    │  ├── full_name = "/"     │
│ [node: /]            │         │  ├── properties          │
│ [prop: compatible]   │         │  ├── parent = NULL       │
│ [node: /cpus]        │         │  └── child ──────────────┼──┐
│ [node: /soc]         │         └─────────────────────────┘  │
│ [node: /soc/uart0]   │                                       │
└──────────────────────┘         ┌─────────────────────────┐  │
                                 │  device_node: "cpus"    │◄─┘
                                 │  ├── parent → "/"        │
                                 │  ├── child → "cpu@0"     │
                                 │  └── sibling ────────────┼──┐
                                 └─────────────────────────┘  │
                                 ┌─────────────────────────┐  │
                                 │  device_node: "soc"     │◄─┘
                                 │  ├── parent → "/"        │
                                 │  └── child → "uart@..."  │
                                 └─────────────────────────┘
```

### Internal `device_node` Structure

```c
/* include/linux/of.h */
struct device_node {
    const char  *name;          // Node name (e.g., "serial")
    const char  *full_name;     // Full path (e.g., "/soc/serial@7e201000")
    phandle      phandle;       // Unique integer ID for this node

    struct property     *properties;   // Linked list of properties
    struct property     *deadprops;    // Removed properties

    struct device_node  *parent;       // Parent node pointer
    struct device_node  *child;        // First child node pointer
    struct device_node  *sibling;      // Next sibling pointer

    struct kobject       kobj;         // sysfs representation
    unsigned long        _flags;
    void                *data;
};

struct property {
    char    *name;      // Property name (e.g., "compatible")
    int      length;    // Length of value in bytes
    void    *value;     // Property value (raw bytes)
    struct property *next;
};
```

## Step 2: Creating Platform Devices from DT Nodes

```
of_platform_populate() — walks DT tree, creates platform_device per eligible node

ELIGIBILITY RULES:
  ✅ Node has "compatible" property
  ✅ Node status is "okay" or status absent
  ❌ Node status is "disabled" → SKIP
  ❌ Node has no compatible     → SKIP

DT TREE:                       PLATFORM DEVICES CREATED:
/
├── cpus/            → ❌ No compatible at top level
│   └── cpu@0        → ✅ platform_device: "cpu"
├── memory@80000000  → ❌ device_type only, no driver needed
└── soc/
    ├── gpio@13000000    → ✅ platform_device: "13000000.gpio"
    ├── uart@14000000    → ✅ platform_device: "14000000.serial"
    ├── i2c@15000000     → ✅ platform_device: "15000000.i2c"
    │   └── sensor@68    → ✅ i2c_client: "68-0068"
    └── spi@16000000     → ✅ platform_device: "16000000.spi"
        └── flash@0      → ✅ spi_device: "spi0.0"
```

### `platform_device` Structure Created

### `of_platform_populate()` Code Flow

```c
/* drivers/of/platform.c */

int of_platform_populate(struct device_node *root, ...) {
    struct device_node *child;

    for_each_child_of_node(root, child)
        of_platform_bus_create(child, matches, ...);

    return 0;
}

static int of_platform_bus_create(struct device_node *bus, ...) {
    struct device_node *child;
    struct platform_device *dev;

    /* Skip nodes without compatible */
    if (!of_find_property(bus, "compatible", NULL))
        goto children;

    /* IMPORTANT: Skip disabled nodes */
    if (!of_device_is_available(bus)) {
        pr_debug("%s: status is disabled, skipping\n", bus->full_name);
        return 0;  // ← DISABLED = NO platform_device created
    }

    dev = of_platform_device_create(bus, NULL, parent);

children:
    for_each_child_of_node(bus, child)
        of_platform_bus_create(child, matches, ...);

    return 0;
}

bool of_device_is_available(const struct device_node *device) {
    const char *status = of_get_property(device, "status", NULL);

    if (status == NULL)
        return true;   // No status property = available

    return !strcmp(status, "okay") || !strcmp(status, "ok");
}
```

## Step 3: Driver Registration

```
TWO PARALLEL PATHS — order doesn't matter, kernel handles matching:

PATH A: Device registered first
  platform_device registered
        │
        ▼
  Search for matching driver (none yet)
        │
        ▼
  Device waits in bus device list
        │  (later, when driver loads)
        ▼
  Driver registered → match found → probe()

PATH B: Driver registered first
  platform_driver registered
        │
        ▼
  Search existing devices for match
        │
  If device exists → probe() immediately
  If no device yet → driver waits
```

## Step 4: The Matching Process

```
Device compatible = "example,soc-uart-v2"
                          │
                          ▼
Scan driver's of_match_table:
  Entry[0]: "example,soc-uart-v2"  ← MATCH! ✅
  Entry[1]: "example,soc-uart-v1"  (not checked — already matched)
  Entry[2]: "arm,pl011"
                          │
                          ▼
                   probe() called!

MULTIPLE COMPATIBLE STRINGS in DT:
  compatible = "example,soc-uart-v2",    ← Try first (most specific)
               "example,soc-uart-v1",    ← Then this
               "arm,pl011";              ← Then generic fallback

Kernel tries EACH string against ALL drivers — first match wins.
```

### Matching Code Deep Dive

```c
/* drivers/base/platform.c */
static int platform_match(struct device *dev, struct device_driver *drv) {
    struct platform_device *pdev = to_platform_device(dev);
    struct platform_driver *pdrv = to_platform_driver(drv);

    /* Priority order:
     * 1. DT compatible string  ← Most common for embedded
     * 2. ACPI                  ← For x86-based Android
     * 3. id_table              ← Legacy matching
     * 4. Name matching         ← Oldest method
     */

    if (pdev->dev.of_node)
        return of_driver_match_device(dev, drv);

    if (is_acpi_node(pdev->dev.fwnode))
        return acpi_driver_match_device(dev, drv);

    if (pdrv->id_table)
        return platform_match_id(pdrv->id_table, pdev) != NULL;

    return (strcmp(pdev->name, drv->name) == 0);
}

/* Checks ALL compatible strings in the node */
int of_device_is_compatible(const struct device_node *device,
                              const char *compat) {
    const char *cp;
    int cplen, score = 0;

    cp = of_get_property(device, "compatible", &cplen);
    if (cp == NULL) return 0;

    /* Score decreases per position — higher = more specific */
    while (cplen > 0) {
        score++;
        if (of_compat_cmp(cp, compat, strlen(compat)) == 0)
            return score;   // MATCH — return position score

        int match = strlen(cp) + 1;
        cp    += match;
        cplen -= match;
    }
    return 0;
}
```

## Step 5: The `probe()` Function — Complete Anatomy

```
WHAT probe() MUST DO:
  1. Read ALL needed info from DT
  2. Request and map hardware resources (MMIO, IRQ)
  3. Initialize hardware to working state
  4. Register with kernel subsystem (char dev, net, IIO, etc.)
  5. Return 0 on success, negative error on failure
```

### Complete `probe()` Example — UART Driver

```c
struct uart_priv {
    void __iomem     *base;
    int               irq;
    struct clk       *clk;
    struct regulator *vdd;
    u32               fifo_size;
    struct uart_port  port;
};

static int uart_probe(struct platform_device *pdev) {
    struct device      *dev = &pdev->dev;
    struct device_node *np  = dev->of_node;
    struct uart_priv   *priv;
    struct resource    *res;
    int ret;

    /* 1. ALLOCATE DRIVER PRIVATE DATA */
    priv = devm_kzalloc(dev, sizeof(*priv), GFP_KERNEL);
    if (!priv) return -ENOMEM;
    platform_set_drvdata(pdev, priv);

    /* 2. GET REGISTER BASE FROM DT: reg = <0x14000000 0x100>; */
    res = platform_get_resource(pdev, IORESOURCE_MEM, 0);
    if (!res) return -EINVAL;

    priv->base = devm_ioremap_resource(dev, res);
    if (IS_ERR(priv->base)) return PTR_ERR(priv->base);

    /* 3. GET INTERRUPT FROM DT: interrupts = <0 33 4>; */
    priv->irq = platform_get_irq(pdev, 0);
    if (priv->irq < 0) return priv->irq;

    ret = devm_request_irq(dev, priv->irq, uart_irq_handler,
                            IRQF_SHARED, dev_name(dev), priv);
    if (ret) return ret;

    /* 4. GET CLOCK FROM DT: clocks = <&clock_ctrl 10>; */
    priv->clk = devm_clk_get(dev, "uart_clk");
    if (IS_ERR(priv->clk)) {
        if (PTR_ERR(priv->clk) == -EPROBE_DEFER)
            return -EPROBE_DEFER;  // ← Clock not ready yet
        return PTR_ERR(priv->clk);
    }
    ret = clk_prepare_enable(priv->clk);
    if (ret) return ret;

    /* 5. GET REGULATOR FROM DT: vdd-supply = <&vcc_3v3>; */
    priv->vdd = devm_regulator_get_optional(dev, "vdd");
    if (IS_ERR(priv->vdd)) {
        if (PTR_ERR(priv->vdd) == -EPROBE_DEFER)
            return -EPROBE_DEFER;
        priv->vdd = NULL;  // Optional — ignore if absent
    }
    if (priv->vdd) regulator_enable(priv->vdd);

    /* 6. GET GPIO FROM DT: reset-gpios = <&gpio0 5 GPIO_ACTIVE_LOW>; */
    int reset_gpio = of_get_named_gpio(np, "reset-gpios", 0);
    if (gpio_is_valid(reset_gpio)) {
        ret = devm_gpio_request_one(dev, reset_gpio,
                                     GPIOF_OUT_INIT_HIGH, "uart-reset");
        if (ret) return ret;
        gpio_set_value(reset_gpio, 0);  // Assert reset
        udelay(100);
        gpio_set_value(reset_gpio, 1);  // Release reset
    }

    /* 7. READ CUSTOM DT PROPERTIES */
    if (of_property_read_u32(np, "fifo-size", &priv->fifo_size))
        priv->fifo_size = 16;  // Default

    bool flow_ctrl = of_property_read_bool(np, "hw-flow-control");

    const char *mode;
    if (of_property_read_string(np, "uart-mode", &mode))
        mode = "rs232";

    /* Which compatible string matched? */
    const struct of_device_id *match = of_match_device(uart_of_match, dev);
    const struct uart_config *cfg = match->data;

    /* 8. PINCTRL — usually automatic before probe(), but can be manual */
    struct pinctrl *pc = devm_pinctrl_get_select_default(dev);

    /* 9. INITIALIZE HARDWARE */
    ret = uart_hw_init(priv);
    if (ret) return ret;

    /* 10. REGISTER WITH KERNEL UART SUBSYSTEM */
    priv->port.dev      = dev;
    priv->port.mapbase  = res->start;
    priv->port.membase  = priv->base;
    priv->port.irq      = priv->irq;
    priv->port.fifosize = priv->fifo_size;
    priv->port.ops      = &uart_ops;

    ret = uart_add_one_port(&uart_drv, &priv->port);
    if (ret) return ret;

    dev_info(dev, "UART probed! IRQ=%d, FIFO=%d, mode=%s\n",
             priv->irq, priv->fifo_size, mode);

    return 0;  // ← SUCCESS
}
```

## Step 6: Deferred Probing — Handling Dependencies

```
PROBLEM: Device B needs Device A probed first, but B probes before A.
SOLUTION: Return -EPROBE_DEFER → kernel retries after each successful probe.

EXAMPLE — Display dependency chain:
  Display needs: Clock controller + Regulator + GPIO controller

TIMELINE:
  T1: display_probe() → devm_clk_get() fails → -EPROBE_DEFER
  T2: clock_ctrl probe() → SUCCESS → kernel retries deferred devices
  T3: display_probe() → clock OK ✅ → regulator fails → -EPROBE_DEFER
  T4: regulator probe() → SUCCESS → kernel retries deferred devices
  T5: display_probe() → clock ✅ regulator ✅ GPIO ✅ → SUCCESS!
```

### Deferred Probing Internal Mechanism

```c
/* drivers/base/dd.c (simplified) */

static LIST_HEAD(deferred_probe_pending_list);
static LIST_HEAD(deferred_probe_active_list);

/* Called when probe() returns -EPROBE_DEFER */
static void driver_deferred_probe_add(struct device *dev) {
    mutex_lock(&deferred_probe_mutex);
    if (list_empty(&dev->p->deferred_probe))
        list_add_tail(&dev->p->deferred_probe,
                      &deferred_probe_pending_list);
    mutex_unlock(&deferred_probe_mutex);
}

/* Called after EVERY successful probe */
static void driver_deferred_probe_trigger(void) {
    schedule_work(&deferred_probe_work);
}

/* Work function: retry deferred probes */
static void deferred_probe_work_func(struct work_struct *work) {
    list_splice_init(&deferred_probe_pending_list,
                     &deferred_probe_active_list);

    while (!list_empty(&deferred_probe_active_list)) {
        dev = list_first_entry(&deferred_probe_active_list, ...);
        bus_probe_device(dev);
        /* SUCCESS → removed from list; still defer → back to pending */
    }
}

/* The actual probe() call site */
static int really_probe(struct device *dev, struct device_driver *drv) {
    int ret;

    pinctrl_bind_pins(dev);  // Apply "default" pinctrl state first

    dev->driver = drv;

    /* ★ ACTUAL probe() CALL ★ */
    ret = drv->probe(dev);

    if (ret == -EPROBE_DEFER)
        driver_deferred_probe_add(dev);

    return ret;
}
```

### I2C Probing Flow

```c
/* STAGE 1: I2C Controller Probe */
static int i2c_controller_probe(struct platform_device *pdev) {
    struct i2c_adapter *adap;

    /* ... initialize I2C controller hardware ... */

    i2c_add_adapter(adap);

    /* ★ Register child DT devices ★ */
    of_i2c_register_devices(adap);
    return 0;
}

void of_i2c_register_devices(struct i2c_adapter *adap) {
    struct device_node *bus  = adap->dev.of_node;
    struct device_node *node;

    for_each_available_child_of_node(bus, node) {
        u32 addr;
        if (of_property_read_u32(node, "reg", &addr)) continue;
        if (addr > 0x7f) continue;

        struct i2c_board_info info = {
            .addr    = addr,
            .of_node = of_node_get(node),
        };

        of_modalias_node(node, info.type, sizeof(info.type));
        info.irq = of_irq_get(node, 0);

        i2c_new_client_device(adap, &info);
    }
}

/* STAGE 2: I2C Client (Sensor) Probe */
```

## Step 8: The Complete Probing State Machine

```
[DT Node Found]
      │
      ▼
status = "okay"?
      │         │
     YES         NO → [SKIP — no device created]
      │
      ▼
[Create platform_device]
      │
      ▼
Driver registered?
      │         │
     YES        NO → [Wait for driver]
      │
      ▼
[Match check]
      │              │
   MATCH           NO MATCH → [Wait for matching driver to register]
      │
      ▼
[Call probe()]
      │
 ┌────┴──────────────────────────┐
 │                               │
ret = 0                    ret = -EPROBE_DEFER
[SUCCESS]                  [Add to deferred list]
 │                               │
 ▼                               ▼
Device operational!        [Wait for next successful probe]
 │                               │
 ▼                               ▼
[Trigger deferred          [Retry probe()]
 probe retry]                    │
                          ┌──────┴──────────┐
                          │                 │
                       SUCCESS          Still defer / ERROR
                          │                 │
                      Device OK         [Give up / retry later]
```

## Step 9: Resource Management in `probe()`

```c
/*
 * devm_ = Device Managed
 * Auto-freed when:
 *   - probe() fails (returns error)
 *   - driver removed
 *   - device unregistered
 *
 * Without devm_: manual cleanup needed at every failure point.
 * With devm_:    kernel handles cleanup automatically.
 */

static int uart_probe(struct platform_device *pdev) {
    struct device *dev = &pdev->dev;

    /* All auto-freed on failure or remove */
    void *mem             = devm_kzalloc(dev, size, GFP_KERNEL);
    void *iobase          = devm_ioremap_resource(dev, res);
    struct clk *clk       = devm_clk_get(dev, "uart_clk");
    struct regulator *vdd = devm_regulator_get(dev, "vdd");
    struct gpio_desc *gpio = devm_gpiod_get(dev, "reset", GPIOD_OUT_HIGH);

    devm_request_irq(dev, irq, handler, 0, "uart", priv);
    devm_pinctrl_get_select_default(dev);

    if (some_hw_init_fails())
        return -EIO;  // ← ALL devm_ resources freed automatically

    return 0;
}

/*
 * CLEANUP ORDER (LIFO — reverse of acquisition):
 * Acquired: mem → iobase → clk → vdd → gpio → irq
 * Freed:    irq → gpio → vdd → clk → iobase → mem
 */
```

## Complete Example: GPIO Controller Probing

```c
/*
 * DT Node:
 * gpio0: gpio@13000000 {
 *     compatible = "example,soc-gpio";
 *     reg = <0x13000000 0x1000>;
 *     interrupts = <0 32 4>;
 *     interrupt-parent = <&gic>;
 *     gpio-controller;
 *     #gpio-cells = <2>;
 *     interrupt-controller;
 *     #interrupt-cells = <2>;
 *     ngpios = <32>;
 *     gpio-line-names = "uart_tx", "uart_rx", "spi_clk", ...;
 *     clocks = <&clock_ctrl 5>;
 *     clock-names = "gpio_clk";
 * };
 */

struct gpio_priv {
    void __iomem      *base;
    struct clk        *clk;
    struct gpio_chip   chip;
    struct irq_chip    irq_chip;
    struct irq_domain *irq_domain;
    u32                ngpios;
    spinlock_t         lock;
};

static int gpio_probe(struct platform_device *pdev) {
    struct device      *dev = &pdev->dev;
    struct device_node *np  = dev->of_node;
    struct gpio_priv   *priv;
    int ret;

    priv = devm_kzalloc(dev, sizeof(*priv), GFP_KERNEL);
    if (!priv) return -ENOMEM;
    spin_lock_init(&priv->lock);
    platform_set_drvdata(pdev, priv);

    priv->base = devm_platform_ioremap_resource(pdev, 0);
    if (IS_ERR(priv->base)) return PTR_ERR(priv->base);

    priv->clk = devm_clk_get(dev, "gpio_clk");
    if (IS_ERR(priv->clk)) {
        if (PTR_ERR(priv->clk) == -EPROBE_DEFER) return -EPROBE_DEFER;
        priv->clk = NULL;  // Some GPIO controllers don't need explicit clock
    }
    if (priv->clk) clk_prepare_enable(priv->clk);

    if (of_property_read_u32(np, "ngpios", &priv->ngpios))
        priv->ngpios = 32;

    /* Setup gpio_chip */
    priv->chip.label            = dev_name(dev);
    priv->chip.parent           = dev;
    priv->chip.of_node          = np;
    priv->chip.base             = -1;  // Dynamic allocation
    priv->chip.ngpio            = priv->ngpios;
    priv->chip.get_direction    = gpio_get_direction;
    priv->chip.direction_input  = gpio_direction_input;
    priv->chip.direction_output = gpio_direction_output;
    priv->chip.get              = gpio_get_value;
    priv->chip.set              = gpio_set_value;

    /* GPIO line names from DT: gpio-line-names = "uart_tx", "uart_rx", ...; */
    priv->chip.names = devm_kasprintf_strarray(dev, "gpio", priv->ngpios);
    of_property_read_string_array(np, "gpio-line-names",
                                   priv->chip.names, priv->ngpios);

    /* Setup interrupt support */
    int irq = platform_get_irq(pdev, 0);
    if (irq > 0) {
        priv->irq_domain = irq_domain_add_linear(np, priv->ngpios,
                                                   &gpio_irq_domain_ops, priv);

        priv->irq_chip.name         = dev_name(dev);
        priv->irq_chip.irq_mask     = gpio_irq_mask;
        priv->irq_chip.irq_unmask   = gpio_irq_unmask;
        priv->irq_chip.irq_set_type = gpio_irq_set_type;

        devm_request_irq(dev, irq, gpio_irq_handler,
                          IRQF_SHARED, dev_name(dev), priv);

        struct gpio_irq_chip *girq = &priv->chip.irq;
        girq->chip           = &priv->irq_chip;
        girq->domain         = priv->irq_domain;
        girq->parent_handler = gpio_irq_handler;
        girq->parent_irq     = irq;
        girq->default_type   = IRQ_TYPE_NONE;
        girq->handler        = handle_bad_irq;
    }

    ret = devm_gpiochip_add_data(dev, &priv->chip, priv);
    if (ret) return ret;

    dev_info(dev, "GPIO controller probed: %d GPIOs, IRQ=%d\n",
             priv->ngpios, irq);

    /* Now other drivers can use:
     * gpios = <&gpio0 5 0>; in their DT nodes
     * and call of_get_named_gpio() to get GPIO 5 */
    return 0;
}

static const struct of_device_id gpio_of_match[] = {
    { .compatible = "example,soc-gpio" },
    { }
};
MODULE_DEVICE_TABLE(of, gpio_of_match);

static struct platform_driver gpio_driver = {
    .probe  = gpio_probe,
    .remove = gpio_remove,
    .driver = { .name = "example-gpio", .of_match_table = gpio_of_match },
};
module_platform_driver(gpio_driver);
```

```
T+0.010s ──► GIC (interrupt controller) — probes FIRST
             ✅ All other devices need interrupts

T+0.015s ──► Clock Controller
             ✅ All other devices need clocks

T+0.020s ──► Pin Controller (pinctrl)
             ✅ All other devices need pin mux

T+0.022s ──► GPIO Controller
             ✅ Sensors, displays need GPIO

T+0.025s ──► PMIC / Regulator
             ✅ All peripherals need power

T+0.030s ──► UART
             ✅ Console available

T+0.035s ──► I2C Controller
             → of_i2c_register_devices() creates i2c_clients
             ✅ Enables I2C device probing

T+0.040s ──► Touchscreen (I2C)
             (Was deferred: needed GPIO interrupt)
             ✅ GPIO ready now

T+0.045s ──► IMU Sensor (I2C)
             ✅ I2C + GPIO ready

T+0.050s ──► SPI Controller
             → of_register_spi_devices() creates spi_devices

T+0.055s ──► SPI Flash

T+0.100s ──► Display controller
             (Was deferred: needed clock + regulator)
             ✅ Both ready now

T+0.150s ──► Camera sensor
             (Was deferred: needed MCLK)
             ✅ Clock ready

T+0.200s ──► USB Controller
T+0.300s ──► WiFi (SDIO)
T+0.500s ──► All devices probed ✅ → Kernel mounts initramfs → /init
```
