```

    ▼              ▼              ▼              ▼              ▼              ▼
```

## 1. Android 12 — Major Changes

### 1.1 DTB Moved to `vendor_boot` Partition

```
BEFORE (Android 10/11):
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  boot.img   │  │   dtb       │  │   dtbo      │
│  (kernel +  │  │  partition  │  │  partition  │
│   ramdisk)  │  │  (base DTB) │  │  (overlays) │
└─────────────┘  └─────────────┘  └─────────────┘

AFTER (Android 12+):
┌─────────────────────────────┐  ┌─────────────┐
│      vendor_boot.img        │  │   dtbo      │
│  ┌─────────┐ ┌───────────┐  │  │  partition  │
│  │ kernel  │ │  base DTB │  │  │  (overlays) │
│  │ ramdisk │ │  (.dtb)   │  │  │             │
│  └─────────┘ └───────────┘  │  └─────────────┘
└─────────────────────────────┘
```

**BoardConfig.mk Change**

```makefile
# OLD (Android 10/11)
BOARD_PREBUILT_DTBIMAGE_DIR  := device/vendor/device/dtb
BOARD_INCLUDE_DTB_IN_BOOTIMG := false

# NEW (Android 12+)
BOARD_INCLUDE_DTB_IN_BOOTIMG         := true
BOARD_MOVE_DTB_TO_VENDOR_BOOT        := true
BOARD_VENDOR_BOOTIMAGE_PARTITION_SIZE := 67108864  # 64MB
```

**`vendor_boot` Image Layout**

```
┌─────────────────────────────────────────────────────────┐
│                   vendor_boot.img                        │
├─────────────────────────────────────────────────────────┤
│  Header v4                                               │
│  ┌───────────────────────────────────────────────────┐  │
│  │ magic: "VNDRBOOT"                                 │  │
│  │ header_version: 4                                 │  │
│  │ page_size                                         │  │
│  │ kernel_addr, ramdisk_addr, dtb_addr               │  │
│  │ dtb_size  ◄── NEW field                           │  │
│  └───────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│  Vendor Ramdisk (first_stage_ramdisk)                   │
├─────────────────────────────────────────────────────────┤
│  DTB Blob  ◄── NEW location (was separate partition)     │
├─────────────────────────────────────────────────────────┤
│  Vendor Ramdisk Table (multiple ramdisks support)        │
└─────────────────────────────────────────────────────────┘
```

## 2. Android 12 — GKI Impact on DT

### 2.1 GKI Architecture

```
BEFORE GKI:
┌───────────────────────────────────────────────────┐
│              Monolithic Kernel                     │
│  ┌─────────────┐  ┌──────────────┐                │
│  │  GKI Core   │  │  SoC-specific│                │
│  │  (upstream) │  │  drivers     │  ← All in one  │
│  └─────────────┘  └──────────────┘    binary      │
└───────────────────────────────────────────────────┘

AFTER GKI (Android 12+):
┌───────────────────────────────────────────────────┐
│                 GKI Kernel                        │
│  ┌────────────────────────────────┐               │
│  │         Core Kernel            │               │
│  │  (Google maintained, generic)  │               │
│  └────────────────────────────────┘               │
│                   +                               │
│  ┌────────────────────────────────┐               │
│  │         Vendor Modules         │               │
│  │    (.ko files - separate)      │  ← Loadable  │
│  │  - soc-driver.ko               │    Modules   │
│  │  - camera-driver.ko            │              │
│  │  - audio-driver.ko             │              │
│  └────────────────────────────────┘               │
└───────────────────────────────────────────────────┘
```

## 3. Android 13 — DTBO Version 3

### 3.1 DTBO Header Evolution

```
┌──────────────────────────────────────────────────────────────┐
│                  DTBO Header Versions                        │
├────────────────┬─────────────────────────────────────────────┤
│  Version 0     │  Basic: size, offset                        │
│  (Android 9)   │  ← Original DTBO format                    │
├────────────────┼─────────────────────────────────────────────┤
│  Version 1     │  + id, rev fields for hardware matching     │
│  (Android 10)  │  ← Board ID based selection                 │
├────────────────┼─────────────────────────────────────────────┤
│  Version 2     │  + custom[0-3] fields                       │
│  (Android 11)  │  ← 4 extra custom matching fields           │
├────────────────┼─────────────────────────────────────────────┤
│  Version 3     │  + flags field                              │
│  (Android 13)  │  + compression support (ZSTD/GZIP)         │
└────────────────┴─────────────────────────────────────────────┘
```

### 3.2 Compressed DTBO

```c
/* New DTBO entry structure in v3 */
struct dtbo_entry_v3 {
    uint32_t dt_size;
    uint32_t dt_offset;
    uint32_t id;
    uint32_t rev;
    uint32_t custom[4];
    uint32_t flags;          // ← NEW in v3
    /* flags bits:
     * [3:0] = compression type
     *   0x0 = no compression
     *   0x1 = zlib/gzip
     *   0x2 = zstd          ← NEW
     * [31:4] = reserved
     */
};
```

```bash
# Create DTBO with ZSTD compression
mkdtboimg.py create dtbo.img \
    --version=3 \
    --compression=zstd \
    camera-overlay.dtbo \
    display-overlay.dtbo \
    audio-overlay.dtbo
```

```makefile
# BoardConfig.mk
BOARD_DTBO_VERSION     := 3
BOARD_DTBO_COMPRESSION := zstd
```

## 4. Android 14 — Significant Changes

### 4.1 DTB in GKI Boot Image

```
OLD (Android 12/13):
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  boot.img    │  │ vendor_boot  │  │    dtbo      │
│  (GKI kernel)│  │  (DTB here)  │  │  (overlays)  │
└──────────────┘  └──────────────┘  └──────────────┘

NEW OPTION (Android 14):
┌──────────────────────┐  ┌──────────────┐
│      boot.img        │  │    dtbo      │
│  ┌────────────────┐  │  │  (overlays)  │
│  │  GKI Kernel    │  │  └──────────────┘
│  ├────────────────┤  │
│  │  Base DTB      │  │
│  └────────────────┘  │
└──────────────────────┘
```

### 4.2 Lazy DT Probing

```
OLD behavior:
Boot → Parse all DT nodes → Probe ALL devices immediately

NEW behavior (Android 14):
Boot → Parse all DT nodes → Probe CRITICAL devices first
                          → Defer non-critical device probing
                          → Probe remaining on demand

Benefits:
✓ Faster boot time
✓ Reduced memory pressure during early boot
✓ Better parallelization of driver probing
```

```dts
peripheral@1000 {
    compatible = "vendor,non-critical-device";
    reg = <0x1000 0x100>;

    android,lazy-probe;              // ← NEW: probe lazily
    android,probe-stage = "late";    // "early" | "normal" | "late"
};
```

### 4.3 DT Schema Validation

Android 14 enforces DT validation against YAML schema files.

```yaml
# bindings/gpio/example,soc-gpio.yaml

%YAML 1.2
---
$id: http://devicetree.org/schemas/gpio/example,soc-gpio.yaml#
$schema: http://devicetree.org/meta-schemas/core.yaml#

title: Example SoC GPIO Controller

maintainers:
  - Developer Name <dev@example.com>

properties:
  compatible:
    const: example,soc-gpio
  reg:
    maxItems: 1
  "#gpio-cells":
    const: 2
  gpio-controller: true
  interrupt-controller: true
  "#interrupt-cells":
    const: 2
  interrupts:
    maxItems: 1
  ngpios:
    minimum: 1
    maximum: 256

required:
  - compatible
  - reg
  - "#gpio-cells"
  - gpio-controller

additionalProperties: false
```

```bash
# Validate DT against schemas
make dtbs_check DT_SCHEMA_FILES=bindings/
```

## 6. GKI 2.0 Impact on Device Tree

### 6.1 Strict DT / Driver Separation

```
┌─────────────────────────────────────────────────────────┐
│                GKI KERNEL (google/aosp)                  │
│                                                          │
│  ✅ ALLOWED in GKI DT:                                   │
│     - Core CPU, memory, timer nodes                      │
│     - Standard ARM/RISC-V architecture nodes             │
│     - Nodes with upstream kernel drivers                 │
│                                                          │
│  ❌ NOT ALLOWED in GKI DT:                               │
│     - Vendor-specific nodes → vendor_boot DTB            │
│     - Proprietary peripheral nodes                       │
│     - SoC-specific custom nodes                          │
└─────────────────────────────────────────────────────────┘
```

### 6.2 KMI Freeze and DT Binding Stability

```
┌────────────────────────────────────────────────────────┐
│ Once a DT binding is used in a released GKI:           │
│                                                        │
│  ✅ CAN change:  Property values                       │
│  ✅ CAN add:     New optional properties               │
│  ❌ CANNOT change: Required property names             │
│  ❌ CANNOT change: Compatible string format            │
│  ❌ CANNOT remove: Existing required properties        │
│                                                        │
│ Ensures vendor .dtb works with newer GKI kernels       │
└────────────────────────────────────────────────────────┘
```

## 9. Migration Guides

### Android 11 → 12 (DTB Location Change)

```bash
# 1. BoardConfig.mk
# Remove:
BOARD_PREBUILT_DTBIMAGE_DIR  := $(DEVICE_PATH)/dtb
BOARD_INCLUDE_DTB_IN_BOOTIMG := false
# Add:
BOARD_MOVE_DTB_TO_VENDOR_BOOT         := true
BOARD_VENDOR_BOOTIMAGE_PARTITION_SIZE := 67108864
BOARD_BOOT_HEADER_VERSION             := 4

# 2. Update flashing scripts
# Old:  fastboot flash dtb dtb.img
# New:  fastboot flash vendor_boot vendor_boot.img

# 3. Verify
unpack_bootimg --boot_img vendor_boot.img --out vendor_boot_out/
ls vendor_boot_out/
#  dtb               ← Must be present
#  vendor_ramdisk
#  vendor_ramdisk_table
```

### Migrating to DTBO v3 with Compression (Android 13)

```bash
# 1. BoardConfig.mk
BOARD_DTBO_VERSION     := 3
BOARD_DTBO_COMPRESSION := zstd

# 2. Update mkdtboimg call
mkdtboimg.py create dtbo.img \
    --version=3 \
    --compression=zstd \
    *.dtbo

# 3. Verify
mkdtboimg.py dump dtbo.img | grep compression
```

### Enabling DT Schema Validation (Android 13+)

```bash
# 1. Install dependencies
pip install dtschema

# 2. Run validation
make dtbs_check

# 3. Fix example error:
# ERROR: gpio@13000000: 'gpio-controller' is required
# FIX in DTS:
#   gpio-controller;
#   #gpio-cells = <2>;

# 4. Enforce in CI
BOARD_DT_SCHEMA_VALIDATION := true
```
